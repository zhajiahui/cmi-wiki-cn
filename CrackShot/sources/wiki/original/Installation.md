## **░ Step 1**
Download the CrackShot JAR file.
## **░ Step 2**
Stop your server.
## **░ Step 3**
Place the CrackShot JAR file inside your server's _plugins_ folder.
## **░ Step 4**
Start your server. A folder named _CrackShot_ will be generated in the _plugins_ folder, which will contain the default configuration files.
