# ⭐ Experience Boosters {#⭐-experience-boosters}

Admins can use a [command](https://docs.phoenixdevt.fr/mmocore/general/commands) to create EXP boosters that apply to all players on the server! Using the `/mmocore booster create` command, you can specify how much extra % EXP players will earn, and even **which profession** the booster applies for.

## Compatibility Options {#compatibility-options}

This type of EXP Boosters is 100% EULA compliant. The best way to utilize these boosters is to create items with this command bound to right clicks, in order to have consumables that apply EXP boosts for all players currently connected!

The `/mmocore booster create` command has an optional `player` parameter that you can use to specify the booster creator. This way, other players can see who activated the EXP booster.

When a booster is created, a message is broadcast in the entire server. It can be edited in the `messages.yml` config file.

## Currently Active Boosters {#currently-active-boosters}

Active boosters are displayed in the player stats menu which you can access using `/player` as seen on the following screenshot. Players can see the time left before the booster expires, who created the booster, and potentially the profession which the booster applies for.
