# 安装指南 {#🔌-installation-guide}

许多插件问题都是由于无效安装造成的，因此请务必阅读以下教程，以腾出一些时间进行调试！

1. 确保先安装[MythicLib](https://www.spigotmc.org/resources/mythiclib.90306/)
2. 将下载的MMOCore文件拖放到插件文件夹中。
3. 重新启动服务器以生成默认配置文件。
4. **如果安装了MMOItems的 MMOMana 插件，请卸载它**，它不适合与任何已安装魔力的插件（例如MMOCore）一起使用。
5. MMOCore附带的默认配置展示了与其他插件相关的各种兼容性功能，包括WorldGuard、Citizens、MythicMobs、MMOItems...如果未安装这些插件，你将在控制台中收到一些启动警告，这是完全正常的。如果你想使用它们，请花些时间探索这些功能并安装所需的插件。
