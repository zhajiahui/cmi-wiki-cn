# 模块化 {#🦾-modularity}

MMOCore是一个模块化插件：它具有你可以选择保留或丢弃的特定模块。例如，你可以选择使用默认的MMOCore队伍系统，或者选择其他插件 - 只要MMOCore支持 - 并且集成将是完美的。MMOCore为你的RPG服务器提供核心功能（职业、技能、升级和副职业），但它绝对最好与其他RPG插件（如任务和公会解决方案）一起使用。

目前MMOCore有任务、队伍、公会、技能创建模块。模块化非常好，因为如果需要，你仍然可以使用默认的MMOCore模块，而更高级的用户可以切换到他们最喜欢的更高级的插件，从而实现更多的可配置性
