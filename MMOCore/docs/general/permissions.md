# 权限 {#🧑‍⚖️-permissions}

|权限|描述 |默认 |
| --- | --- | --- |
| `mmocore.admin` | 授予对`/mmocore`的访问权限 | OP |
| `mmocore.waypoints` | 访问`/waypoints` | OP |
| `mmocore.pvpmode` | 访问`/pvpmode` | OP |
| `mmocore.currency` | 访问`/deposit`和`/withdraw` | OP |
| `mmocore.bypass-waypoint-wait` | 绕行航点等待时间 | None |
| `mmocore.class-select` | 访问`/class` | OP |
| `mmocore.attributes` | 访问`/attributes` | Player |
| `mmocore.skills` | 访问`/skills` | Player |
| `mmocore.profile` | 访问`/profile` | Player |
| `mmocore.friends` | 访问`/friends` | Player |
| `mmocore.guild` | 访问`/guild` | Player |
| `mmocore.party` | 访问`/party` | Player |
| `mmocore.skilltrees` | 访问`/skilltrees` | Player |
| `mmocore.quests` | 访问`/quests` | Player |
