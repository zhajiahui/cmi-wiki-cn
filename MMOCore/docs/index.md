# 首页 {#🏠-home}

![Vyor7Op](assets/3ab30c1d9edd-banner.DGZx1d5z.png)

MMOCore 由 MMOItems 的作者开发，提供一套新的 RPG 方案，旨在替代已过时的常见插件，并保留玩家熟悉的自定义选项与功能。经过 7 年多的开发和大量问题测试，作者希望提供尽可能好的使用体验。

> **提示**
>
> 从 [Polymart](https://polymart.org/product/3412/mmocore)或 [Spigot](https://www.spigotmc.org/resources/mmocore.70575/)] 获取MMOCore

有疑问时，可以加入 [Discord](https://phoenixdevt.fr/discord)，向工作人员或社区求助。Wiki 会尽量保持更新；发现错字或过时内容时，也欢迎反馈。

> **信息**
>
> MMOCore 自带基础的职业、基础属性和任务等配置，也提供了许多入门示例。不过，插件的大部分内容仍需要自行配置。

当你准备好安装MMOCore时，导航到下一页！
