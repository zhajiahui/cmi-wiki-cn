# 迁移到 SQL（归档）

以下是一个简短指南，可将所有数据正确加载到数据库中以供MMOCore读取：

1. 关闭你的服务器。
2. 将PD2MySQL.jar文件放入MMOCore/userdata/ 文件夹中（以及所有UUID文件）
3. 运行 jar 并输入所需的信息。如果你有任何错误，可以在这里寻求帮助。
4. 验证数据库的内容
5. 使用最新的MMOCore启动你的服务器（记住在config.yml中启用MySQL！）

**[PD2MySQL](https://cdn.discordapp.com/attachments/619382995073105926/686925969642356736/PD2MySQL.jar)** 的下载链接。
