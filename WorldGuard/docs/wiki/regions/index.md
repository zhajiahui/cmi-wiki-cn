# 区域 { #regions }

WorldGuard 可以定义不同形状、带有名称的三维空间，称为“区域”。每个世界可以没有区域，也可以有多个区域；每个区域都可设置所有者、成员、自定义优先级、旗标和父区域。

- 保护出生点和世界中的其他区域

- 创建允许玩家拥有地块的商业区

- 禁止在中立区域进行玩家之间的战斗

- 禁止进入指定区域

- 设置能治疗玩家的“医院”区域

父子区域层级和优先级系统可以组合出复杂的配置。
