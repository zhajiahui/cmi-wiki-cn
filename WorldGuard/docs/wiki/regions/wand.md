# 区域查询工具 { #region-wand }

区域查询工具可以列出指定位置的所有区域。它是一个普通 Minecraft 物品，拿着它右键点击方块即可。默认物品是皮革，可在[配置](../config.md)中修改。

使用查询工具需要 `worldguard.region.wand` 权限。
