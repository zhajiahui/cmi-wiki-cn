# 兼容插件 {#compatible-plugins}

MythicMobs 兼容 Minecraft 中许多流行插件，还有通过 API 进一步扩展其功能的附属插件。

**Mythic 附属插件：**

- [Crucible](https://mythiccraft.io/index.php?resources/crucible-create-unbelievable-mythic-items.2/)：使用 Mythic 技能系统制作自定义物品，让玩家获得应对自定义生物所需的优势！
- [BossShop 附属插件](https://www.spigotmc.org/resources/mythicmobs-%E2%9A%94-bossshoppro-add-on-%E2%9A%94.58415/)：兼容商店插件 BossShopPro，方便在商店中使用 MythicMobs 物品。
- [Depenizen](https://ci.citizensnpcs.co/view/All/job/Depenizen/)：为 [Denizen](https://guide.denizenscript.com/) 添加 MythicMobs 标签和功能，同时为 MythicMobs 添加 Denizen 条件和目标选择器！
- [Quests 附属插件](https://www.spigotmc.org/resources/mythicmobs-quests-module.7261/)：兼容 Quests 插件，支持将 Mythic 生物用作任务目标。
- [Skript 附属插件](https://github.com/BerndiVader/mmSkriptAddon)：提供与 Skript 的完整互通兼容！

**兼容 MythicMobs 的常用插件：**

- [Advanced Achievements](https://www.spigotmc.org/resources/advanced-achievements.6239/)：创建与生物有关的自定义成就
- [BetonQuest](https://www.spigotmc.org/resources/betonquest.2117/)：完整兼容任务目标
- [BeautyQuests](https://www.spigotmc.org/resources/beautyquests.39255/)：完整兼容任务目标
- [Denizen](https://guide.denizenscript.com/)：为服务器编写自定义脚本，控制生物、玩家及其他各种内容
- [EnchantsPlus](https://www.spigotmc.org/resources/enchantsplus.3396/)：为物品使用自定义附魔
- [Graveyards](https://www.spigotmc.org/resources/graveyards-40-off.7191/)：在玩家重生时施加技能
- [Heroes](https://www.spigotmc.org/resources/heroes.305/)：生物可以掉落 Heroes 经验等内容！
- [Holograms](https://www.spigotmc.org/resources/holograms.4924/)：自定义血条和名称标签。
- [LibsDisguises](https://www.spigotmc.org/resources/libs-disguises.81/)：为生物设置伪装
- [McMMO](https://www.spigotmc.org/resources/mcmmo.2445/)：掉落 McMMO 经验等内容。
- [MiniaturePets](https://www.spigotmc.org/resources/%E2%8C%BE-miniaturepets-%E2%8C%BE-custom-mobs-great-for-eula.23991/)：使用自定义 MiniaturePets 制作生物！
- [SkillAPI](https://www.spigotmc.org/resources/skillapi-premium.28029/)：生物可以掉落 SkillAPI 经验等内容。
- [TerrainControl](https://www.spigotmc.org/resources/terraincontrol.2214/)：在 TC 生物群系中生成自定义生物
- [Vault](https://www.spigotmc.org/resources/vault.41918/)：与货币有关的特殊技能和条件
- [WeaponMechanics](https://www.spigotmc.org/resources/weaponmechanics.99913/)：让生物使用其中的技能机制！
- [WorldGuard](https://dev.bukkit.org/projects/worldguard)：使用 WG 区域控制生成和条件
