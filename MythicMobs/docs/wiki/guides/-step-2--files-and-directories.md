# （步骤 2）文件与目录 {#step-2-files-and-directories}

了解各项内容后，接下来需要知道它们应放在哪里！

MythicMobs 文件夹包含多个子文件夹，分别保存定义生物、物品和生成规则的 yaml 文件。你也可以使用[包](../packs.md)，将内容整理到各自的小目录中。

MythicMobs 文件夹中有对应各个组件的子文件夹。这些文件夹可以包含任意数量的子文件夹和 .yml 文件，每个文件也可以包含任意数量的生物、物品、随机生成等配置。你还可以在包中创建文件夹，用于保存包内的生物。

有效的文件路径示例：

- /plugins/MythicMobs/Mobs/SkeletonKing.yml
- /plugins/MythicMobs/Mobs/Skeletons/King.yml
- /plugins/MythicMobs/Packs/Skeletons/Mobs/King.yml
