# Parent Target

# 父实体的目标 {#parent-target}

## 说明 {#description}

以正在被施法者的父实体攻击的实体为目标。

## 属性 {#attributes}

> *此 AI 攻击目标选择器没有属性。*

## 示例 {#examples}

```yaml
  AITargetSelectors:
  - clear
  - ParentTarget
```

## 别名 {#aliases}

- parentAttack
