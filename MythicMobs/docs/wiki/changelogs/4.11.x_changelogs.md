# 4.11.X 更新记录

# 4.11.0 {#4110}

## 通用设置 {#general}

- 新增对 1.16.4 的支持

## 生物 {#mobs}

- 新增 PIGLIN_BRUTE、BABY_PIGLIN_BRUTE
- 将 Options.PreventItemPickup 的默认值改为 true

## 技能机制 {#mechanics}

### onAttack 光环 {#onattack-aura}

- 允许在 damageAdd、damageMultiplier 中使用占位符

### 轨道投射物 {#orbitals}

- 为 Orbital 新增弹射物子弹

### Shoot 与 Volley {#shoot-volley}

- 新增 Trident 弹射物类型
- 新增 splash_potion 和 lingering_potion 弹射物类型
- 将 Projectile 机制的大部分选项添加到 Shoot 和 Volley

### ShootFireball {#shootfireball}

- 新增 type=[SMALL/LARGE/DRAGON] 属性

### 新增：BlockPhysics {#new-blockphysics}

- 在目标位置触发一次方块物理更新

### 新增：PotionClear {#new-potionclear}

- 清除目标实体的全部药水效果

### 新增：Extinguish {#new-extinguish}

清除目标实体的所有着火时间

### 新增：FawePaste {#new-fawepaste}

### 新增：Oxygen {#new-oxygen}

给予目标玩家一定量的氧气

```
- oxygen{amount=10}
```

### 新增：setNoDamageTicks {#new-setnodamageticks}

设置目标的无敌时间，以刻为单位。如果在攻击期间立即使用，应延迟执行，因为无敌时间是在事件完成后应用的。

```
- setNoDamageTicks{ticks=0;delay=1} @trigger ~onAttack
```

### 新增：Swap {#new-swap}

交换施法者与目标实体的位置。

### 新增：WolfSit {#new-wolfsit}

设置目标狼的坐下状态

```
- wolfSit{state=true}
```

## 效果 {#effects}

### 粒子效果 {#particle-effects}

- 为粒子效果新增 dir=x,y,z 选项，用于指定方向向量
- 为所有粒子效果新增 audience=[world/target] 选项

### 新增：TotemUndying 效果 {#new-totemundying-effect}

- 播放不死图腾使玩家复活的效果
- 可以指定资源包中的一个模型，覆盖显示在玩家屏幕上
- 音效无法关闭 :(

```
- totemUndying{model=2}
```

## 目标选择器 {#targeters}

### 通用设置 {#general-2}

- 为 @Location 目标选择器新增 yaw 和 pitch
- 升级了 raytrace 机制，使其能穿过屏障方块

### 新增：@BlocksInRadius{r=#} 位置目标选择器 {#new-at-blocksinradiusr-location-targeter}

### 新增：@CasterSpawnLocation {#new-at-casterspawnlocation}

### 新增：@ObstructingBlock {#new-at-obstructingblock}

### 新增：@FloorOfTargets 元目标选择器 {#new-at-flooroftargets-meta-targeter}

### 新增：@LocationsOfTargets 元目标选择器 {#new-at-locationsoftargets-meta-targeter}

## 条件 {#conditions}

### Moving {#moving}

- 更新了 moving 条件，使其适用于玩家

### 新增：HasPassenger {#new-haspassenger}

### 新增：Burning // isBurning {#new-burning-isburning}

### 新增：SlimeSize {#new-slimesize}

```
- size >5
```

## 物品 {#items}

### NBT 标签改进 {#nbt-tag-improvements}

- 新增指定 NBT 标签数据类型的功能

```
AnItem:
  Id: EMERALD
  NBT:
    AnInteger: int/32
    ADouble: double/50.0`
    AByte: byte/1
```

## API {#api}

- 新增 MythicMobItemGenerateEvent，每当生成物品时调用
