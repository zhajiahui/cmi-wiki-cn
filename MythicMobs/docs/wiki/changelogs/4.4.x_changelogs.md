# 4.4.0 {#440}

## DropTables 更新 {#droptables-update}

掉落表已从头完全重写，速度更快、问题更少，并且现在包含丰富的 API，让其他插件可以添加自定义掉落类型。

### 通用设置 {#general-2}

- 掉落表现在会在启动时预加载，CPU 消耗大幅降低。
- 掉落表的 **Conditions** 和 **TriggerConditions** 现在使用新的条件系统
- 已移除 **DropsPerLevel**
- 新增的 **BonusLevelItems** 和 **BonusLuckItems** 选项，可让掉落表根据掉落者的等级和击杀者的幸运属性额外抽取物品。如果只希望每级增加获得额外物品的概率，可以使用小数。
- **TotalItems**、**MaxItems** 和 **MinItems** 选项现在更加可靠，随机性也更好。
- 使用 **TotalItems**、同时使用 **MaxItems** 和 **MinItems**，或使用任何 "Bonus" 物品选项时，掉落表会改为将每个物品的“概率”按权重计算。否则，掉落表会按通常方式抽取，每一项都按概率计算。

### 物品掉落 {#item-drops}

- 基础掉落和装备物品现在可以通过行内基本选项自定义，无需创建完整的 MythicItem
- 目前可用的行内选项包括 **name**、**data**、**amount**、**lore** 和 **color**

```
 Equipment:
 - leather_chestplate{name="Dark Leather";lore="&8A vest made of darkened leather";color=BLACK} chest 1 1
```

### 装备 {#equipment}

- 旧语法仍然可用，现在也可以使用以下写法：

```
 Equipment:
 - iron_sword:0
 - iron_sword:hand
 - iron_sword hand
 - iron_sword hand 1 0.1  //(you still have to enter amount before chance)//
```

## 命令 {#commands}

- 对于获取或给予物品的命令，现在可以指定掉落表，将整个掉落表的物品给予玩家。

## 技能机制 {#mechanics}

### Command {#command}

- **asCaster** 选项现在会使生物通过 **minecraft:execute** 执行命令

### Equip {#equip}

- equip 机制现在可以同时装备多个物品或掉落表，以逗号分隔。

```
equip{items="iron_sword hand, iron_helmet head, iron_boots feet"}
```

### 新增：DropItem {#new-dropitem}

DropItem（或 DropItems）是一种以位置为目标的技能，可在目标位置掉落物品或掉落表。

- - dropitem{item=X}

### 新增：RemoveBuff {#new-removebuff}

- - removebuff{name=X}

## 条件 {#conditions}

### 新增：Blocking {#new-blocking}

- 如果目标正在使用盾牌格挡，则为 true
- - blocking

### 新增：HasBuff {#new-hasbuff}

- - hasbuff buffname

## 物品 {#items}

- 为物品新增 **Options.PreventStacking: true**
- **Options.Color: r,b,g** 现在对 Potion 物品生效
- 对于皮革物品，Color 现在除了 **r,g,b** 格式外，还可以使用 Bukkit 的 DyeColor 名称

### 烟花 {#fireworks}

- 为 FIREWORK 和 FIREWORK_CHARGE 物品新增选项
- 对于 Colors 和 FadeColors，可以使用 **RED,GREEN,BLUE** 格式指定所需颜色

```
Firework:
  Colors:
  - 255,0,255
  - 0,0,0
  FadeColors:
  - 200,0,0
  Flicker: true
  Trail: true
```

## 伪装 {#disguises}

- 新增幻术师伪装
- 新增鹦鹉伪装，带有 Disguise.Color 选项
- 更新为使用最新版 LibsDisguises
- 改进了对错误伪装配置的错误捕获

## API {#api}

- MythicMobsDeathEvent 已改动，附加插件可能需要更新。
- 插件现在可以通过 API 注册自定义掉落类型，方式类似自定义机制。
