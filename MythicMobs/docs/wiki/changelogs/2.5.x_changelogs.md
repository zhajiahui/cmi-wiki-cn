## 支持 MiniaturePets {#miniaturepets-support}

MythicMobs 现在支持 MiniaturePets 插件！
<https://www.spigotmc.org/resources/miniaturepets.23991/>

MiniaturePets 允许使用各种工具创建自定义“宠物”模型，现在借助 MythicMobs，你可以将这些自定义宠物变成强大的首领！

这为生物提供了大量自定义空间。

注意，目前宠物的移动速度无法修改，而且速度极高。希望 MPet 开发者能在未来修复这一点。

### 用法 {#usage}

使用 MiniaturePets 支持很简单。

```
ExampleMob:
  Type: MPET
  MPet:
    Type: <type>
    Anchor: <invisible "base" mob type>
    ShowName: <true/false>
```

例如，可以使用 MPets 提供的 "Pug" 生物类型创建一个 AngryPug 生物：

```
AngryPug:
  Type: MPET
  MPet:
    Type: PUG
    Anchor: SPIDER
    ShowName: true
  Display: 'Angry Pug'
```

### 目标选择器 {#targeters}

#### 过滤器 {#filters}

所有目标选择器现在都可以使用筛选器，筛选要选取的实体类型。

通过以下两个新选项使用筛选器（适用于任何目标选择器）：

- ignore=X *（两者中更实用的选项）*
- target=X *（不那么实用，因为大多数对象默认都会被选中）*

Example:

1. damage{a=20} @EntitiesInRadius{r=10;ignore=players,animals}

可用的筛选器包括：

- players
- creative
- spectators
- NPC（Citzen NPC）
- animals
- monsters
- creatures
- watermobs
- flyingmobs
- 以后还会加入更多……

#### 新增：@Cone {#new-at-cone}

返回构成锥形的 #points 个目标位置

Options:

- angle - 锥形的角度
- range - 锥形的范围
- points - 构成锥形的“点”的数量
- rotation - 锥形围绕施法生物旋转的角度，范围为 360 度

#### 新增：@EntitiesInCone {#new-at-entitiesincone}

以锥形内的实体为目标

Options:

- angle - 锥形的角度
- range - 锥形的范围
- rotation - 锥形围绕施法生物旋转的角度，范围为 360 度

#### 新增：@Line {#new-at-line}

以一条直线上的位置/点为目标（用于创建直线效果）

#### 新增：@EntitiesInLine {#new-at-entitiesinline}

以一条直线上的所有实体为目标

#### 新增：@Mount {#new-at-mount}

以生物生成时骑乘的坐骑为目标

### 触发器 {#triggers}

#### ~onFirstSpawn {#onfirstspawn}

- 在冷却/预热时间结束后，刷怪点首次生成生物时触发。
- 生物重新生成时不会触发（与每次都会触发的 onSpawn 不同）
- 配合将刷怪点的 checkForPlayers 选项设为 false，可用于向全服公告首领已生成等用途

#### ~onPlayerDeath {#onplayerdeath}

- 世界中任意玩家因任何原因死亡时触发
