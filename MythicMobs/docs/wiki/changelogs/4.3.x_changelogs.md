# 4.3.X 更新记录

# 4.3.2 {#432}

## 问题修复与其他改动 {#bug-fixes-other}

- 修复了 1.8 上生物伤害的更多问题
- 修复了几个技能触发器在 1.8 上不生效的问题
- 修复了伤害修正项在 1.8 上不生效的问题
- 修复了 1.8 上的其他几个问题
- 修复了使用仇恨表时控制台出现 "unknown target reason" 错误的问题

# 4.3.1 {#431}

## 问题修复与其他改动 {#bug-fixes-other-2}

- 修复了 Cast、CastInstead 条件动作不生效的问题
- 修复了 1.8 中的生物伤害
- 修复了 **/mm item import** 命令每个文件只允许一个物品的问题
- 修复了一些控制台错误
- 修复了增益未能被追踪的一些问题

# 4.3.0 {#430}

## 命令 {#commands}

- 生命值为 100% 的生物现在会在 /reload 时完整更新所有改动
- 为 **mob spawn** 命令新增 -t 标志，可在目标方块处生成
- 为 **item give** 命令新增 -s 标志，可静默给予物品
- 为 **/mm m spawn** 新增命令别名 **/spawnmob**
- 生成命令现在接受原版生物类型来生成生物
- 重新添加了 Timings 命令
- 修复了许多 Tab 补全问题

### 导入物品 {#import-items}

- 新增 **/mm item import <itemName> [fileName]** 命令，可导入手持物品，供 MythicMobs 使用
- 文件名默认为 <itemName>.yml

## 生物 {#mobs}

### 通用设置 {#general}

- 生命值为 100% 的生物现在会在 /reload 时完整更新所有改动
- 新增 "Rider" 选项，作用类似 Mount
- Mount、Rider 和通过技能召唤的生物，现在会注册为召唤者的“子级”，供其他条件/机制使用。
- 新增 **Options.PassthroughDamage: true**，如果生物存在父级，则将其受到的所有伤害转移给父级。

### 潜影贝 {#shulkers}

- 为潜影贝新增 Options.Color

## 技能机制 {#mechanics}

### 新增：Buff {#new-buff}

- Meta 和 Buff 机制
- 对目标施加一个持续一定时间的“增益”。
- Options:
  - buffName
  - Charges
  - Duration
  - interval
  - onStartSkill
  - onTickSkill
  - onEndSkill

Buff 机制及继承自它的所有增益类机制，将在未来的更新中大幅改进，获得更多功能。

### 新增：Feed {#new-feed}

- 为目标玩家补充饥饿值
- feed{amount=#;saturation=#;overfeed=[true/false]}

### 新增：Orbital {#new-orbital}

- Meta 和 Buff 机制
- 可以使用 Buff 机制的任何选项
- 创建一个“环绕”目标实体或位置的弹射物
- “原点”位于环绕点

### 新增：Look {#new-look}

- 使生物看向目标
- look{headOnly=[boolean];immediately=[boolean]}

### 新增：ParticleOrbital {#new-particleorbital}

### 新增：SetSpeed {#new-setspeed}

### 新增：Undisguise {#new-undisguise}

- 如果施法者有伪装，则取消其伪装
- - undisguise{}

### AtomEffect {#atomeffect}

- 不再需要 EffectLib

### Disguise {#disguise}

- Disguise 技能现在可以使用配置生物时普通伪装可用的**所有选项**。

例如，此配置：

```
Disguise:
  Type: PLAYER
  Player: RickyLing
  Skin: jaylawl
```

……现在也可以像这样用于技能中：

1. disguise{type=PLAYER;player=RickyLing;skin=jaylawl}

### Missile {#missile}

- 新增 **forwardOffset**、**sideOffset** 选项

### ModifyProjectile {#modifyprojectile}

- 为 modifyProjectile 技能新增 **action** 选项，动作有 SET、MULTIPLY
- 修复了涉及此机制的几个问题

### 粒子效果 {#particle-effects}

- 新增 forwardOffset、sideOffset
- 适用于 Particle 和 ParticleLine 效果
- ParticleLine 现在遵循 UseEyeLocation 选项

### Prison {#prison}

- 新增 **materialData** 选项

### Shoot {#shoot}

- 为 Shoot 机制新增 **gravity=false** 选项

## 条件 {#conditions}

### 通用设置 {#general-2}

- 修复了条件以 "- condition
variable" 格式编写时不生效的许多问题

### 新增：fieldOfView {#new-fieldofview}

- - fieldofview{angle=#;rotation=#}
- 如果目标处于生物视野内，则为 true
- Angle 是视野的角度
- Rotation 可将视野顺时针旋转 # 度

### 新增：hasParent {#new-hasparent}

- - hasparent
- 如果生物存在已注册且当前存活的父级，则返回 true
- 如果父级已死亡或已消失，则返回 false

## 目标选择器 {#targeters}

### 新增：@Children {#new-at-children}

- 以玩家或生物召唤的任何存活“子级”为目标

### 新增：@Forward {#new-at-forward}

- 以施法者前方为目标

## 刷怪点 {#spawners}

- 大幅优化了刷怪点，在某些情况下可使 CPU 占用降低最多 90%
- "Level" 现在允许使用 "1to5" 等格式的范围
- 修复了 **Despawn: false** 的生物在重载时重复出现的问题
- 修复了半径未使用 X 轴的问题
- 修复了刷怪点的其他多个问题

## 自定义 AI {#custom-ai}

### 新增 AI 行为 {#new-goals}

- fleeWolves
- goToParent
- panic
- randomFly

## API {#api}

- 修复了通过 API 注册的自定义目标选择器

## 兼容性 {#compatibility}

### 伪装 {#disguises}

- 新增 **babypolarbear** 伪装
- 方块和物品伪装现在可以接受 Mythic 物品名称
- 所有剩余的 Disguise 选项均已相应移动到 Disguise 配置块下

### 全息文字 {#holograms}

- 新增生物选项 **Nameplate.Enabled: true**，用于强制使用自定义名称牌
