### 技能参数（付费版功能） {#skill-parameters-premium-feature}

技能参数是一项新功能，让你更轻松地创建通用技能，并从其他技能向其传递参数。如果听起来不好理解，这里有个示例！

目前，大多数人会为各种生物编写许多相似的伤害技能，只稍微调整伤害差异，其他方面的作用基本相同。

**旧的做法：**

```
ShadowDamage20:
  Skills:
  - damage{amount=20}
  - some shadowy effect

ShadowDamage50:
  Skills:
  - damage{amount=50}
  - some shadowy effect

Mob1:
  Skills:
  - skill:ShadowDamage20 ~onAttack

Mob2:
  Skills:
  - skill:ShadowDamage50 ~onAttack
```

**借助技能参数，可以将这些技能合并为单个技能！新的做法：**

```
ShadowDamage:
  Skills:
  - damage{amount=<skill.damage>}

Mob1:
  Skills:
  - skill:ShadowDamage{damage=20} ~onAttack

Mob2:
  Skills:
  - skill:ShadowDamage{damage=50} ~onAttack
```

“技能参数”系统会将 **skill/metaskill** 机制中的**任何**选项（该机制专用的选项除外）沿技能树向下传递，供后续引用。如果后续技能传递了同名参数，就会覆盖它。这些参数可用于任何支持占位符的地方。

```
- skill{skill=SomeSkill;anything=2;somethingElse=5}

SomeSkill:
  Skills:
  - particles{amount=<skill.anything>}
  - damage{amount=<skill.somethingElse>}
```

## 技能机制 {#mechanics}

### 新增：起点覆盖（付费版功能） {#new-origin-override-premium-feature}

- 新增 `origin=@targeter` 选项，可在任何机制中设置原点。此选项会传递至所有子机制。

### BreakBlock {#breakblock}

- 新增 doDrops、doEffect、useTool 选项

### 伪装**重大变更** {#disguise-major-change}

- 将 disguise 机制重命名为 disguiseOld
- Disguise 现在只接受通过 d= 指定的 LibsDisguises 配置字符串

### FAWEPaste {#fawepaste}

- 新增 chestDropTable 选项
- 允许指定一个 MythicMobs 掉落表，在粘贴该结构图时，自动随机填充其中的所有箱子

### FillChest {#fillchest}

- 使用掉落表的内容填充目标位置的箱子

### GiveItem {#giveitem}

- 新增 fakeLooting=true 选项，播放从原点拾取物品的动画

### 消息 {#messages}

- 新增 audience 选项

### ModifyProjectile {#modifyprojectile}

- 为环绕体新增 radius 特性

### 投射物 {#projectiles}

- 大幅改进了方块碰撞检测
- 改进了对巨型生物（巨人、恶魂等）的碰撞检测
- 改进了对 ModelEngine 生物的碰撞检测

### RemoveAura {#removeaura}

- 现在可以指定 "ANY"，移除目标的全部光环

### 新增：ChainMissile （付费版功能） {#new-chainmissile-premium-feature}

- 结合 Chain 与 Missile 机制，创建可在多个目标之间弹跳的导弹

### 新增：giveItemFromTarget {#new-giveitemfromtarget}

- 给予施法者一个物品，同时播放从目标实体或位置拾取物品的动画

### 新增：raytraceTo （仅限付费版） {#new-raytraceto-premium-only}

- 从原点向目标位置进行射线检测
- 与 raytrace 机制具有相同的选项

### 新增：ShootShulkerBullet {#new-shootshulkerbullet}

- 发射一枚潜影贝子弹
- 具有 onTick、onHit、onEnd 选项

### 新增：clearThreat {#new-clearthreat}

- 清空生物的仇恨表

### 新增：variableUnset{var=} {#new-variableunsetvar}

## 效果 {#effects}

### 接收对象 {#audiences}

- 新增 *caster* 接收对象
- 新增 *@targeter* 接收对象，允许使用任何实体目标选择器来指定接收对象

### 粒子效果——生物粒子？？？**（仅限付费版）** {#particle-effects-mob-particles-premium-only}

- 为所有粒子效果新增特殊类型 particle=mob
- 随后可以通过 mob=[type] 指定一个 MythicMob
- 这是一种变通方法，通过使用不执行游戏刻更新、佩戴模型或使用字体字符的盔甲架，将生物作为效果中的“粒子”。如果愿意，也可以使用盔甲架以外的对象，但出于性能考虑，我们不建议这样做。

### BlockWave {#blockwave}

- 新增 velocityX、velocityY、velocityZ 和 ignoreAir 选项
