# 4.6.0 - 4.6.4 {#460-464}

## 通用设置 {#general}

- 新增配置选项 RandomSpawning.DisableVanillaSpawns
- 现在可以使用新的简写语法 **skill:name** 调用技能

```
Skills:
- skill:someskill ~onAttack
```

## 主要功能 {#major-features}

### 保存改进 {#better-saving}

设置 **Despawn: false** 的生物现在会更可靠地保存信息，并能在重启前后记住所有自身信息，例如主人、姿态等。

### 变量系统 {#variables-system}

MythicMobs 现在包含许多处理变量的新机制和条件，可在生物或玩家上设置临时、不保存或永久变量。详情请参阅变量页面。

### 占位符 {#placeholders}

占位符系统（以前不知为何被称为变量）已完全重做，速度更快，并新增了多种占位符。

*此处指的是在任何已配置字符串中使用 <> 占位符的系统，例如 <caster.name>*

此系统现已集成 PlaceholderAPI，可以在任何支持 MM 占位符的地方使用 %placeholderapi% 占位符

占位符现在应当可以用于任何允许字符串的机制和条件。

部分新增占位符包括：

- <caster.var.X> - 获取当前施法者上变量 X 的值
- <target.var.X> - 获取当前目标上变量 X 的值
- <trigger.var.X> - 获取当前触发者上变量 X 的值
- <skill.var.X> - 获取当前技能树上变量 X 的值
- <random.#to#> - # 与 # 之间的随机数

变量占位符后可以追加 |default，以便在所查找的变量未设置时使用默认值。

```
<target.var.something|default>
```

### 内联条件 {#in-line-conditions}

现在可以使用新的 ? “if”运算符，在机制中使用基本条件。这些条件仅作为普通条件运行（以施法者为目标），不支持**条件动作**，并且始终检查条件是否为 **true**。

例如：

```
Skills:
- message{m="hey i'm on a gold block!"} @trigger ?onBlock{t=GOLD_BLOCK} ~onInteract
```

机制行中可以按需要添加任意多个这类条件，多个条件可以同时使用。

## 技能机制 {#mechanics}

### 新增：BreakBlock {#new-breakblock}

破坏目标位置的方块

```
Skills:
- breakblock @targetlocation
```

### 新增：onAttack {#new-onattack}

一种特殊的光环机制，为目标临时添加 onAttack 技能。也可用于修改该次攻击造成的伤害。

```
Skills:
- onAttack{auraName=fiery_strikes;onHit=FireStrike;duration=200;charges=5;multiplier=2} @self
```

在此示例中，施法者在 10 秒内的接下来 5 次物理命中，会触发以被击中对象为目标的 FireStrike 技能，并造成 200% 伤害。不过，如果 FireStrike 的条件不满足，就会造成普通伤害，因为伤害倍率也不会生效。

onAttack 具有以下选项：

- 光环可用的全部选项
- **onHit=[skill]** - 光环生效期间执行的技能
- **cancelEvent=true** - 是否取消事件并不造成基础伤害
- **multiplier=#** - 可选的原始命中伤害倍率
- **add=#** - 可选的原始命中伤害固定增加值

### 新增：onDamaged {#new-ondamaged}

一种特殊的光环机制，为目标临时添加 onDamaged 技能。也可用于修改该次攻击造成的伤害。

```
Skills:
- onDamaged{auraName=fire_shield;onHit=FireShield;duration=200;charges=5;multiplier=0.5} @self
```

在此示例中，施法者在 10 秒内接下来受到的 5 次命中，会触发以攻击者为目标的 FireShield 技能，并使该次伤害变为 50%。不过，如果 FireShield 的条件不满足，就会受到正常伤害，因为伤害倍率也不会生效。

onDamaged 具有以下选项：

- 光环可用的全部选项
- **onHit=[skill]** - 光环生效期间执行的技能
- **cancelEvent=true** - 是否取消事件及受到的伤害
- **multiplier=#** - 可选的原始命中伤害倍率
- **sub=#** - 可选的原始命中伤害固定减少值（负值则增加伤害）

设置或更改目标生物的阵营

```

```

### 新增：SetGameMode {#new-setgamemode}

设置目标玩家的游戏模式

```

```

### 新增：Shield {#new-shield}

给予目标指定数量的伤害吸收生命值作为护盾。

```
Skills:
- shield{amount=10;maxShield=20} @target
```

### 新增：ShieldPercent {#new-shieldpercent}

按目标最大生命值的一定百分比，给予伤害吸收生命值作为护盾。

```
Skills:
- shield{multiplier=0.5;maxShield=2} @target
```

MaxShield 也作为倍率使用，因此示例中的护盾最多可叠加至目标最大生命值的 2 倍。

### 新增：VariableSet {#new-variableset}

在指定作用域中设置一个[变量](../skills/variables.md)。

```
  setVariable{
      variable=[scope].[name];
      value=[the value];
      type=[variable_typpe];
      save=[true/false];
      duration=[optional_duration_in_ticks]
    }

Skills:
- setvariable{var=skill.testVar;value="hello";type=STRING} ~onInteract
- setvariable{var=caster.something;value=1;type=INTEGER;save=true} @self ~onInteract
- setvariable{var=target.temporaryVar;value="im temporary";type=STRING;duration=200} @target ~onAttack
```

可通过在变量前添加 **scope.name** 前缀，或使用 **scope=[scope]** 选项来设置作用域。

### 新增：VariableAdd {#new-variableadd}

为指定作用域中的[变量](../skills/variables.md)增加一个数值。仅适用于数值类型的变量。

```
Skills:
- variableadd{var=skill.testVar;amount=1} ~onInteract
```

### 新增：VariableSubtract {#new-variablesubtract}

从指定作用域中的[变量](../skills/variables.md)减去一个数值。仅适用于数值类型的变量。

```
Skills:
- variablesubtract{var=skill.testVar;amount=1} ~onInteract
```

### 光环 {#auras}

为光环新增了多个选项，并修复了许多问题：

| **选项** | **说明** |
| --- | --- |
| **maxStacks=5** | 同一施法者可在一个目标身上叠加此光环的最大层数 |
| **mergeAll=false** | 默认为 false，用于合并同一目标身上来自所有施法者的光环，并增加层数 |
| **mergeSameCaster=true** | 默认为 true，用于合并同一目标身上来自同一施法者的光环，并增加层数 |
| **refreshDuration=true** | 默认为 true，叠加新层数时刷新光环持续时间 |

## 条件 {#conditions}

### 新增：StringEquals {#new-stringequals}

如果两个字符串匹配，则返回 true。两个值均可使用占位符。

```
Conditions:
- stringEquals{value1="yes";value2="<mob.var.ready|nope>"}
- stringEquals{value1="yes";value2="%essentials_godmode%"}
```

### 新增：VariableEquals {#new-variableequals}

如果变量与该值匹配，则返回 true。值中可以包含占位符/其他变量等。

```
Conditions:
- variableEquals{variable=[scope].[variablename];value="[a value]"}
- variableEquals{variable=target.somevariable;value="hello"} true

BearGrowl:
  TargetConditions:
  - variableEquals{var=target.heardbear;value="yes"} cancel
  Skills:
  - message{m="You hear a growling noise"}
  - setvariable{var=target.heardbear;value="yes";duration=6000}
```

### 新增：VariableIsSet {#new-variableisset}

如果变量已在目标作用域中设置，则返回 true。

1. variableIsSet{variable=[scope].[variablename]}
2. variableIsSet{variable=target.somevariable} true

### 新增：VariableInRange {#new-variableinrange}

如果变量位于给定范围内，则返回 true。仅适用于数值变量。

1. variableInRange{variable=[scope].[variablename];range=[range]}
2. variableInRange{variable=target.somevariable;range=>10} true

## 触发器 {#triggers}

### 新增：onDespawn {#new-ondespawn}

经过多年来大家的请求，我们终于找到办法添加一个像样的 ~onDespawn 触发器。每当生物因死亡以外的任何原因不再存在时，它都应当触发。

## 物品 {#items}

### NBT 支持 {#nbt-support}

- 现在可以按以下格式为物品指定 NBT 标签：

```
Item:
  Id: DIAMOND_SWORD
  NBT:
    Base:
      ATag: 20
      SomeOtherTag: something
    GemSlots:
      RedGem: 0
    'Denizen NBT':
      somedenizentag: a_string
```

这可以与许多其他插件联动，也可以仅用于存储一些自定义信息。

对于更熟悉技术的读者，'Base' 下的所有内容都会放入物品的基础复合标签中，其余内容则会放入对应的键下（如果未定义任何子项，则全部放入基础标签）。

如果配合 Denizen 使用，希望在 Denizen 中使用的所有标签都必须放在 'Denizen NBT' 下，且必须使用小写，才能在 Denizen 脚本中生效。

## 掉落表 {#drop-tables}

- 新增 "nothing" 掉落类型，方便使用加权掉落表
- 终于修复/实现了 BonusLevelItems 和 BonusLuckItems

**BonusLevelItems: [number]/[range]**

- 根据生物等级修正掉落物品数量
- 可以设置为范围，例如 0.2to0.5
- 计算方式：**amount = amount + (mob_level *
bonus_level_items)**
- 需要在掉落表中设置 **TotalItems**、**MinItems** 或 **MaxItems** 才会生效

**BonusLuckItems: [number]/[range]**

- 根据击杀者的幸运属性修正掉落物品数量
- 可以设置为范围，例如 0.15to8
- 适用于幸运属性、基于幸运的附魔/诅咒，以及幸运药水效果
- 计算方式：**amount = amount + (luck * bonus_luck_items)**
- 需要在掉落表中设置 **TotalItems**、**MinItems** 或 **MaxItems** 才会生效
