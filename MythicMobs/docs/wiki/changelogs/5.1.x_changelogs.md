# 5.1.X 更新记录

# 5.1.4 {#514}

## 技能机制 {#mechanics}

### 新增：SetRaiderPatrolLeader {#new-setraiderpatrolleader}

- 设置袭击者的巡逻队长状态
- setRaiderPatrolLeader{leader=true} @target

### 新增：SetRaiderPatrolBlock {#new-setraiderpatrolblock}

- 使目标袭击者前往给定位置巡逻
- setRaiderPatrolBlock @location

### 伤害类技能机制 {#damaging-mechanics}

- 修复了 `ignoreEnchants` 选项
- 新增 `FREEZE` 伤害原因
- 修复了 `preventKnockback` 对某些伤害原因返回未知伤害来源的问题
- 修复了 `preventImmunity` 选项未按预期工作的问题

## 条件 {#conditions}

### 新增：isPatrolLeader {#new-ispatrolleader}

- 检查目标实体是否为掠夺者小队的队长

## 问题修复与其他改动 {#bug-fixesother}

- 修复了 `preventStacking` 物品选项
- 修复了使用 openDoor、breakDoor、float 和 fleeSun AI 目标时的 AI 寻路
- 通过使 MythicHealMechanicEvent 仅在强制同步时运行，修复了异步调用该事件的错误
- 修复了 1.19 上的守卫者光束效果
- 修复了物品属性在 Spigot 服务器上不生效的问题
- 修复了服务器版本不受支持时 BukkitEntity#setCustomName 的一个问题
- 新增 `<caster.children.size>` 占位符，返回施法者当前拥有的子级数量
- 尝试修复 onDamage 光环的一些奇怪问题

# 5.1.2 {#512}

## 通用设置 {#general}

- 新增对 1.19.x 的支持
- 为元技能新增 `CancelIfNoTargets: false` 选项，即使 TargetConditions 筛掉所有可能目标，也会继续执行技能。
- 为世界等级缩放新增 `Base: [level]`、`ScaleVanillaMobs: true`、`BelowZero: [modifier]` 选项

## 生物 {#mobs}

- 为飞行生物新增 Options.FlyingSpeed
- 修复了属性的一些问题

## 技能机制 {#mechanics-2}

### 新增：ShowEntity {#new-showentity}

- 向目标玩家显示被隐藏的施法者
- `- showEntity{} @NearestPlayer{r=10}`

### 光环 {#auras}

- 修复了 doEndSkillOnTerminate=false 不生效的问题

### 伤害类技能机制 {#damaging-mechanics-2}

- 修复了 `ignoreenchants` 的拼写

## 条件 {#conditions-2}

### Altitude {#altitude}

- 改进了 altitude 条件，使其适用于下界和地下
- MaxHeight 选项现在默认设为 30

### BowTension {#bowtension}

- 修复了 bowtension 需要 mythiclib 方法的错误

## API {#api}

- 新增 MythicHealMechanicEvent
- 为 Pack API 新增几个方法
- 为 UUIDUtil、CompoundTag 和 CompoundTagBuilder 新增几个方法

## 问题修复与其他改动 {#bug-fixesother-2}

- 更新至最新版 adventure 快照
- 改进了技能日志记录
- 修复了 FillChest 机制导致的崩溃
- 为一些幽匿粒子增加了更多支持
- 修复了 BukkitEntity#getMaxHealth 获取错误数值的问题
- 修复了 stun 机制的问题
- 修复了 distance 条件中的 NPE
- 修复了 mount 机制相关的 NPE

# 5.1.1 {#511}

## 通用设置 {#general-2}

- 为 Raider 生物类型新增袭击者相关选项

## 技能机制 {#mechanics-3}

### 新增：EndProjectile {#new-endprojectile}

- 终止弹射物。仅可用于弹射物机制中。

### FillChest {#fillchest}

- 现在可以以其他容器为目标，不再仅限于箱子
- 新增 `shouldStack=true/false` 选项

### OnDamaged {#ondamaged}

- 修复了 ondmg 偏转未检查子碰撞箱的问题

### ParticleLine {#particleline}

- 为 particleline 效果新增 maxdistance（默认为 256）

### Projectile {#projectile}

- 为 Projectiles 新增 arrowType=NORMAL,SPECTRAL,TRIDENT
- 修复了弹射物最大持续时间
- 允许在弹射物命中条件中解析施法者占位符

### TakeItem {#takeitem}

- 现在可以以其他容器为目标，而不再仅限于玩家背包

## 条件 {#conditions-3}

### HasItem {#hasitem}

- 也可以检查其他容器

## API {#api-2}

- 为 SkillConditions 新增几个方法

## 问题修复与其他改动 {#bug-fixesother-3}

- 为使用 repeat 和 repeatInterval 选项的机制新增 <skill.var.interval> 或 <skill.var.itr>
- 修复了 MythicDungeons 世界卸载时的 NPE
- 修复了使用 teleport 机制时玩家未保持相同俯仰角/偏航角的问题
- 允许在物品 NBT 配置段中使用字符串列表
- 为物品属性配置段新增占位符支持
- 修复了刷怪点的 RadiusY 未保存的问题
- 为世界缩放配置新增 Base 等级选项
- 为自定义技能参数新增占位符支持

# 5.1.0 {#510}

## 通用设置 {#general-3}

- 新增对 1.19 的支持
- 新增 FROG、TADPOLE 和 WARDEN 生物类型
- 新增对粒子 SCULK_SOUL、SHRIEK、SCULK_CHARGE、SCULK_CHARGE_POPS 和 SONIC_BOOM 的支持
