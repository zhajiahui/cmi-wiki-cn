# 2.3.X 更新记录 {#23x-changelogs}

<http://www.mythicmobs.net/forum/viewtopic.php?f=1&t=916>

#### 随机生成 {#random-spawning}

随机刷怪点已重做，改用 MythicMobs 新增的系统生成刷怪位置，而不再使用原版生物的生成位置。此改动仅适用于 **Action: ADD**，**Action: REPLACE** 将继续按旧方式运行。

所有在随机生成中使用 **Action: ADD** 的生物，现在都有机会在任意玩家附近一定半径内的随机位置生成。此功能可进行多项配置，包括每位玩家每秒生成的位置数、玩家附近的生成半径、Y 轴半径、最小距离，以及此前可用的全部条件。系统还包含限制每个区块生物数量的设置。

`If the new ADD-action doesn't work for you after updating to 2.3, add this random spawn to your server and it will be fixed: http://hastebin.com/enumubotox.apache . This bug has been fixed in the upcoming (2.4) MythicMobs release.`

这对你意味着什么？这意味着随机生成也可以发生在有照明的区域，而不再仅限于原版生物能够生成的地方。

此系统异步运行，因此多核服务器使用它不会有任何性能损失。对于单核服务器，将提供一个选项，可在需要时关闭新的位置生成器，改用旧系统。

相关 config.yml 选项：

```
RandomSpawning:
  GenerateSpawnPoints: false
  MaxMobsPerChunk: 80
  SpawnRadiusPerPlayer: 64
  SpawnRadiusPerPlayerY: 32
  DespawnLazyRandomMobs: true
  PointsPerSecond:
    Land: 10
    Air: 0
    Sea: 0
    Lava: 0
    Ground: 0
```

##### 向后兼容问题 {#backwards-compatibility-issues}

在此次更新之前创建、使用 **Action: ADD** 的所有随机刷怪点，都将不再仅于“低亮度”区域生成生物。如果需要生物继续遵循该行为，就需要为这些生成配置添加 lightlevel 条件。

#### 生物类型与等级 {#mob-type-level}

现在使用记分板存储生物类型和等级（如果你关心具体细节，所用计分项为 "MythicMobType" 和 "MythicMobLevel"）。这使我们在使用 **Despawn: False** 时，能在重启前后更准确地保留生物类型和等级，尤其适用于以狼为基础创建可升级的自定义宠物。

这也意味着不再要求生物具有显示名称。

#### Signal 技能与触发器 {#signal-skill-trigger}

##### 新增：Signal {#new-signal}

- [Signal 手册页面](../skills/mechanics/signal.md)

此次更新包含一套名为“信号”的强大新工具。借助信号技能和触发器，现在可以轻松在生物之间传递消息。实现起来非常简单：

```
BossMob:
  Skills:
  - signal{signal=healme} @MobsInRadius{type=HealerMob;r=20}

HealerMob:
  Skills:
  - skill{skill=healyskill} @trigger ~onSignal:healme
```

你甚至可以使用命令向生物发送信号！

```
/mm signal <UUID> <signal>
```

还有一个方便的 "lastsignal" 条件，可用于读取生物最后收到的信号。如果未在 ~onSignal 触发器中指定信号，它会被*任意*信号触发，随后便可使用该条件进行筛选。

#### 变量 {#variables}

- 新增 <random.min-max> 变量，会被替换为给定范围内的随机数。
- 新增 <mob.owner.name> 变量，返回狼主人的名称。
- 新增 <mob.owner.uuid> 变量，返回狼主人的 uuid。
- 新增 <mob.score.objective> 变量，返回施法生物在给定计分项中的分数。
  - 例如，<mob.score.hits> 会返回生物在 "hits" 计分项中的分数
- 新增 <target.score.objective> 变量，返回目标选择器所选目标在给定计分项中的分数。
  - 例如，<target.score.kills> 会返回 @targeters 在 "kills" 计分项中的分数
- 新增 <trigger.score.objective> 变量，返回技能触发者在给定计分项中的分数。
- 新增 <global.score.objective> 变量，返回全局对象在给定计分项中的分数。
- 新增 <score.objective.dummyname> 变量，返回指定虚拟名称在给定计分项中的分数。
  - 例如，<score.deaths.fakeplayer> 会返回 "fakeplayer" 在 "deaths" 计分项中的分数

#### 问题修复与其他改动 {#bugs-other}

- 将更多技能改为始终同步运行，从而修复了自 2.2 版本起出现的所有异步错误。
- 如果仍然发现任何异步相关问题，**一定**要报告！
- 刷怪点现在将牵引位置设在方块中心，而不是角落
- 修复了控制台中随机抛出的多个异步错误
- 修复了 Projectile 技能中的 NPE
- 修复了 missile 的 inertia 属性中的拼写错误
- 修复了狼被驯服后丢失属性的问题
- 修复了伪装中的马铠问题
- 移除了手动垃圾回收，以提升性能
