# 4.1.X 更新记录

# 4.1.0 {#410}

## 新增功能：HealthBars {#new-feature-healthbars}

MythicMobs 现在支持添加显示在生物名称下方的全息生命条！此功能使用起来很简单。

```
Mob:
  Type: SPIDER
  Display: 'HealthBar Spider'
  HealthBar:
    Enabled: true
    Offset: 1.45 # Height value, can be negative
```

此功能需要 Holograms 插件：
<https://www.spigotmc.org/resources/holograms.4924/>

## 新增功能：Nameplates {#new-feature-nameplates}

名称牌允许扩展玩家伪装生物的名称牌，其通常限制为 16 个字符。要使用此功能，只需安装 Holograms，然后省略伪装中的 "Player" 字段（仍然需要皮肤！）。未指定玩家字段时，它会改用 Display 字段，通过自定义名称牌显示。

```
Monkey:
  Type: skeleton
  Display: "this display name is too long for players normally"
  Disguise:
    Type: player
    Skin: Kurdie
```

此功能需要 LibsDisguises 和 Holograms 插件：
<https://www.spigotmc.org/resources/holograms.4924/>

## 技能机制 {#mechanics}

### 新增：ConsumeHeldItem {#new-consumehelditem}

消耗玩家手持物品中的 # 个。可用于在 Artifacts 附加插件中制作消耗品。

1. consumeHeldItem{amount=1} @trigger

### 新增：Decapitate {#new-decapitate}

掉落目标玩家的头颅。目前仅适用于玩家。

### 新增：GiveCurrency {#new-givecurrency}

给予目标玩家 X 数量的 Vault 货币。需要 Vault 和一个经济插件。

1. giveCurrency{amount=#} @target

### 新增：Glow 效果 {#new-glow-effect}

使目标获得指定颜色的发光效果，持续 # 刻。需要 GlowAPI。

1. effect:glow{color=RED;duration=1000}

### 新增：PercentDamage {#new-percentdamage}

造成相当于玩家最大生命值一定百分比的伤害，其中 1 代表 100%。具有与 Damage 机制相同的选项。

1. percentDamage{percent=0.5}

### 粒子效果 {#particle-effects}

- 为 Particles 新增 **directional** 和 **directionReversed** 选项
- 使某些粒子以 # 速度移动
- 方向基于从原点位置指向目标位置的方向。

### SetOwner {#setowner}

- 如果施法者是狼，现在会将狼的所有权给予目标

### 已修复的技能机制 {#fixed-mechanics}

- 使 ShootFireball、ShootPotion、ShootSkull 可用于位置目标选择器
- 修复了 Projectiles 的 forwardOffset

## 条件 {#conditions}

### 新增：Mounted {#new-mounted}

### 新增：MythicMobType {#new-mythicmobtype}

### 新增：HasCurrency {#new-hascurrency}

如果玩家拥有 X 数量的 Vault 货币，则返回 true。需要 Vault 和一个经济插件。

1. hascurrency <amount>

### 新增：HasInventorySpace {#new-hasinventoryspace}

### 新增：HasPermission {#new-haspermission}

如果玩家拥有 X 权限，则返回 true。

1. haspermission <permission>

### 新增：TCBiome {#new-tcbiome}

如果位置符合指定的 TerrainControl 生物群系，则返回 true。可以进行宽松或严格匹配（默认为宽松匹配）。

1. tcbiome Forest *（匹配名称中包含 FOREST 的任意 TerrainControl 生物群系）*
2. tcbiome{biome=TropicalDesert;strict=true} *仅匹配 TropicalDesert，不匹配 TropicalDesertBorder*

### 已修复的条件 {#fixed-conditions}

修复了在 4.0 中未正确迁移的条件，包括：

- PlayerWithin
- PlayerNotWithin
- TargetWithin
- TargetNotWithin
