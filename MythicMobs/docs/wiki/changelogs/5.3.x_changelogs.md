# 5.3.X 更新记录

# 5.3.1+ {#531}

## 通用设置 {#general}

- 为弹射物子弹新增 bulletForwardOffset，默认为 2.5
- 为子弹新增 `bulletOffset` 选项（默认为 1.8）

## 问题修复与其他改动 {#bugs-other}

- 为 teleport 机制新增占位符支持
- 修复了 1.18 上的加载问题
- 修复了 DamagingMechanics 中的 NPE
- 修复了转移伤害未包含修正伤害的问题
- 修复了 strEquals 条件使用施法者占位符时的错误，关闭 #1185
- 修复了 blockType 和 blockIgnore 目标选择器筛选器在未设置数量限制时不生效的问题，关闭 #1182
- 修复了仇恨表以同阵营玩家为目标的问题
- 修复了 `setVariableLocation` 机制对非实体目标不生效的问题
- 修复了 onDamaged 光环中不合理的错误
- 修复了启用 highAccuracy 后 hugSurface 弹射物失效的问题
- 修复了 blockmask 失效的问题
- 修复了 score 机制的占位符支持
- 修复了启用 PassthroughDamage 时 suicide 机制不生效的问题
- 修复了 PassthroughDamage 对某些伤害类型不生效的问题
- 修复了 asParent、asOwner、asTrigger 目标修饰器的几个问题
- 修复了某些光环配置导致的内存泄漏

### 复合条件 {#composite-conditions}

新增复合条件。技能中的条件现在可以用括号分组，使用 AND（&&）和 OR（||）运算符组合，也可嵌套以实现复杂逻辑。整组条件将一起判断。

```
Conditions:
- ((night || raining) && onBlock{material=LIME_CONCRETE}) true
```

### Projectile {#projectile}

- 新增 `DISPLAY` 和 `TEXT` 子弹类型

  - 文本子弹：`- projectile{bullet=TEXT;bulletText="...";bulletBillboard=CENTER;backgroundColor=64,0,0,0}`
- 允许盔甲架和展示实体弹射物进行 3D 旋转：

  - pitch - 俯仰旋转角度 <0>
  - yaw - 偏航旋转角度 <0>
  - roll - 横滚旋转角度 <0>
  - rotation | rot - 多边形的旋转，使用 x,y,z 格式 <0,0,0>（pitch/yaw/roll 的紧凑写法）
  - pitchSpeed|ps & yawSpeed|ys & rollSpeed|rs & rotationSpeed|rots，与前述选项相同，但用于为旋转添加速度
- 新增选项 `highAccuracyMode=[true/false]` - 如果为 true，弹射物会使用射线检测判断是否命中方块，而不是常规检查，使高速弹射物不会穿过方块。
- 新增选项 `requireLineOfSight=[true/false]` - 如果为 true，在应用各项选项后，弹射物会立即命中其原点到“起始点”之间任何阻挡视线的对象
- 新增选项 `drawHitbox=true` - 在弹射物周围用粒子绘制其实体检测碰撞箱，便于调整。
- 为所有盔甲架/物品展示/物品子弹新增选项 `bulletEnchanted`/`enchanted`
