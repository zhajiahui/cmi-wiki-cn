## 条件 {#conditions}

### 新增：Cuboid {#new-cuboid}

检查目标实体是否位于由 location1 和 location2 表示的指定长方体内。

- - cuboid{location1=x,y,z;location2=x,y,z;world=world}

### 新增：LastDamageCause {#new-lastdamagecause}

检查实体最近一次受伤的原因

```
Conditions:
- lastdamagecause ENTITY_ATTACK
```

<https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/event/entity/EntityDamageEvent.DamageCause.html>

### 新增：Pitch {#new-pitch}

检查目标实体的俯仰角

```
TargetConditions:
- pitch 20to40
- pitch <100
```

### 新增：Wearing {#new-wearing}

检查活体实体的盔甲槽位中是否有普通物品或 Mythic 物品的条件

```
TargetConditions:
- wearing{slot=helmet;material=DIAMOND_HELMET} true
- wearing{slot=chestplate;mmitem=AnItem}
```

槽位为 helmet、chestplate、leggings 和 boots

### 新增：Yaw {#new-yaw}

检查目标实体的偏航角

```
TargetConditions:
- yaw >50
- yaw 50to100
```

### 通用设置 {#general-3}

### 目标数量限制 {#target-limits}

所有实体目标选择器现在都支持目标数量限制。你可以借此限制选取的对象数量，也可以指定选取顺序。

通过以下选项设置：

- limit=#
- sort=X

假设你希望技能只选取 30 码以内最近的 2 名玩家。只需将限制设为 2，并按最近距离排序：

- **@PlayersInRadius{r=30;limit=2;sort=NEAREST}**

目前 sort 可以使用以下值：

- NONE *（通常按实体已存在的时间排序）*
- RANDOM
- NEAREST
- FURTHEST
