### 村民交易 {#villager-trades}

现在可以配置村民交易！请注意，村民必须具有特定职业才能交易，某些物品可能要求村民达到特定等级。

```
MerchantTest:
  Type: VILLAGER
  Display: '&6Merchant Test'
  Health: 20
  Faction: tester 
  Options:
    Profession: NITWIT
    Type: DESERT
    Level: 2
  Trades:
    1:
      Item1: 5 EMERALD
      Item2: 5 DIAMOND
      Result: DIAMOND_SWORD
      MaxUses: 5
    2:
      Item1: 64 EMERALD
      Result: SkeletonKingSword
      MaxUses: 1
```

### 新增：Chain {#new-chain}

这让你可以制作在目标之间弹跳的技能，例如“闪电链”类技能。每次技能“弹跳”后，都会判断 BounceConditions。在示例中，如果某人与生物之间隔着一堵墙，而你站在门口，技能就可以从你弹跳到那个人身上，因为它通过弹跳绕过了墙。每次施放只会弹跳到同一实体一次。另外，技能每次弹跳时，弹跳起点的实体都会成为该技能的“原点”，而 onBounce 继承的目标则是下一次弹跳要到达的实体，因此制作效果时 fromOrigin 很有用！示例：

1. chain{

```
    bounces=5;
    bounceRadius=10;
    bounceDelay=1;
    hitSelf=false;
    hitPlayers=true;
    hitNonPlayers=true;
    hitTarget=true;
    onBounce=[
      - effect:particleline{p=flame;fromOrigin=true}
    ];
    bounceConditions=[
      - inlineofsight
      - hasaura{aura=damageResist} false
    ];
  } @target ~onTimer:20
```

### Damage {#damage}

- 新增 damageType 选项，可以设为任意所需值
- 可以在 DamageModifiers 和 onDamaged 光环中使用自行定义的任何自定义 damageTypes

以下是一些实际使用示例：

1. damage{amount=10;element=FIRE} @target ~onUse
2. damage{amount=10;element=ICE} @target ~onUse

   DamageModTest:
Type: COW
DamageModifiers:

   - LIGHTNING 0.1
   - FIRE 2.0
   - AIR 1.0
   - ICE 0.5
Skills:
   - message{m="Damaged by <skill.var.damage-type> for <skill.var.damage-amount>"} @PIR{r=50} ~onDamaged

### onDamaged {#ondamaged}

- 新增 **damageMods** 选项，可创建应用伤害修正的光环。
- 也可以指定在 damage 机制中使用的自定义 damageMods

```
  - onDamaged{
      auraName=damageResist;d=200;
      onTick=[
        - particles{p=flame;amount=10;hS=0.4}
      ];
      damageMods="FIRE 0.5"} @self ~onInteract
```

## AI 行为与目标 {#ai-goalstargets}

### 新增：NearestConditionalTarget {#new-nearestconditionaltarget}

一种仅限付费版的 AI 目标选择器，使生物攻击附近任何满足所给条件的实体。示例：

```
AITargetSelectors:
- clear
- nearestConditionalTarget{conditions=[
      - entitytype PLAYER
      - hasaura{aura=marked_for_death}
    ]}
```

### 新增：FleeConditional {#new-fleeconditional}

一种仅限付费版的 AI 目标，使生物逃离附近任何满足所给条件的实体。示例：

```
AIGoalSelectors:
- clear
- fleeConditional{distance=5; speed=2; conditions=[
      - inlineofsight
      - entitytype COW
    ]}
```
