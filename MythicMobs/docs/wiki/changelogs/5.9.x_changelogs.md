# 5.9.X 更新记录

# 5.9.5 {#595}

## 问题修复 {#bug-fixes}

- 更新部分依赖。
- 修复带属性的物品在本应堆叠时无法堆叠的问题。
- 修复部分耐久度相关功能未使用新耐久度组件数据的问题。
- 修复等级修正中的部分错误。
- 修复较新版本中后坐力效果的多个问题。
- 修复眩晕机制的 freezeFacing 选项效果反转的问题。

# 5.9.4 {#594}

## 问题修复 {#bug-fixes-2}

- 为 raytraceTo 机制添加 `ignoreEntities`。
- 修复射线追踪机制中 `ignorePassable=false` 仍会穿过屏障方块的问题。

# 5.9.3 {#593}

## 问题修复 {#bug-fixes-3}

- 修复 ignoreSameFaction 目标过滤器的部分问题。

# 5.9.2 {#592}

## 通用设置 {#general}

- 为 `GoToOwner/Parent` AI 目标添加 `teleportToWorld=true/false`。
- 为 runaitargetselector 添加“goal/g”别名，使其与错误消息一致。
- 添加 `%mythic_stat_...%` PAPI 占位符。
- 添加 `<target.distanceSq>` 和 `<trigger.distanceSq>` 占位符。

## 条件 {#conditions}

### 新增：CompareValues {#new-comparevalues}

## 问题修复 {#bug-fixes-4}

- 修复 suicide 机制未将生物视为对自身造成伤害的问题，关闭 #1584。
- 修复较新版本中对话气泡的 yaw/pitch 颠倒问题。
- 可能修复了 MountMe 机制。
- 修复配置物品 NBT 时 MapList 元素不生效的问题。
- 修复原版战利品表掉落中的 IllegalArgumentException，关闭 #1949。
- 修复复制刷怪笼时生物类型相关的错误，关闭 #1951。
- 修复 shield 机制中的错误，关闭 #1955。
- 修复 `<skill.targets>` 占位符中的 NPE，关闭 #1961。
- 修复 1.21.4 上的 ClientboundSetEntityDataPacket 错误。
- 修复 PermissionFactionProvider 将 OP 加入所有阵营的问题。
- 修复非英语服务器上的 StackOverflowError。
- 修复菜单图标配置错误时插件无法加载的问题。

# 5.9.1 {#591}

## 问题修复 {#bug-fixes-5}

- 修复 VariableMath 机制不支持 double 变量的问题。
- 修复 ItemMatcher 的部分错误。
- 修复 moveTowardsTargetConditional AI 目标。
- 修复弹射物反弹。
- 修复弹射物的其他多个问题。

- 修复 1.21.5 上的射线追踪错误。
- 修复自定义伤害属性不触发 onDamaged 光环的问题。
- 修复弹射物的 `hitself` 不生效的问题。

# 5.9.0 {#590}

## 通用设置 {#general-2}

- 添加 `/pins regionRedefine` 命令。
- 将包图标改为使用 Mythic 物品语法。
- 缩放方程和 `LevelModifiers` 现在可用于任意属性。
- 为所有数值占位符添加 step 和 lerp 函数。

```
step(e, x) { 0, x < e; 1, x >= e
lerp(a, b, r)
```

## 技能机制 {#mechanics}

### 新增：swingOffhand {#new-swingoffhand}

- 添加 `swingOffhand` 机制。

### 新增：setEntityPose {#new-setentitypose}

- 添加 `setEntityPose{pose=X}` 机制。

### 新增：setItemGroupCooldown {#new-setitemgroupcooldown}

- 添加 `setItemGroupCooldown{group=namespace:key;ticks=20}` 机制。

### Hit {#hit}

- 为 hit 机制添加 `scaleByAttackCooldown`（根据武器攻击冷却缩放伤害）。

### Leap {#leap}

- `Leap` 机制的 Noise 现在默认为 `0`。

### MetaSkill {#metaskill}

- 为 `MetaSkill` 机制添加 `snapshotStats=true`。

### Missile {#missile}

- 为 `missile` 机制添加 `startWithParentVelocity` 选项。

### 投射物 {#projectiles}

- 为弹射物类机制添加 HitTargeter。

hitTarget htr 接受实体目标选择器。htr 选中的实体会经过 onHit 处理，并获得免疫延迟。

### Slash {#slash}

- 为 SlashMechanic 添加 `specificStep/ss`。

### Totem {#totem}

- 为 Totem 机制添加 `faceAwayFromCaster=true` 选项。
- 为 Totem 机制添加 `hugSurface=true` 选项。

### Wait {#wait}

- 新增特殊关键字机制 `wait`。
- 暂停技能树，直到满足条件。

## 条件 {#conditions-2}

### 新增：itemGroupOnCooldown {#new-itemgrouponcooldown}

- 添加 `itemGroupOnCooldown{group=namespace:key}` 条件。

### 新增：服务器版本条件 {#new-server-version-conditions}

- 添加 `serverAfter{version=1.21.4;inclusive=true}`、`serverBefore{version=1.21.4;inclusive=false}` 和 `serverIsPaper` 条件。

### Stance {#stance}

- 将 `stance` 条件的 `strict` 默认值改为 `true`。

## 目标选择器 {#targeters}

- 修复 `@FloorOfTarget` 目标选择器的多个错误。
- 将位置选择器选项的默认值改为 `faulty=false`。
- 为 `@RingAroundOrigin` 目标选择器添加 `relative=true/false`。

### 新增：`@PlayerLocationByName` {#new-at-playerlocationbyname}

### 新增：`@PredictedTargetLocation` {#new-at-predictedtargetlocation}

`@PredictedTargetLocation{ticks=X}`

- 根据施法者目标的速度，选取它在未来 X 刻后的预测位置。

## 触发器 {#triggers}

- 将 `onTridentHit` 重命名为 `onProjectileHit`，将 `onTridentThrow` 重命名为 `onProjectileThrow`。
- 添加 `onProjectileLand` 触发器。

## 占位符 {#placeholders}

### 新增：距离占位符 {#new-distance-placeholders}

- 添加 `<target.distance>` 和 `<trigger.distance>` 占位符。

### 新增：Unix 时间戳占位符 {#new-epoch-placeholders}

- 添加 `<utils.epoch>`、`<utils.epoch.millis>` 和 `<utils.epoch.ticks>` 占位符。

## 物品 {#items}

### 原版战利品表掉落 {#vanilla-loot-table-drop}

- 新增掉落类型 `- vanillaLootTable minecraft:table_name`，用于从原版战利品表和数据包中掉落物品。

### BlockStates 组件 {#blockstates-component}

- 添加对 `BlockStates` 组件的支持，用于在物品上指定方块状态：

  ```yaml
  TestBlockStates:
    Material: OAK_SLAB
    Display: 'Waterlogged Slab'
    Options.Placeable: true
    BlockStates:
    - type top
    - waterlogged true
  ```

### Glider 组件 {#glider-component}

- 为物品添加 `Glider: true` 选项，以使用 Glider 组件。

### UUID 与时间戳选项 {#uuid-timestamp-options}

- 添加 `Options.GenerateUUID: true/false` 和 `Options.GenerateTimestamp: true/false`，在生成物品时赋予 UUID 或时间戳。

## API {#api}

### 新增：事件方法 {#new-event-methods}

- 公开事件方法。
- 添加 `MythicSkillEvent`，在调用技能时触发。

### 新增：Crucible 与 RPG API {#new-crucible-rpg-api}

- 公开 Crucible 和 RPG 功能的 API。

### 新增：数据包展示实体 API {#new-packet-display-entities-api}

- 公开更多基于数据包的展示实体 API 方法。

### 新增：仇恨表 API {#new-threat-table-api}

- 公开威胁表映射。

### 已移除：已弃用的装备槽位写法 {#removed-deprecated-equipment-slot-method}

- 移除早已弃用的、按槽位编号引用装备槽的方法。

### AI 行为 {#ai-goals}

- 升级 `ownerTarget` 和 `ownerAttacker` AI 目标，使任意生物都能使用；添加 `parentAttacker` 和 `parentTarget` AI 目标。
- 重构所有者接口以保持一致。
