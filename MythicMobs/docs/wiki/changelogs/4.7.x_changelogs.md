### 元技能改进 {#better-metaskills}

元技能现在可以在许多地方以行内形式编写，无需引用另一个技能。这意味着，使用弹射物等某些复杂元技能时，不再需要创建多个小技能。

做法是创建一个用方括号 [] 括起的新机制列表，代替技能名称。这样几乎可以无限嵌套技能。每个新的技能列表都应正确缩进，以确保 YAML 能正确读取。

```
Skills:
- projectile{
      interval=1; velocity=30; bulletType=BLOCK; material=MAGMA_BLOCK; tyo=0.5; g=1; bulletSpin=-40; hnp=true; stopatentity=false; duration=100;
      onHit=[
          - damage{amount=50}
          - ignite{ticks=20}
      ];
      onTick=[
          - particles{p=flame;a=20;hs=0.5;vs=0.5}
      ];
      onEnd=[
          - particles{p=largeexplode;a=50;speed=1;hs=0.05;vs=0.05}
          - effect:sound{s=entity.dragon_fireball.explode;p=0.6;v=2}
          - damage{amount=30} @ENO{r=5}
      ];
  } @targetlocation
```

### 数学运算与占位符 {#mathplaceholders}

**此功能仅限付费版**。现在可以在许多地方使用数学运算和数值占位符！我们计划将其扩展到任何地方，但这项工程很大。在支持数学运算的地方，只需在原本填写数值的位置，将占位符和表达式放在 '' 之间。例如：

```
Skills:
- damage{amount=1}
- damage{amount='5 + 5'}
- damage{amount='<caster.level> * 10'}
```

以此类推。目前以下机制可以使用数学运算：

- **damage**
- **damagePercent**
- **heal**
- **healPercent**
- **setLevel**

数学运算也可以用于掉落数量：

```
Drops:
- gold_nugget '1 + (0.2 * <caster.level>)'
```

### 投射物弹体 {#projectile-bullets}

弹射物机制现在可以指定子弹类型，用来呈现弹射物。弹射物不再仅限于粒子！这些类型适用于 projectile、missile 和 orbital 机制。可用的子弹类型有：

- **ARROW** - *projectile{bulletType=ARROW;...}*
- **BLOCK** - *projectile{bulletType=BLOCK;material=STONE;...}*
- **ITEM** - *projectile{bulletType=ITEM;material=STONE;...}*
- **MOB** - *projectile{bulletType=MOB;mob=SkeletonKing;...}*

没错，你甚至可以发射由其他 Mythic 生物组成的弹射物！通过弹射物技能发射的生物无法被交互，但仍会使用其全部技能……也可以使用新的 **bulletSpin=#** 选项让子弹旋转。

## 技能机制 {#mechanics}

### 新增：onShoot {#new-onshoot}

一种特殊的光环机制，为目标临时添加 onShoot 技能。

```
Skills:
- onShoot{auraName=fireball_bow;onShoot=[ shootfireball ];duration=200;charges=5} @self
```

在此示例中，施法者接下来的 5 次射箭会发射火球，而不是箭。

### 新增：Speak {#new-speak}

Speak 类似 message 技能，但用于让生物“说话”。生物会按配置的格式在聊天栏发言，如果安装了全息显示插件，还会出现对话气泡！

```
 - speak{m="OH BOY I HAVE SPEECH BUBBLES NOW"} @trigger ~onInteract
 - speak{m="OW THAT HURTS I CANT BELIEVE YOU WOULD HIT AN INNOCENT MAN"} @trigger ~onDamaged 
```
