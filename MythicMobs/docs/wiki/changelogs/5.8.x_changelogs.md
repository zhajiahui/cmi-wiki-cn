- 修复了弹射物上的 HitTargeter
- 修复了自几次更新前开始，一些自定义 AI 目标未加载的问题

- 修复了粒子在 1.20.X 版本上抛出错误的问题

- 修复了 MountTarget 机制在较新版本上失效的问题

- 修复了 FancyDrops 的伤害计算和排行榜将已取消的伤害计入的问题
- 修复了死亡排行榜未向所有参与玩家显示的情况
- 修复了 terminated 引用总是被克隆的问题
- 修复了 varequal 和 varrange 未使用技能元数据的问题
- 修复了属性在启动时未使用基础值的问题
- 修复了 varinRange 条件作为 TargetCondition 时无法引用技能变量的问题
- 修复了 @ThreatTablePlayers 目标选择器中的 NPE

# 5.8.0 {#580}

**注意：此次更新包含多项优化、新机制、改进、问题修复和新增 API 功能。发现任何问题时，请创建 Issue，或在适当的 Discord 频道告知我们。**

**`Note: This update includes various optimizations, new mechanics, improvements, bug fixes, and additional API features. Please report any issues you find by opening an Issue or letting us know in the appropriate Discord channel.`**

## 通用设置 {#general-2}

- 新增对 1.21.3 和 1.21.4 的支持
- 进行了大量细微的性能优化（感谢 Taiyou！）
- 新增 `Configuration.General.AnnounceOpReload`，位于 `config-general.yml` 中，用于设置是否向所有在线管理员发送 Mythic 重载公告。
- 优化了多个弹射物/实体选择机制，并移除了关键部分的流式操作使用（例如 `IEntitySelector`、`PacketEntityRenderer`）。
- 新增一个全局选项，可自动为所有物品应用 FancyDrops（默认禁用）。
- 新增 `/mm m spawn [type] [amount] @targeter` 命令。

## 随机生成 {#random-spawning}

- **带权重的多个生物**：现在可以在随机刷怪点条目中指定多个生物，并为其设置权重，例如：

  ```yaml
  Deeps:
    Types:
    - RegularZombie 100
    - BigZombie 50
    - GiantZombie 5
    Worlds: world
    Chance: 0.1
    Priority: 1
    Action: ADD
    PositionType: LAND
  ```
- **结构支持**：新增 `Structures:` 列表选项，可将随机刷怪点限制为仅在特定结构中生成生物：

  ```yaml
  Nether_Fortress:
    Types:
    - blaze_wisp 100
    Worlds: world_nether
    Chance: 0.02
    Priority: 1
    Action: ADD
    PositionType: LAND
    Structures:
    - 'minecraft:fortress'
    - 'incendium:forbidden_castle'
  ```
- **新增配置选项**：
  - `RandomSpawning.MaxGenerationAttempts` 用于限制集群生成器生成时的尝试次数。
  - `RandomSpawning.LocalSpawningLimit`，以及单个随机刷怪点上新增的 `MaxLocalMobs` 选项，用于覆盖局部数量限制。
- **重命名**：旧的 `GroupMultiplier` 选项现在改为 `LocalGroupMultiplier`，位于 `config-spawning.yml` 中，其默认值逻辑也已改变。
- 对集群生成和结构检测逻辑进行了多项改进。

## 生物 {#mobs}

- 将狼、猫、青蛙、村民等的变种选项统一为 `Options.Variant`，允许使用自定义变种。
- 新增配置**自定义生物刷怪笼物品**的功能，包括设置生成延迟、生成范围等。
- 新增狼专用的 `Options.Variant`，用于自定义狼变种。

## 技能机制 {#mechanics}

### `NEW: followPath` {#new-followpath}

- 一种使目标生物沿指定路径行走的光环。

### `NEW: log` {#new-log}

- `log{message="Debug to console with variables <caster.var.test>"}`，用于简单的日志记录。

### `NEW: setTextDisplay` {#new-settextdisplay}

- `setTextDisplay{text="text here"} @Target` 机制，用于显示文本。

### `NEW: openTrades` {#new-opentrades}

- 为目标玩家打开商人交易界面。
  - `realTrade/real` 属性决定是否与实际村民进行交易。

### `NEW: movePin` {#new-movepin}

- `movePin{pin=X}` 机制，用于移动位置标记。

### `NEW: directionalVelocity` {#new-directionalvelocity}

- `directionalVelocity{yaw=50}` 根据指定角度为目标施加速度。

### `NEW: rotateTowards` {#new-rotatetowards}

- 使施法者转向目标。

### `NEW: setChunkForceLoaded` {#new-setchunkforceloaded}

- 强制加载目标位置的区块。

### `NEW: resetAI` {#new-resetai}

- 将生物的 AI 恢复为出厂默认设置。

### `NEW: matchRotation` {#new-matchrotation}

- `matchRotation{of=@targeter}`，用于匹配给定目标的旋转。

### `NEW: clearExperience` {#new-clearexperience}

- 重置玩家的经验值。

### `NEW: setProjectileDirection` {#new-setprojectiledirection}

- `setProjectileDirection{magnitude=1}`，用于控制弹射物方向。

### `NEW: lookAtTarget` {#new-lookattarget}

- 一种使生物看向当前目标的 AI 目标。

### `UPDATED: dropItem` {#updated-dropitem}

- 现在包含一个以掉落物品为目标的 `then=` 技能配置段。

### `UPDATED: setSpeed` {#updated-setspeed}

- 遵循配置的移动速度；如果未设置，则默认使用生物的基础速度。

### `UPDATED: consumeSlotItem` {#updated-consumeslotitem}

- 正确移除数量为 `0` 的物品。

### `UPDATED: shoot` {#updated-shoot}

- 现在支持通过 `item=<material>` 指定自定义弹射物（例如 `item=REDSTONE`）。

### `UPDATED: particleOrbital` {#updated-particleorbital}

- 在施法者死亡/自然消失后终止，并支持为 `ticks` 使用占位符。

### `recoil` {#recoil}

- 修复了 1.21+ 上的后坐力；后坐力数值可使用占位符。

## 条件 {#conditions}

### `NEW: boundingBoxesOverlap` {#new-boundingboxesoverlap}

- 检查包围盒是否重叠。

### `NEW: distanceFromPin` {#new-distancefrompin}

- `distanceFromPin{pin=X;distance=<5}` 条件。

### `NEW: distanceFromLocation` {#new-distancefromlocation}

- `distanceFromLocation{x=...;y=...;z=...;distance=...;world=...}` 条件。

### `NEW: PlaceholderBoolean` {#new-placeholderboolean}

- 如果变量为 'true' 或 '1'，则为 true，否则为 false。

### `NEW: originDistanceFromPin` {#new-origindistancefrompin}

- 检查与指定位置标记的距离。

### `NEW: stringEmpty / stringNotEmpty` {#new-stringempty-stringnotempty}

- 检查字符串是否为空。

### `lookAt` {#lookat}

- 现在具有 `distance`/`d` 属性（默认为 5），用于检查生物是否正看向该距离内的目标。

## 目标选择器 {#targeters}

### `NEW: @BlocksInPinRegion` {#new-at-blocksinpinregion}

- 以位置标记定义的区域内的方块为目标。

### `NEW: @HighestBlock` {#new-at-highestblock}

- 以原点所在位置的最高方块为目标。

### `NEW: @TrackedPlayers` {#new-at-trackedplayers}

- 以当前正在渲染或追踪该生物的玩家为目标。

### `NEW: @ChunksinWERegion` {#new-at-chunksinweregion}

- `@ChunksinWERegion{region=X}` 目标选择器。

### `NEW: @PNO` {#new-at-pno}

- `PlayersNearOrigin` 的别名。

### `NEW: @OwnerLocation` {#new-at-ownerlocation}

- 以已驯服实体的主人位置为目标。

### `NEW: @ParentLocation` {#new-at-parentlocation}

- 以父级位置为目标。

### `NEW: @WolfOwner` {#new-at-wolfowner}

- 重新添加了选取已驯服狼的主人的目标选择器。

### `skipTargetsUpToIndex` {#skiptargetsuptoindex}

- 让目标选择器跳过前 N 个匹配目标。

### `@ObstructingBlock` {#at-obstructingblock}

- 已重写，以提升性能。

### `mobsInRadius` {#mobsinradius}

- 现在可正确检测原版生物类型。### 占位符
- 为 `random.float` 占位符新增舍入支持，使用语法 `<random.float.1to5{round=2}>`。
- 新增数学函数：`todegree(value)`、`toradian(value)` 和 `clamp(value,min,max)`。
- **新增：**`caster.attack_cooldown` 占位符，用于原版挥击冷却。

## 物品 {#items}

- 新增 `Options.Glint: true`，用于添加附魔光效。
- 新增 Mythic 颜色选择器，用于自定义物品的颜色相关属性。
- 为花式掉落新增 `vfxmodel/vfxitemmodel` 支持，使用 1.21.3+ 物品模型。
- 新增 `namespace:enchant_name` 支持，供 `Enchantments` 选项使用。
- 为所有物品条件/机制新增 `strict=true`，防止将 Mythic 物品与原版物品匹配。
- 扩展了 `Equippable` 组件，以支持更多字段。
- 新增 `#tag` 和 `*wildcard` 支持，供 `itemType` 条件使用。
- 新增 `Tool` 和 `UseCooldown` 子组件，以提供更多物品自定义功能。
- 调整了物品组件的顺序，使 `TooltipStyle` 最后加载。

### 新增：用于高级物品提示的 `TooltipStyle` 组件。 {#new-tooltipstyle-component-for-advanced-item-tooltips}

## API {#api}

- 重构了 `EquipSlots`，以支持自定义槽位。
- 新增用于转储物品组件数据的 API 方法（例如 `DropTable.usesWeights()`、`DropTable.GetDrops()`）。
- 新增 API 条件类型 `ISkillMetaLocationComparisonCondition`。
- 通过 `BukkitItemMatcher` 增强了物品匹配。
- 开放了更多插件触发器和事件调用，供自定义扩展使用。

## 问题修复与优化 {#bug-fixes-optimizations}

- 预先生成并存储默认生物属性，以提升生成时的性能。
- 改进了世界检查，以修复一些并发问题。
- 改进了占位符的舍入。
- 修复了随机生成的生物偶尔出现在墙内或负坐标处的问题。
- 修复了面向新版本构建时，插件在旧版本上无法加载的问题。
- 修复了某些情况下 double 类型占位符相关的 NPE。
- 修复了苦力怕的 `onPrime` 触发器。
- 修复了自定义方块无法作为生物图腾头部的问题。
- 粒子效果不再错误地受到 Spigot 默认可视范围的限制。
- 修复了 `force=true` 选项在 `look` 机制中的问题。
- 修复了弹射物的负重力。
- 修复了 1.21+ 上的后坐力。
- 修复了刷怪点未正确保存，以及 `Spawners.DisableCommandSaving` 逻辑相反的问题。
- 修复了 `onDamaged` 光环未被技能伤害触发的问题。
- 修复了 `consumeSlotItem` 在物品数量为 `0` 时失败的问题。
- 修复了默认药水等级为 `2` 而非 `1` 的问题。
- 修复了烟花颜色按 `RBG` 而非 `RGB` 加载的问题。
- 修复了 `teleport{unsafe=false}` 未将玩家正确放置在固体方块上的问题。
- 修复了 `hasItem`、`holding` 及其他物品条件，使其支持新的物品匹配器。
- 修复了生命恢复属性错误地为已死亡玩家恢复生命值的问题。
- 修复了针对无法受伤实体的 MythicDamageEvent（现在会正确取消）。
- 修复了 `mobsInRadius` 对某些原版类型失效的问题。
- 修复了刷怪笼物品未应用正确生物数据的问题。
- 修复了子碰撞箱元数据操作导致堆栈溢出的问题。
- 修复了 `spin` 效果，使其在施法者死亡时停止。
- 修复 `EnderBeam` 机制中的 IllegalArgumentException。
- 修复 `setDisplayEntityItem` 机制无法正确处理 Crucible 生成物品的问题。
- 修复物品展示实体的插值和旋转问题。
- 修复未设置 `MovementSpeed` 的生物使用 `setSpeed` 机制后卡住的问题。
- 修复 `setSpeed` 机制：未配置速度值时，倍率现在基于该生物类型的默认速度。
- 修复 `chicken jockey` 选项不生效的问题。
- 修复 1.21.4 中多种船类型失效的问题。
- 进一步修复多处并发和缓存问题（加快物品查找、distanceSquared 等）。

此版本包含许多新功能、错误修复和优化。如果遇到问题或异常行为，请在相应频道报告！
