# 2.0.X 更新记录 {#20x-changelogs}

### 2.0.6 {#206}

#### 通用设置 {#general}

- 改进了对 1.8.7 的支持

#### 问题修复与其他改动 {#bug-fixes-other}

- 修复了 sendtitle 技能会截掉副标题最后一个字符的问题
- 修复了 Damage 技能的 amount 数值在少数情况下略有偏差的问题
- 修复了 ParticleLine 和 ParticleRing 效果缺少粒子数据包的问题

### 2.0.5 {#205}

#### 通用设置 {#general-2}

- 将刷怪点、部分技能、扫描器和效果等多个系统改为异步运行；如果服务器有 >1 个 CPU 核心，性能将大幅提升。
- 如果服务器有 >1 个 CPU 核心，建议将 scan-interval 从原来的 60 设为 5 或 10。

#### 生物 {#mobs}

- SpawnModifiers 现在支持以 "# to #" 格式指定范围，并从中随机取值。
- 大多数技能不再以创造模式玩家为目标

#### 问题修复与其他改动 {#bug-fixes-other-2}

- 进一步改进了刷怪点！（现在几乎不产生额外开销）
- 修复了刷怪点有时会生成多个生物的问题
- 修复了某些伪装名称中的颜色不生效的问题
- 修复了 Spawners 有时无法识别关联生物死亡的问题。
- 修复了 Spawners 在插件重载时丢失其生物追踪记录的问题。
  - Spawners 现在会在重载时牵回、清理并重新生成其生物。
- 修复了尝试为过时插件启用兼容支持时，插件无法加载的问题。
- 修复了 SENDTITLE 技能未能正确加载两个字符串元素的问题。
- 修复了未设置伤害值时，生物不造成伤害而未使用原版默认值的问题

#### "Default" 生物配置 {#default-mob-configs}

现在无需使用 RandomSpawning 即可修改默认原版生物的属性（好主意！）。只需以想要修改的生物类型名称（MobType）作为配置名称即可！

以下是一些有效示例：

```
ZOMBIE:
  Health: 100
  Damage: 10
  Options:
    MovementSpeed: 0.3
    FollowRange: 100

WITHER_SKELETON:
  Health: 250
  Damage: 1000
  Drops:
  - experience 99999
```

#### 技能系统改进 {#improved-skill-system}

```
  * The skill system has been completely recoded the **Skills:**   section is now used for the new skill types.
  * Old skills can still be used under the **LegacySkills:**   section of configs. The old skills will NOT work under the Skills section anymore.
  * The new option syntax is a lot more straight-forward and should help a lot of people who found the old system confusing.
  * The new targeter option opens up a lot more possibilities for how skills can target things.
```

##### 语法 {#syntax}

技能语法略有变化。所有技能现在都采用以下格式：- skill{option1=val;option2=val;etc} @target ~onTrigger
=[healthmod] [chance]

```
  * SKILL is the skill's name
  * {options} are the skill's options.
  * target is the skill's target
  * trigger is the trigger, same as currently
  * healthmod is the same with 1 exception, health ranges must be prefixed with a = now also such as =25%-50%
  * chance is the same
```

如果还不太理解，可以参考下面的示例：

```
Skills:
- potion{type=SLOW;lvl=5;d=60} @Self ~onDamaged
```

这会在生物受到伤害时为其添加 SLOW 药水效果。

##### 目标选择器 {#targeters}

目前有两类目标选择器：ENTITY 和 LOCATION。有些技能现在可选择实体或位置作为目标，也有很多技能同时支持这两类目标。

以下是目前已加入的一些目标选择器：

```
  * @Self
  * @Target
  * @TargetLocation
  * @PlayersInRadius{r=#}
  * @PlayersInRing{min=#,max=#}
  * @PlayersInWorld
  * @LivingEntitiesInRadius{r=#}
  * @LivingEntitiesInWorld
  * @Location{x=#;y=#;z=#}
```

完整列表见插件手册。今后还会加入更多目标选择器，包括 @Line、@Cone 等。

##### 变量 {#variables}

字符串中生物变量的语法有了较大变化。

例如：原来的 **$mobname** 现在改为 **<mob.name>**

特殊字符的写法也有变化。例如，冒号原来使用 **&co;**，现在改为 **<&co>**

新可用变量的完整列表见手册。

##### 更多示例 {#more-examples}

```
Skills:
- effect:particles{cooldown=5;particle=flame;amount=200;vSpread=1;hSpread=2;Speed=0;yoffset=2} @self @onTimer:20
- skill{s=Fireball} @target
- particles{p=reddust;a=25;hs=0.5;vs=1;s=0.5;y=0.5} @self
- delay 10
- particleline{p=reddust;a=2;hs=0.1;vs=0.1;s=0;y=0.5;db=0.1} @target
- damage{amount=20} @target
```
