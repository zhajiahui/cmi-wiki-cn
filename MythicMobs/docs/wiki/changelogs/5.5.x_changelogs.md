# 5.5.X 更新记录

# 5.5.1 {#551}

## 通用设置 {#general}

- 新增初步的 1.20.3 支持（尚不完整，可能存在版本相关问题）
- 允许 broadcast 命令解析占位符
- 新增 `fromOrigin=true` 选项，供 `throw` 机制使用
- 将取消零伤害伤害事件的设置默认值改为 false

## 条件 {#conditions}

### 新增：`isUsingSpyglass` {#new-isusingspyglass}

### Health {#health}

- 新增 `includeAbsorption` 选项，供 `health` 条件使用

### Yaw {#yaw}

- 为 yaw 条件新增 `clamp` 选项，将 yaw 限制在 0-360，默认为 true

## 问题修复与其他改动 {#bugs-other}

- 修改了伤害触发器监听器，使其跳过零伤害的子类事件，以解决与其他使用此类事件进行 PvP 检查的插件之间的问题
- 修复了 hasItem 条件未检测到通过 API 添加的自定义物品的问题
- 修复了世界卸载期间弹射物中出现的 NPE
- 修复了光环的 `cancelOnTakeDamage` 选项不适用于方块伤害的问题
- 修复了 `requireLineOfSight=true` 时弹射物原点朝向为 yaw=0 的问题
- 修复了使用 fromOrigin=true 召唤多个弹射物时，它们沿一条直线相互堆叠的问题
- 修复了 HideFlag，使其在 1.20 之前的版本上使用 127，以向后兼容
- 修复了导入的物品未正确生成的问题，关闭 #1389

# 5.5.0 {#550}

## 通用设置 {#general-2}

- 新增 `General.CancelDamageIfZero` 配置选项，默认为 true（当前行为）

### 标记点系统 {#pins-system}

- 允许将位置快速保存到 `pins.yml` 文件中（位于任意包文件夹内）
- 新增 `/mm pins create [pack] [name]` 命令，用于将当前位置保存为一个位置标记
- 新增 `@Pin{pin=name}` 目标选择器
- 新增 `inPinRegion{pin1=X;pin2=Y}` 条件

## 生物 {#mobs}

新增可用的 Mythic 实体类型：

- EXPERIENCE_BOTTLE
- INTERACTION
- ITEM_DISPLAY
- MINECART
- MINECART_CHEST

为猫新增 Tamed 选项

## 技能机制 {#mechanics}

### 新增：`onChat` {#new-onchat}

- 一种拦截目标下一条聊天消息的光环
- 在消息被拦截后执行技能，并将 `<skill.var.input>` 作为输入传递

```
- onChat{then=[
    - message{m="Entered <skill.var.input>"}
]}
```

### 新增：`setFlying` {#new-setflying}

- `setFlying{flying=true}`

### 新增：`setInteractionSize` {#new-setinteractionsize}

- `setInteractionSize{height=X;width=Y}`

### 新增：`summonFallingBlock` {#new-summonfallingblock}

- `summonFallingBlock{material=SAND}`

### 光环 {#auras}

- 新增 `<skill.var.aura-duration-millis>` 占位符

### `Glow` {#glow}

- 在 1.18+ 上不再需要 GlowAPI（感谢 Phil）

### `Orbital` {#orbital}

- 新增 `reversed=true` 选项，用于反转方向

### `ModifyProjectile` {#modifyprojectile}

- 新增 `YOFFSET` 特性，可用于环绕体

### `PickupItem` {#pickupitem}

- 新增 `onPickup`（别名为 `then`）选项，供 `pickupItem` 机制使用，以在拾取物品后执行一个机制

### Speak {#speak}

- 允许使用 `\n` 强制在发言中换行

## 条件 {#conditions-2}

### 新增：`blockTypeInRadius` {#new-blocktypeinradius}

- 允许检查一定半径内是否存在一定数量的方块

示例：检查 10 格内是否有 10 个朝北或朝南且正在燃烧的熔炉：`blockTypeInRadius{r=10;a=>9;types=minecraft:furnace[lit=true,facing=north],minecraft:furnace[lit=true,facing=south]}`

### 新增：`inPinRegion` {#new-inpinregion}

- 目标位置是否位于由 2 个位置标记之间创建的区域内
- `inPinRegion{pin1=x;pin2=Y}`

### 新增：`itemType` {#new-itemtype}

- 以物品实体为目标时使用，例如使用 `ItemsInRadius` 目标选择器时

### 新增：`triggerBlockType` {#new-triggerblocktype}

- 与 ~onBlockBreak 等方块相关触发器配合使用

### 新增：`triggerItemType` {#new-triggeritemtype}

- 与 ~onItemPickup 等物品相关触发器配合使用

### MobsInRadius {#mobsinradius}

- 允许条件同时检查原版生物

## 目标选择器 {#targeters}

### 新增：`@InteractionLastAttacker` {#new-at-interactionlastattacker}

- 以最后一个击打交互实体的人为目标

### 新增：`@InteractionLastInteract` {#new-at-interactionlastinteract}

- 以最后一个与交互实体交互的人为目标

### 新增：`@Pin` {#new-at-pin}

- 以包中 pins.yml 定义的位置标记为目标
- `@Pin{pin=X}`

### Ring {#ring}

- 新增 `relative=true` 选项，使圆环随施法者朝向旋转

## 占位符 {#placeholders}

- 新增 `<item.amount>` 占位符，可用于物品相关触发器

## 物品 {#items}

- 新增通过 `Options.Trim: material.pattern` 使用盔甲纹饰的支持
- 为成书新增 `Author`、`Title` 和 `Pages` 选项

## API {#api}

- 新增 `MythicPreReloadEvent` - 在重载操作开始前触发
