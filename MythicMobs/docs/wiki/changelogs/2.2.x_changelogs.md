# 2.2.X 更新记录 {#22x-changelogs}

### 2.2.0 {#220}

由于需要修复大量问题且时间有限，2.2.0 被拆分为多次更新，以便更快发布重要的问题修复。因此，条件相关的更新将推迟至 2.3。现在，先来使用原版目标选择器吧！

#### 原版目标选择器 {#vanilla-targeters}

现在可以在 MythicMobs 技能中使用原版“命令方块”目标选择器了！它们的行为与游戏内*完全*一致，支持相同的全部选项、属性及其他功能，包括与记分板的交互。

- @a、@e、@p 和 @r 均受支持！
- 原版目标选择器的选项与命令方块中一样，填写在 [] 内。
  - 例如，**@a[x=100,y=64,z=-100,c=10,r=5]** 就是一个有效的原版目标选择器
  - **@a[x=1,y=64,z=-18,dx=3,dy=4,dz=19,team=!TEAM1,score_ASD_min=19,score_ASD=20,m=1]** 也有效

#### 生物 {#mobs}

##### 选项 {#options}

- 新增 **Persistent: true/false** - 设为 true 后，生物不仅永不自然消失，还会完全不受 */mm
m killall* 影响。适用于确实应该永远不会死亡的生物。设置了此项的生物，在设为 **Despawn: true** 时仍然会自然消失

#### 技能机制 {#mechanics}

##### 通用选项 {#general-options}

- 为所有机制新增 **repeat=X** 和 **repeatInterval=Y** 属性。
  - 同时设置这两项后，该行会每隔 Y 刻重复执行，共执行 X 次。

##### 技能机制 {#skill-mechanic}

- 新增 **forceSync** 属性，默认为 false。
  - 被调用的技能及其后续调用的所有技能都将同步执行，而不是异步执行。
  - 适用于对时机极其敏感、必须精确到每一刻都按顺序执行的技能。
  - 可能修复自 2.1.2 起出现的某些时序相关问题
  - 仅适用于通过 Skill 技能机制调用的技能
  - 默认为 false

##### Pull 技能机制 {#pull-mechanic}

- 新增 **toOrigin** 属性，默认为 false。设为 true 时，高级技能会将目标拉向技能原点，而非施法者。

##### 新增：Missile 技能机制 {#new-missile-mechanic}

与 Projectile 技能类似，但发射的是“追踪导弹”，而非轨迹固定的弹射物，且可配置惯性。

##### 新增：Totem 技能机制 {#new-totem-mechanic}

与 Projectile 技能类似。创建一个不会移动的静态“图腾”，停留在原地并对周围区域周期性施加效果。可为其设置持续时间和/或充能次数。

##### 新增：Velocity 技能机制 {#new-velocity-mechanic}

使用 x/y/z 向量直接改变玩家的速度。

##### 新增：BlockMask 效果 {#new-blockmask-effect}

一种向目标位置发送“虚假”方块更新的强大效果。可用于创建更强烈的效果，例如让被火球击中的区域看起来变成黑色的煤和火，或让方块看起来被摧毁。重新登录后，方块会恢复正常。可配置持续时间。

##### 新增：BlockUnmask 效果 {#new-blockunmask-effect}

撤销区域内的 BlockMask 效果。

#### 问题修复与其他改动 {#bug-fixes-other}

- 修复了即使设置 **Despawn: true**，生物仍会自然消失的问题
- 修复了 @trigger 未清除继承目标的问题
- 修复了 ARMOR_STAND 不支持 ~onInteract 触发器的问题
- 修复了冷却时间，现在可以接受小数
- 修复了几个旧版技能不再生效的问题
- 修复了被弹射物击杀时自定义 KillMessages 不生效的问题
- 修复了头颅物品不显示其显示名称的问题
- 修复了一个可能导致控制台刷屏的仇恨表目标事件错误
- 修复了许多其他问题
