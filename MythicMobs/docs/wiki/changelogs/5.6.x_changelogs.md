# 5.6.2 {#562}

## 随机生成 {#random-spawning}

- 重写了随机生成器，并新增一些配置选项
- 为随机生成新增 `ReplaceObeysCap`，默认为 false。

## 问题修复与其他改动 {#bugs-other}

- 新增 `onSummon`（别名为 `then`）属性，供 `summon` 机制使用；指定后，会在生物召唤完成后对其运行该技能。
- 新增 `<caster/target/trigger.raytrace.#>` 占位符
- 新增 `<target/trigger.stat.STAT_NAME>` 占位符
- 新增 `DisplayOptions.TeleportDuration` 选项
- 新增 `Options.VisibleByDefault`
- 新增 `executeAfterDeath=true` 选项，供 `skill` 和 `vskill` 机制使用
- 为对应的效果机制新增 `fakelightning` 和 `fakeexplosion` 别名
- 为 fireball 机制新增 `fromOrigin`
- 为 summon 机制新增 `inheritDespawnOption` 选项
- 为目标选择器的 `limit` 选项新增占位符支持
- 为 WEPasteSchematicMechanic 的 `x/y/z` 偏移和 `rotation` 选项新增占位符支持
- 新增对子碰撞箱的活跃生物父级的深层查找
- 尝试在 command 机制中捕获错误，以防止 NPC 失效
- 将 hide 机制中的 `permanent` 选项改为 `ignoreAuraOptions`
- 修复了重载期间刷怪点数据有时被清空的问题
- 修复了 GlowEffect 光环未正确合并的问题
- 修复了 GlowEffect 的 NPE
- 修复了集群生成器中的 IllegalArgumentException
- 修复了 Fireball 机制中的 NPE，关闭 #1561
- 修复了无效技能参数相关的 NPE
- 修复了新随机生成器相关的 NPE

- 修复了生成生物时的 NoSuchMethodError

# 5.6.0 {#560}

## 主要改动 {#highlights}

- 重写了配置文件。旧设置应当会自动迁移，现在位于新的 `configs` 文件夹中
- 新增 `Fancy` 掉落、玩家独立战利品掉落
- 发光效果不再需要 GlowAPI
- 生物生成蛋改进

## 通用设置 {#general}

- 改进了 getCoordinates 实用命令的输出

## 配置 {#configs}

- 为不同的全息显示功能新增配置选项，并调整了一些设置

## 标记点 {#pins}

- 新增并改进了一些位置标记命令
- 新增用于全息显示的 `/mm pins toggleviewing` 命令
- 新增 `/mm pins move` 命令
- 将 `/mm pins list` 改为按位置标记距你的远近排序，最近的在前

## 生物 {#mobs}

- 为生物新增 `Variables` 字段，用于预设技能可用的变量
- 为 MEG 生物新增 `Nameplate.Mounted: false` 选项
- 生物生成蛋现在可以在 `config-mobs.yml` 中完全配置，并可按生物分别覆盖显示名称/lore

```
SomeMob:
  Egg:
    Display: '<caster.name> EGG'
    Lore:
    - 'im a testing egg'
```

## 技能机制 {#mechanics}

### `NEW: followPath` {#new-followpath}

- 新增 `followPath mechanic` - 一种使目标生物沿指定路径行走的光环

### `NEW: modifyDamage` {#new-modifydamage}

- 将 `modifyDamage` 机制的默认伤害类型设为 `ALL`
- 使 `modifyDamage` 机制在 `type=ALL` 时修改所有伤害类型
- 新增 `modifyDamage` 机制，允许修改当前触发事件的伤害

### `Auras` {#auras}

- 为所有光环机制新增 `cancelOnCasterDeath=true` 选项
- 为光环新增调试信息

### `Hide` {#hide}

- Hide 机制现在继承自光环
- 新增 AbstractPlayer#hideEntity 和 AbstractPlayer#showEntity

### `Hit` {#hit}

- 为 hit 机制新增 `forcedDamage`

### `Glow` {#glow}

- Glow 发光效果不再需要 GlowAPI
- Glow 发光效果现在继承自光环

### `takeItem` {#takeitem}

- 修复了 `takeItem` 机制的其他问题
- 新增 `exact=false` 选项，供 `takeItem` 机制使用

## 条件 {#conditions}

### `NEW: lookingAt` {#new-lookingat}

- 新增 lookingAt 玩家条件

### `NEW: originLocation` {#new-originlocation}

- 新增 `originLocation{location=x,y,z}` 条件，用于匹配原点是否位于指定位置

## 触发器 {#triggers}

- 新增 `onSkillDamage` 触发器，由技能伤害触发

## 目标选择器 {#targeters}

- 新增 `bb=false` 筛选器，使目标选择器忽略 MEG 子碰撞箱
- 新增 `unique=false` 实体目标选择器选项，设为 false 时，允许目标选择器同时命中一个模型生物的多个子碰撞箱

## 占位符 {#placeholders}

- 新增多个 `caster.target.` 占位符，用于作用于施法者的目标
- 新增 `<trigger.item.amount>` 占位符

## 生物掉落物 {#mob-drops}

- 新增多个掉落选项

## RandomSpawning {#randomspawning}

- 新增 `LimitMultiplier` 等选项，帮助控制随机生成

## API {#api}

- 新增 PlayerLevelProvider
- 新增 `MythicMobEggEvent`，在使用生成蛋时触发
