# 2.4.2 {#242}

## 物品属性 {#item-attributes}

物品属性现在支持使用 "# to #" 语法，在范围中填写负值。

Examples:

- AttackSpeed: -0.2 to -0.4
- Health: 10 to 20%

- 修复了未定义任何属性时，物品仍被应用空 AttributeModifiers NBT 标签的问题。
- 修复了不会自然消失的生物丢失类型的问题
- 修复了在位置目标选择器与实体目标选择器之间切换时的继承问题
- 修复了史莱姆和岩浆怪完全不生成的问题
- 修复了 ShootPotion 机制完全不生效的问题
- 修复了生物生成的几个问题

# 2.4.0 {#240}

## 重要通知 {#important-notice}

`This version of MythicMobs requires the useage of Java 8 (or later) on your servers.`
不使用 Java 8 会导致插件完全无法运行。此要求同样适用于 MythicMobs 的后续版本。

## 支持 Minecraft 1.9 {#minecraft-19-support}

此版本的 MythicMobs 主要致力于兼容 Minecraft/Spigot 1.9 服务器。我们已尽力让 MythicMobs 利用 Minecraft 1.9 提供的新功能，例如双持、新增药水效果等。如果我们遗漏了你希望在 MythicMobs 中使用的某些特定功能，请务必在[问题报告与建议子论坛](http://www.mythicmobs.net/forum/viewforum.php?f=6)中提出建议。

插件仍保留对 Spigot 1.8.8 和 1.7.10 的兼容性。

## 条件 {#conditions}

### 新增：distancefromspawn {#new-distancefromspawn}

新增了一个可判断距世界出生点距离的条件。支持数值范围、大于/小于等写法。语法请参阅[条件页面](https://wiki.mythiccraft.io/mythicmobs/conditions/start)。

## 生物 {#mobs-3}

### 新增：BossBar {#new-bossbar}

允许为自定义生物使用类似末影龙和凋灵的生命条，而且可以自定义！参见 [BossBar](../mobs/bossbar.md)。

### 新增类型 {#new-types}

- 新增对**潜影贝（Shulker）**作为 MythicMob 的支持。

### 选项 {#options-4}

- **AlwaysShowName: [true/false]** - 在基于 1.9 的服务器上，此选项适用于任何实体。在基于更早版本的服务器上，仅适用于盔甲架。
- **AttackSpeed: [number]** - 设置生物的近战攻击速度。也兼容 LevelModifiers。
- **Collidable: [true/false]** - 定义生物是否具有碰撞箱。仅适用于基于 1.9 的服务器。
- **Glowing: [true/false]** - 使生物无限期发光。
- **Profession: [type]** - 设置僵尸村民的村民类型。FIXME

### 装备 {#equipment}

- 现在可以使用槽位编号 **5** 将物品装备到生物的副手。`Mob:
Equipment:
  - item:5`

### 伪装 {#disguises}

新增伪装选项：

- **Glowing: [true/false]**
- **Gliding: [true/false]**

### AI 行为 {#ai-goals}

- **新增：Patrol** - 使生物在多个指定位置之间巡逻。仅在基于 1.9 的服务器上生效。语法请参阅 [AI 目标页面](https://wiki.mythiccraft.io/mythicmobs/databases/mobs/aigoals)。
- **GoToLocation x,y,z** - 已修复。

### LevelModifiers {#levelmodifiers}

- **AttackSpeed: [number]** - 生物每升一级，增加 [number] 攻击速度。
- **MovementSpeed: [number]** - 生物每升一级，增加 [number] 移动速度。

## 技能机制 {#mechanics}

### 新增：JSONMessage {#new-jsonmessage}

一种新的消息发送方式。支持点击和悬停事件，例如执行命令、填入命令建议和显示提示文本。工作方式与 minecraft:tellraw 命令相同！参见 [JSONMessage](../skills/mechanics/jsonmessage.md)。

### Lightning 效果 {#lightning-effect}

为[闪电效果](../skills/mechanics/lightning.md)新增 "localized" 和 "localizedradius" 属性。

### Equip {#equip}

现在可以在 equip 机制中使用槽位 "5" 指定生物的副手。参见 [Equip 机制](../skills/mechanics/equip.md)。

```
Skill:
- equip{i=best_sword_ever:5}
```

### Shoot {#shoot}

shoot 机制新增了许多有趣的功能。其能力和灵活性比以前强了数倍。新增属性/选项请参见：[Shoot 机制](../skills/mechanics/shoot.md)。

### 粒子效果 {#particle-effects}

Minecraft 1.9 新增的所有粒子均兼容 MythicMobs。包括：

- **endRod** - 新增的末地烛方块发出的柔和白色光点
- **dragonbreath** - 外观与 *reddust* 相同，但颜色和行为不同
- **damageIndicator** - 弹跳的黑色爱心
- **sweepAttack** - 横扫攻击……

### 药水效果 {#potion-effects}

Minecraft 1.9 新增的所有状态/药水效果均兼容 MythicMobs。包括：

- **发光（Glowing）**
- **漂浮（Levitation）**
- **幸运（Luck）**
- **霉运（Bad Luck）**

所有可用状态效果的完整列表可在[药水页面](https://wiki.mythiccraft.io/mythicmobs/databases/items/potions)查看。

## 物品 {#items-2}

### 新增：Item.Attributes {#new-itemattributes}

新增了一个特殊字段，可用于控制 Minecraft 1.9 引入的新物品属性系统。它取代了 MythicMobs 中原先基于 "Options" 字段的属性系统。参见[物品属性](../items/attributes.md)。

### 新增：Item.Hide {#new-itemhide}

新增了一个特殊字段，可隐藏物品提示文本中的特定文字。它取代了旧的 "HideFlags" 选项。使用方法请参阅[物品概览](https://wiki.mythiccraft.io/mythicmobs/databases/items/overview)。

### 已更改的选项 {#changed-options}

- **BannerLayers** - 现在也可以添加到 Minecraft 1.9 新增的盾牌物品上。

### 已弃用的选项 {#deprecated-options}

这些选项仍然有效，但已弃用，我们不再为其提供支持。请使用新的物品属性系统和新的 "Hide" 标签。

- **Damage**
- **FollowRange**
- **Health**
- **HideFlags**
- **KnockbackResistance**
- **MovementSpeed**

- 修复了消息变量在伪装名称中不生效的问题
- 修复了 MythicMobs 生成的物品与 *Shopkeepers* 的兼容性问题
- 修复了使用 <target.> 变量时 command 机制不生效的问题
- 修复了多个 NPE
- 修复了使用 1.9 时所有僵尸类型都生成成僵尸村民的问题
- 修复了使用 *Action: add* 的新随机生成系统的多个问题
- 修复了 2.3.0 中的多个问题
