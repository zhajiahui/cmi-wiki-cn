# 5.4.X 更新记录

# 5.4.0 {#540}

## 主要改动 {#highlights}

### 版本支持 {#version-support}

新增对 1.20.2 的支持

### Damage {#damage}

- 新增对多类型伤害的支持
- 新增 DamageTags，可在任何伤害机制上使用 tags=THIS,THAT 指定任意数量的自定义标签，例如 `- damage{amount=5;tags=FIRE}`
- 新增 `damageTag` 条件，检查触发技能的伤害是否具有给定标签
- 将 element 伤害属性改为仅应用一个伤害标签

### 投射物升级 {#projectile-upgrades}

- 弹射物游戏刻插值
- 新增 DISPLAY 和 TEXT 子弹类型
- 物品展示子弹类型：新增 "tx"、"ty" 和 "tz"（t 取自 translation，即平移），用于偏移子弹的视觉位置；也可以用 "translation"（"pos"、"offset"）按 x,y,z 格式同时设置所有数值
- 为展示子弹新增 `bulletBrightness`，还不知为何新增了 `bulletBrightnessBlock` 和 `bulletBrightnessSky`
- 为展示子弹新增 `bulletBillboard`
- 为生物子弹新增 `bulletForwardOffset`
- 为展示和文本子弹新增 `bulletCullingDistance` 选项

### 属性系统 {#stat-system}

- 新增[属性系统](../stats.md)

### 全息文字 {#holograms}

- 新增我们自己的全息显示系统
- 所有全息显示相关功能不再需要第 3 方全息显示插件
- 在 1.19.4+ 上，生物名称现在可以通过名称牌功能显示为多行，使用 `\n` 换行

### 刷怪点 {#spawners}

- 大幅重写刷怪点 - 参见刷怪点部分

## 通用设置 {#general}

- 新增 `/mm test mechanic [line]` 命令，用于测试执行技能行
- 允许在 `packinfo.yml` 中使用 CustomModelData
- 升级了物品编辑器，新增了一批按钮

## 生物 {#mobs}

- 新增对生物以玩家为父级的支持

新增生物类型：

- `BLOCK_DISPLAY`
- `CAMEL`
- `CHEST_BOAT`
- `ITEM_DISPLAY`
- `SNIFFER`
- `TEXT_DISPLAY`

### AI {#ai}

- 新增 `radius` 选项，供 `LookAtPlayers` 目标使用
- 为 MeleeAttackGoal 新增 `attackReachModifier` 选项（默认为 4）

## 技能机制 {#mechanics}

### 新增：Cancel {#new-cancel}

- 取消当前技能树

```yml
SomeSkill:
 Skills:
 - message{m="hello"} @server
 - cancel ?isMonster #cancels the rest of the skill from executing
 - message{m="bye"} @server
```

### 新增：Hit {#new-hit}

- 使用施法者的伤害属性、手持武器等，模拟施法者的一次物理命中
- 与 `baseDamage` 机制具有相同的选项
- 会考虑近战属性（普通技能伤害除非专门配置，否则不会考虑）

### 新增：SetTransformation {#new-settransformation}

- 对目标展示实体进行变换

```yml
- transformation{action=set;transformation=translation;value=0,0,1} @self

- transformation{action=set;transformation=right_rotation;value=0,0,0,1} @self ~onwhatever
```

动作值：SET、ADD、MULTIPLY、DIVIDE
变换值：TRANSLATION、SCALE、RIGHT_ROTATION、LEFT_ROTATION

### 新增：ClearExperienceLevels {#new-clearexperiencelevels}

### 新增：pushBlock {#new-pushblock}

- 沿给定方向推动目标方块。遵循与活塞相同的规则。
- 方向可以是基本方位，也可以是位置目标选择器。如果给出目标选择器，则会向该位置推动方块一次
- 此机制还支持 `onPush` 和 `onFail` 技能，会在方块位置触发

此机制遵循活塞规则，也会推动其他相连的黏液块，但仅限与被推动方块相邻或位于其前方的黏液块——它无法推动连接在被推动方块*后方*的方块。

### 新增：`setProjectileDirection` {#new-setprojectiledirection}

- 将调用此机制的弹射物方向改为朝向给定目标

### 新增：`setProjectileBulletModel` {#new-setprojectilebulletmodel}

- 新增 `setProjectileBulletModel{model=X}` 机制，可由弹射物调用，以更改子弹物品的模型 ID（仅适用于 DISPLAY 子弹）

### 新增：`StatAura` {#new-stataura}

- 以光环形式为目标施加属性修正。

Example:

```
- stataura{stat=PARRY_CHANCE;type=ADDITIVE;value=0.5;duration=200} @self ~onDamaged
```

- 会在受伤时将施法者的招架概率属性提高 50%，持续 10 秒

### ArrowVolley {#arrowvolley}

- 新增 "pickup"/"canPickup" 属性，默认为 true

### 伤害类技能机制 {#damage-mechanics}

- 为伤害机制新增 `powerAffectsDamage`、`ignoreShield`、`ignoreEffects`、`ignoreResistance`、`damagesHelmet` 和 `noAnger` 布尔选项

### 粒子效果 {#particle-effects}

- 新增粒子：DRIPPING_CHERRY_LEAVES、FALLING_CHERRY_LEAVES、LANDING_CHERRY_LEAVES
- 为粒子效果机制新增 `startSideOffset` 占位符支持

### 投射物技能机制（Projectile、Missile 等） {#projectile-mechanics-projectile-missile-etc}

- 新增 `tickInterpolation` 选项（默认为 0）
- 将生物子弹的 Y 轴偏移选项改为 bulletYOffset

设置 tickInterpolation 后，会在弹射物的每两个游戏刻之间插入相应数量的点，并在这些点上同样执行 onTick 和 onHit 技能，从而在单个游戏刻内执行多次“刻”更新。

这可用于填补超高速弹射物的间隙，也能防止速度极快的弹射物跳过实体。

- 为弹射物新增 `interactable=true`、`onInteractSkill`（需要 1.19.4+），用于让玩家像击打恶魂火球一样击打弹射物。

### Missile {#missile}

- 为 missile 机制新增 `hugSurface` 和 `bounce` 选项（以及与 Projectile 机制类似的所有其他相关选项）

### Lunge {#lunge}

- 新增 `oldMath/old/o` 属性，用于决定是否使用旧的异常数学计算方式（默认：false）

### Orbital {#orbital}

- 为环绕体新增 `hugSurface`

### PotionClear {#potionclear}

- 新增 `type`/`types` 属性，供 `potionClear` 机制使用

### Switch {#switch}

- 允许运行元技能，并重构代码

### Rally {#rally}

- 重写了 Rally 机制。为 rally 新增 `conditions` 选项，所有属性现在均为可选。

### Volley {#volley}

- 新增 "pickup"/"canPickup" 属性，默认为 true

## 条件 {#conditions}

### 新增：DamageTag {#new-damagetag}

新增 damageTag 条件，检查触发技能的伤害是否具有给定标签

`- damageTag{tag=FIRE}`

### 新增：directionalVelocity {#new-directionalvelocity}

- 新增 `directionalVelocity` 条件，用于检查目标的速度是否符合给定参数。
- 为 DirectionalVelocityCondition 新增 side、forward 和 vertical 别名

Options:

| 选项 | 说明 | 默认值 |
| --- | --- | --- |
| x | X 方向的速度（范围） | null（不检查） |
| absx | 使用 X 方向速度的绝对值 | false |
| y | Y 方向的速度（范围） | null（不检查） |
| absy | 使用 Y 方向速度的绝对值 | false |
| z | Z 方向的速度（范围） | null（不检查） |
| absz | 使用 Z 方向速度的绝对值 | relative=true 时为 true，否则为 false |
| relative | 设为 true 时，X 表示前后方向，Z 表示左右方向 | false |

如果未指定 X、Y 或 Z 轴速度，则不检查该速度分量。'absx'、'absy' 和 'absz' 选项决定检查时是否使用对应速度的绝对值。如果 'relative' 为 true，则将速度视为相对于实体朝向的速度。

### 新增：MaterialOnCooldown {#new-materialoncooldown}

`materialIsOnCooldown` 条件，别名为 `materialCooldown`、`matCooldown`
参数为 `material` / `mat` / `m`，默认为 enderpearl

如果该材质类型对玩家而言正在冷却，则为 true，否则为 false

### 新增：自定义占位符 {#new-custom-placeholders}

新增自定义占位符文件，方便配置静态、可复用甚至带条件的值。

每个包现在都可以在包根目录中放置一个 `placeholders.yml`，其中可包含任意数量的占位符。

这些占位符可以是静态的，也可以定义为条件占位符——会选择第一个判断为 true 的项，如果全部为 false，则选择 Default。

placeholders.yml 的示例可以如下所示：

```
TestPlaceholder: 'some value'
TestConditionalPlaceholder:
  Day:
    Conditions:
    - day
    Value: day
  Night:
    Conditions:
    - night
    Value: night
  Default: idk

Added ability to define random placeholders that will just choose a random line from a list in the `placeholders.yml` file
```

TestRandomPlaceholder:

- red
- green
- blue

