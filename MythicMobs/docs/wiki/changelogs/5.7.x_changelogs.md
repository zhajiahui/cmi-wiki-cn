# 5.7.X 更新记录

# 5.7.2 {#572}

## 通用设置 {#general}

- 新增 `ThreadPoolSize` 选项，位于 `config-general.yml` 中，用于限制 Mythic 使用的异步线程数量。默认为 -1（不限制）。
- 新增 `toggleTimer` 实用命令。
- 新增 `-p` 选项，供 `spawner create` 和 `spawner move` 命令使用，以在玩家位置创建/移动刷怪点。

## 技能机制 {#mechanics}

### 投射物 {#projectiles}

- 升级了弹射物的 MEG 子弹类型。
- 为 MEG 弹射物新增子弹相关选项：`bulletScale`、`bulletColor`、`bulletGlowing`、`bulletGlowColor`。

### 变量 {#variables}

- 新增 `DOUBLE` 变量类型。

## 目标选择器 {#targeters}

- 新增 `usePitch=true` 选项，供 `@EntitiesInCone` 目标选择器使用。

## 随机刷怪 {#random-spawners}

- 允许在随机刷怪点等级中使用占位符。

## 占位符 {#placeholders}

新增 <caster.type> 和 <caster.type.name> 占位符。

## 问题修复与其他改动 {#bugs-other}

- 为 `CustomComponentRegistry` API 新增一些功能。
- 将物品数据标签从 NBT 改为使用 PDC，修复了 1.21 上 Spigot 反序列化的问题。
- 修复了父级属性的一个加载问题。
- 修复了属性可能引发的 StackOverflowError。
- 修复了失效的父级占位符。
- 修复了 EntitiesInCone 中范围的计算错误。
- 修复了缺失的施法者占位符，并新增 c. 别名。
- 修复了 entity_effect/mobSpell 粒子的问题。
- 修复了 BukkitItemStack 中的 NPE。
- 修复了光环中的 NPE。
- 修复了从控制台向生物发送信号时的 NPE。
- 修复了技能参数未传递给条件动作调用的技能的问题。
- 修复了掉落 ChatMessages 中空行未显示的问题。
- 修复了使用实体元数据导致的内存泄漏。
- 修复了 onSpawnOrLoad 事件未触发的问题。
- 修复了此前构建版本引入的粒子错误刷屏问题。
- 修复了插件在 1.19.4 上不加载的问题。
- 修复了无效粒子数据导致的问题。
- 修复了计算世界最大高度时的 y 越界错误。
- 修复了仇恨表中出现 NPE 和计算错误的问题。
- 将 <caster.name> 改为 <caster.type.name>，修复了 setName 机制的循环问题。
- 修复了战利品爆散导致物品无法堆叠的问题。

# 5.7.0 {#570}

**注意：对该版本的支持涉及重大升级，可能仍然存在 Bug。发现 Bug 时，请创建 Issue，或在 Discord 的下述频道告知我们。

`Note: 1.21 support was a huge upgrade and there may still be bugs. Please make sure to report any bugs you find by opening an Issue or by letting us know in the` mythic-121-testing `channel in Discord`**

## 通用设置 {#general-3}

- 新增对 1.20.5、1.20.6 和 1.21 的支持
- 停止支持 1.16.4、1.18.2、1.19.1、1.19.2 和 1.19.3。
- 生物和技能中多种接受物品的选项现在可以接受掉落表，并会使用其中的随机物品，例如 Item 生物类型。

## 生物 {#mobs}

- 新增对实体类型 `Armadillo`、`Bogged` 和 `Breeze` 的支持。
- 为生物新增 HEARING 听觉能力，通过 `Hearing.Enabled: true` 启用。需要 1.20+
- 新增 [`~onHear`](../mobs/mobs.md#hearing) 触发器，用于响应听到的声音
- 为僵尸和骷髅新增 `Options.PreventConversion`。
- 将直接在生物上定义的变量改为默认始终保存。

## 技能 {#skills}

### 技能机制 {#mechanics-2}

- 新增粒子：`white_smoke`、`dust_plume`、`gust`、`gust_emitter`、`gust_dust` 和 `trial_spawner_detection`
- Mojang 在 1.21 中移除了粒子 `mobSpellAmbient`
- 允许 `command` 和 `message` 机制以位置为目标，以使用基于位置的占位符。
- 将 `setItemDisplay` 机制重命名为 `setDisplayEntityItem`，以明确用途并避免命名冲突。

#### 新增：`Log` {#new-log}

- `log{message="Debug to console with variables <caster.var.test>"}`

#### 新增：`SetTextDisplay` {#new-settextdisplay}

- `setTextDisplay{text="text here"} @Target`

#### 新增：`Taunt` {#new-taunt}

- 将施法者的仇恨值设为当前目标所瞄准对象的仇恨值的 110%，并强制目标攻击施法者。需要仇恨表。

#### 新增：`openTrades` {#new-opentrades}

- `openTrades (openTrade, trade)` 机制，用于向目标玩家打开商人交易界面。
- 新增 `realTrade/real` 属性 - 决定玩家是否与实际村民进行交易（例如掉落交易经验等）。

#### 新增：`setChunkForceLoaded` {#new-setchunkforceloaded}

- 将目标位置的区块设为强制加载

#### DropItem {#dropitem}

- 为 dropItem 机制新增 `then=` 技能，以掉落的物品实体为目标。

### 条件 {#conditions}

- 为条件新增 `onPass[Skill]` 和 `onFail[Skill]`。

#### 新增：`boundingBoxesOverlap` {#new-boundingboxesoverlap}

#### 新增：`distanceFromPin` {#new-distancefrompin}

- `distanceFromPin{pin=X;distance=<5}`

#### 新增：`distanceFromLocation` {#new-distancefromlocation}

- `distanceFromLocation` 条件。值有 `x`、`y`、`z`、`distance/d`，以及可选的 `world`（未提供世界名时，默认为玩家当前世界）。

### 目标选择器 {#targeters-2}

#### 新增：`@BlocksInPinRegion` {#new-at-blocksinpinregion}

#### 新增：`@HighestBlock` {#new-at-highestblock}

- 以原点所在位置的最高位置为目标。

#### 新增：`@TrackedPlayers` {#new-at-trackedplayers}

- 以处于渲染距离内、当前正在渲染该生物的玩家为目标

#### 新增：`@ChunksinWERegion` {#new-at-chunksinweregion}

- 新增 `@ChunksinWERegion{region=X}` 目标选择器。

#### Pin {#pin}

- 新增 `random=true` 选项，如果以多位置标记为目标，则会随机选取一个，而不是全部选取。

### 占位符 {#placeholders-2}

- 新增 `PlaceholderBoolean`，如果变量为 'true' 或 '1'，则判断为 true，否则为 false。
- 为 `random.float` 占位符新增舍入支持，使用语法 `<random.float.1to5{round=2}>`

## API {#api}

- 重构了 EquipSlots，以支持自定义槽位。
- 为 MythicRPG 进行了多项 API 改进。
- 新增用于转储物品组件数据的方法。
