# 5.0.1（测试版） {#501-beta-build}

## 主要改动 {#highlights}

- 现在需要 Java 16
- Mythic API 正被拆分为独立模块（面向附加插件作者）
- 大幅重写 API
- 注册自定义触发器
- ModelEngine 的原生模型配置
- MythicKeys 模组支持

## 通用设置 {#general}

### 模型配置 {#model-configuration}

现在可以在生物配置内配置 ModelEngine 模型。

```
Mob:
  Model: [model id]
```

或者使用更多选项……

```
Mob:
  Model:
    Id: [model id]
    ViewRadius: 64
    Drive: true
    DamageTint: true
```

etc...

## 技能机制 {#mechanics-2}

### 新增：onKeyPress {#new-onkeypress}

- 客户端需要 [MythicKeys 模组](https://github.com/ASangarin/MythicKeys)，服务端需要 [MythicKeysPlugin](https://www.spigotmc.org/resources/mythickeysplugin-custom-keybinds-api.98893/)。
- 对目标玩家施加光环，并在目标玩家按下按键时触发技能
  - `onKeyPress{key=minecraft:server;onPress=metaSkillHere}`

### 新增：onKeyRelease {#new-onkeyrelease}

- 客户端需要 [MythicKeys 模组](https://github.com/ASangarin/MythicKeys)，服务端需要 [MythicKeysPlugin](https://www.spigotmc.org/resources/mythickeysplugin-custom-keybinds-api.98893/)。
- 对目标玩家施加光环，并在目标玩家松开按键时触发技能
  - `onKeyRelease{key=minecraft:server;onRelease=metaSkillHere}`

### 新增：ShieldBreak {#new-shieldbreak}

- 打断目标玩家的盾牌格挡，并禁用其盾牌 `duration` 刻。

### PasteSchematic {#pasteschematic}

- 将 fawePaste 改为 PasteSchematic，现在也适用于普通 WorldEdit
- 为 fawepaste 机制新增 rotation=90/180/-90

## 问题修复与其他改动 {#bug-fixesother-2}

- 修复了非 Paper 的 Spigot 上的生物掉落
- 修复了 shoot 机制的 onHitSkill 未继承技能变量的问题，关闭 #687
- 新增 `min(x, y)`、`max(x, y)`、`atan2(y, x)` 数学函数。可以在[数学运算](../skills/math.md)中查看所有受支持的运算符和函数，也可以向 [gitlab](https://git.mythiccraft.io/mythiccraft/MythicMobs/-/issues) 提交新增运算符和函数的建议
- 修复了几个生物 AI。关闭 #681
- 修复了 WorldGuard 支持相关的 NPE
- 修复了移除生物时伪装有时未消失的问题
