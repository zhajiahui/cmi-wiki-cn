# Set Dragon Podium {#set-dragon-podium}

## 说明 {#description}

将末影龙停栖点，也就是其盘旋中心，设为目标位置。仅支持 Paper 1.18.2+。

## 属性 {#attributes}

> *此技能机制没有属性。*

## 示例 {#example}

```yaml
  Skills:
  - setDragonPodium @Location{c=125,50,-521}
```

- podium
