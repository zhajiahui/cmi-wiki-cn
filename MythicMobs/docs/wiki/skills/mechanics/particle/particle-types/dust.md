# Dust {#dust}

## Particle {#particle}

![img](../../../../assets/4f0e98c5d6e4ad.gif)

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| color | c | 粒子的颜色。 | #FF0000 |
| size |  | 粒子的大小。 | 1 |

> 该粒子具有 [Dustoptions](../particle-types.md#dustoptions) 数据类型，并继承其所有属性

## 示例 {#examples}

```yaml
  Skills:
  - particle{p=dust;color=#FF0000;size=1}
```
