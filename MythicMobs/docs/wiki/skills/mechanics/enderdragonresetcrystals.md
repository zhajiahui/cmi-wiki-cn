# Ender Dragon Reset Crystals {#ender-dragon-reset-crystals}

## 说明 {#description}

若目标位置所在维度正在进行末影龙战斗，则生成末影龙水晶。

## 属性 {#attributes}

> *此技能机制没有属性。*

## 示例 {#examples}

```yaml
  Skills:
  - enderDragonResetCrystals @selflocation ~onDamaged =50%
```

> 受到伤害后达到 50% 生命值阈值后，重置施法者维度中的末影龙水晶
