# Set Chunk Force Loaded {#set-chunk-force-loaded}

## 说明 {#description}

设置目标位置所在区块是否强制加载

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| loaded | l | 是否强制加载该区块 | true |

## 示例 {#examples}

```yaml
  Skills:
  - setchunkforceloaded @selflocation
```
