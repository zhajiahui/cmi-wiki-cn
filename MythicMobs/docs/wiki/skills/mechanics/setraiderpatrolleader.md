# Setraiderpatrolleader {#setraiderpatrolleader}

## 说明 {#description}

设置目标袭击者是否应该是袭击者巡逻队长

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| leader | l, bool, b | 是否将目标袭击者设为队长 | true |

## 示例 {#examples}

```yaml
  Skills:
  - setRaiderPatrolLeader{leader=true} @target
```

## 别名 {#aliases}

- setRaiderLeader
