# Decapitate {#decapitate}

## 说明 {#description}

掉落目标玩家头部的副本。当针对非玩家实体使用时不会执行任何操作。

## 属性 {#attributes}

> *此技能机制没有属性。*

## 示例 {#examples}

掉落点击生物的人的头。

```yaml
  Skills:
  - decapitate @trigger ~onInteract
```
