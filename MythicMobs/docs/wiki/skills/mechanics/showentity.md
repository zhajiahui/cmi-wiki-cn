# Showentity {#showentity}

## 说明 {#description}

如果通过使用[隐藏](hide.md)机制隐藏施法者，则向目标玩家显示施法者。

## 属性 {#attributes}

> *此技能机制没有属性。*

## 示例 {#examples}

```yaml
  Skills:
  - showEntity @NearestPlayer{r=10}
```

## 别名 {#aliases}
