# Fake Explosion {#fake-explosion}

## 说明 {#description}

在指定目标处产生爆炸效果。会播放声音和粒子效果，但不会造成任何损坏。

## 属性 {#attributes}

> *此技能机制没有属性。*

## 示例 {#examples}

```yaml
ExplosionSkill:
  Skills:
  - fakeexplosion @self
```
