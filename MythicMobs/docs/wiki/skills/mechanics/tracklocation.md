# Tracklocation {#tracklocation}

## 说明 {#description}

将施法生物的追踪位置设为目标位置。玩家不能拥有追踪位置；此后可通过相关[目标选择器](../targeters/trackedlocation.md)和[条件](../conditions/distancefromtrackedlocation.md)使用此位置。

## 属性 {#attributes}

> *此技能机制没有属性。*

## 示例 {#examples}

```yaml
  Skills:
  - tracklocation @targetlocation
```
