# Set Block Open {#set-block-open}

## 说明 {#description}

设置目标块的打开状态

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| open | o | 是否将方块设为打开状态 | true |

## 示例 {#examples}

```yaml
  Skills:
  - setblockopen @ObstructingBlock
```
