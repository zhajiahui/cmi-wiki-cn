# Set Flying {#set-flying}

## 说明 {#description}

设置目标玩家是否正在飞行

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| flying | f, state, value | 目标玩家是否处于飞行状态 | false |

## 示例 {#examples}

```yaml
  Skills:
  - setflying{f=true} @PIR{r=2}
```
