# Log {#log}

## 说明 {#description}

直接将消息记录到控制台。用于调试或保存目的。

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| message | m | 要记录的消息。 | "" |

## 示例 {#examples}

```yaml
  Skills:
  - log{message="Hello World!"} @None
```

## 别名 {#aliases}

- console
- print
- printf
