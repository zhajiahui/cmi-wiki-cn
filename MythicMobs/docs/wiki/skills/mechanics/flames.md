# Flames {#flames}

## 说明 {#description}

在目标位置产生火焰效果，模仿 Minecraft 刷怪笼的火焰，因此带有随机性。

## 属性 {#attributes}

> *此技能机制没有属性。*

## 示例 {#examples}

```yaml
FlamesSkill:
  Skills:
  - flames @self
```
