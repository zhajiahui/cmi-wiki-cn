# Dismount {#dismount}

## 说明 {#description}

如果生物正骑乘某个实体，让它离开坐骑，否则不执行任何操作。

> **这是一个无目标机制，受影响的实体将始终是施法者**

## 属性 {#attributes}

> *此技能机制没有属性。*

## 示例 {#examples}

```yaml
  Skills:
  - dismount ~onDamaged
```
