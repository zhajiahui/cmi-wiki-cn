# Fear {#fear}

## 说明 {#description}

施加[光环](../aura.md)，使目标在恐惧中四处逃窜

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| speed | s | 实体的逃离速度。 | 0.35 |
| directionChangeInterval | dirchange, dci | 实体改变方向的间隔，单位为刻。 | 20 |
| feardistance | fearrange, fdist, fd | 受影响实体与施法者之间的距离小于此值时，会尝试*远离*施法者，而不是完全随机地奔跑。 | 10.0 |
| rotationticks | rotateticks, rt | 实体头部转向新的奔跑方向所需的时间，单位为刻。 | 5 |
