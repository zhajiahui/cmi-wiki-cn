# Set Pitch {#set-pitch}

## 说明 {#description}

设置目标实体的头部俯仰角

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| amount | a, pitch, p | 要设置的 pitch（俯仰角）值 | 0 |

## 示例 {#examples}

```yaml
  Skills:
  - setpitch{amount=45} @EIR{r=10}
```
