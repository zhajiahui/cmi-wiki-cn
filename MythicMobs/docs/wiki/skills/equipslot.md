# 装备槽位 {#equip-slot}

MythicMobs 定义了一组有效的装备槽位，供配置时使用。

| 槽位 | 别名 |
| --- | --- |
| HEAD | HELMET, HELM, HAT |
| CHEST | CHESTPIECE, CHESTPLATE, BODY |
| LEGS | LEGGINGS, PANTS |
| FEET | BOOTS, SHOES |
| HAND | MAINHAND, WEAPON |
| OFFHAND | SHIELD |
