# In Claim {#in-claim}

## 说明 {#description}

检查目标位置是否处于受支持的领地保护插件所定义的领地中。

支持的插件：

- GriefPrevention
- Lands
- CrashClaim
- PlotSquared
- Residence

## 属性 {#attributes}

*此条件没有属性*

## 示例 {#examples}

```yaml
  Conditions:
  - inclaim false
```

```yaml
  TargetConditions:
  - inclaim false
```
