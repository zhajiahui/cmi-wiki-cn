# Height {#height}

## 说明 {#description}

检查目标的 Y 位置是否在范围内

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| height | h | 目标 Y 坐标的范围。 |  |

## 示例 {#examples}

```yaml
  Conditions:
  - height{h=<50} true
```
