# Lineofsight {#lineofsight}

## 说明 {#description}

测试目标是否在施法者的视线范围内。如果目标隐藏在方块后面，则返回   false  

## 属性 {#attributes}

> *此条件没有属性*

## 示例 {#examples}

```yaml
  TargetConditions:
  - lineofsight
```
