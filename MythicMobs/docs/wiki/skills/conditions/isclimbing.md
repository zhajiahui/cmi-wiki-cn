# Is Climbing {#is-climbing}

## 说明 {#description}

检查目标实体是否正在攀爬。爬梯子的玩家或爬墙的蜘蛛都符合条件。

## 属性 {#attributes}

*此条件没有属性*

## 示例 {#examples}

```yaml
  Conditions:
  - isClimbing true
```

## 别名 {#aliases}
