# Velocity {#velocity}

## 说明 {#description}

根据范围检查目标实体的速度

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| velocity | v | 要检查的速度。 |  |

## 示例 {#examples}

```yaml
  Conditions:
  - velocity{v=<3} true
```
