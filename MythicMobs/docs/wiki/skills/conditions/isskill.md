# Is Skill {#is-skill}

## 说明 {#description}

检查指定的元技能是否存在

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| name | n, skill, s | 要检查是否存在的元技能。 |  |

## 示例 {#examples}

```yaml
  Conditions:
  - isSkill{skill=ExampleMetaSkill}
```
