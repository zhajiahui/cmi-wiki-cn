# Dawn {#dawn}

## 说明 {#description}

检查目标位置的世界时间是否为黎明，从游戏时间22000到2000。

## 属性 {#attributes}

*此条件没有属性*

## 示例 {#examples}

```yaml
  Conditions:
  - dawn true
```
