# Heightabove {#heightabove}

## 说明 {#description}

检查目标的 Y 位置是否高于某个值

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| height | h | 目标必须高于的高度。 |  |

## 示例 {#examples}

```yaml
  Conditions:
  - heightabove{h=50} true
```
