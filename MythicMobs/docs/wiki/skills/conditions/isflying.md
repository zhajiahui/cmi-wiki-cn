# Isflying {#isflying}

## 说明 {#description}

检查玩家是否正在飞行。实际上仅适用于创造模式式的飞行。要检查鞘翅滑翔，请使用[滑翔条件](gliding.md)。

## 属性 {#attributes}

*此条件没有属性*

## 示例 {#examples}

```yaml
  TargetConditions:
  - isFlying true
```

## 别名 {#aliases}

- flying
