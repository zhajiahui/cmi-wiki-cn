# Color {#color}

## 说明 {#description}

检查绵羊、潜影贝、猫（类型）、鹦鹉（变种）、马、羊驼和行商羊驼的颜色。

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| color | clr, c | 要检查的颜色。 | WHITE |

## 示例 {#examples}

```yaml
  Conditions:
  - color{c=RED} true
```

## 别名 {#aliases}

- clr
