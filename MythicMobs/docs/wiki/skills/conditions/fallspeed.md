# Fallspeed {#fallspeed}

## 说明 {#description}

如果目标的下落速度在给定范围内

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| speed | s | 要匹配的速度。 |  |

## 示例 {#examples}

```yaml
  Conditions:
  - fallspeed{s=>5} true
```
