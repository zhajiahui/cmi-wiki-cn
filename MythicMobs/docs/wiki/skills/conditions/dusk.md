# Dusk {#dusk}

## 说明 {#description}

检查目标位置的世界时间是否为黄昏，从游戏时间14000到18000。

## 属性 {#attributes}

*此条件没有属性*

## 示例 {#examples}

```yaml
  Conditions:
  - dusk true
```
