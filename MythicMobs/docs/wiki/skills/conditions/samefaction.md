# Samefaction {#samefaction}

## 说明 {#description}

此条件检查目标实体是否与施法者属于同一阵营。

## 属性 {#attributes}

*此条件没有属性*

## 示例 {#examples}

```yaml
  TargetConditions:
  - samefaction true
```
