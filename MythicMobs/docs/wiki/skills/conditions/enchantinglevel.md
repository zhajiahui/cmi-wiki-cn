# Enchanting Level {#enchanting-level}

## 说明 {#description}

检查目标玩家的经验等级

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| level | l | 要检查的经验等级范围。 | 0 |

## 示例 {#examples}

```yaml
  TargetConditions:
  - EnchantingLevel{l=<10} true
```
