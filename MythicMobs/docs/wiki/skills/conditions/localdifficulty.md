# Localdifficulty {#localdifficulty}

## 说明 {#description}

测试目标位置的难度等级。

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| difficulty | diff, d | 要检查的难度范围。 |  |

## 示例 {#examples}

```yaml
  Conditions:
  - localdifficulty{d=>0}
```
