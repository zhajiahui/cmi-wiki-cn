# Food Saturation {#food-saturation}

## 说明 {#description}

检查目标的食物饱和量

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| amount | a, food, f, saturation, s | 要检查的饱和度范围。 | 0 |

## 示例 {#examples}

```yaml
  TargetConditions:
  - FoodSaturation{a=<1} true
```
