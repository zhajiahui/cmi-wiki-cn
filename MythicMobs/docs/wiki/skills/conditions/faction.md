# Faction {#faction}

## 说明 {#description}

检查目标实体是否属于指定阵营

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| faction | f | 要检查的阵营。 |  |

## 示例 {#examples}

```yaml
TargetConditions:
- faction{faction=MyFaction} true
```
