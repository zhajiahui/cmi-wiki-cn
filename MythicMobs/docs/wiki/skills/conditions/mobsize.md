# Mobsize {#mobsize}

## 说明 {#description}

检查可变大小实体的体型，例如史莱姆、岩浆怪和幻翼。

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| size | s | 要检查的大小范围。 |  |

## 示例 {#examples}

```yaml
- size{s=>5} true
```
