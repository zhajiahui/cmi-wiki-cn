# Size {#size}

## 说明 {#description}

检查目标实体的大小。   有效实体：`Slime`、`Magmacube`、`Phantom`

## 属性 {#attributes}

| 参数 | 别名 | 说明 | 默认值 |
| --- | --- | --- | --- |
| size | s | 要检查的大小。 |  |

## 示例 {#examples}

```yaml
  TargetConditions:
  - size{s=>1} true
```

## 别名 {#aliases}

- mobSize
