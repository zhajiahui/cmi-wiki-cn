# Lineofsightfromorigin {#lineofsightfromorigin}

## 说明 {#description}

检查目标是否处于元技能原点的视线内，即从元技能原点能否以任意方向看到目标实体。

## 属性 {#attributes}

> *此条件没有属性*

## 示例 {#examples}

```yaml
  TargetConditions:
  - lineofsightfromorigin 
```
