# Children {#children}

## 说明 {#description}

选中施法者召唤的所有子实体。若使用 [summon](../mechanics/summon.md) 机制召唤时将 `summonerIsOwner` 设为 `true`，也适用于玩家施法者。

## 属性 {#attributes}

> *此目标选择器没有属性*

## 示例 {#examples}

```yaml
  Skills:
  - heal{a=10} @Children
```

## 别名 {#aliases}

- child
- summons
