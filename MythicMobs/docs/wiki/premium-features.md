# 付费版功能

# Premium 版功能 {#premium-features}

## 付费版 {#premium}

[MythicMobs Premium](https://mythiccraft.io/index.php?resources/mythicmobs.1/product-purchases) 附带许多仅限 Premium 的福利，包括：

- Discord 中的专属 Premium 身份组。
- 访问高级支持渠道
- 更早获取最新版本。
- 获取开发构建版本。
- 使用仅限高级机制，例如[光线追踪](skills/mechanics/raytrace.md)和[链式导弹](skills/mechanics/chainmissile.md)！
- 使用自定义伤害类型和伤害修正。
- 能够在以下位置使用数学和[占位符](skills/placeholders.md)：
  - 生物属性（生命值、伤害等）
  - 大多数技能
  - 物品属性
  - 掉落表数量
- 能够使用[技能参数](skills/metaskills.md#skill-parameters-premium-feature)
- 能够使用[内嵌目标条件](skills/inline-conditions.md)
- 在[弹射物技能](skills/mechanics/projectile.md)中使用命中条件和反弹。
- 使用带条件的 [AI 行为或目标选择器](mobs/custom-ai.md)。
- 在任意技能机制中使用 `origin=@targeter`。
- 更多！

MythicMobs Premium 解锁的功能也适用于兼容的 Mythic 插件，包括 Crucible、RPG、Enchantments、Achievements、Dungeons 等。

随着时间的推移，更多的高级功能将继续添加。你可以[点击此处](https://mythiccraft.io/index.php?resources/mythicmobs.1/product-purchases)将你的帐户升级到高级版。

## Premium+ {#premium-2}

对于那些希望多捐赠一点或拥有大型服务器的人，我们的 Premium+ 套餐为你提供了一些额外的好处：

- Discord 中的专属 Premium+ 身份组。
- 支持工单优先处理，并可联系开发者。
- 许可证可用于你拥有的多台服务器。
