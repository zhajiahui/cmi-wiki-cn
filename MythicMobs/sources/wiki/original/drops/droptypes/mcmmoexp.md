# Mc M M O Exp

## Description {#description}

When dropped, a given amount of McMMO exp is given to the trigger, if a player.  
A `<drop.amount>` [placeholder](https://wiki.mythiccraft.io/mythicmobs/Skills/Placeholders#misc-placeholders) can be used inside the reward message to fetch the amount of exp being given. This message can be configured inside the `config-general.yml` file

## Attributes {#attributes}

> *This drop has no attributes*

## Examples {#examples}

```yaml
  Drops:
  - mcmmo-exp 20
```

## Aliases {#aliases}
