# Advanced User Guides And Techniques

In this page you can find the more advanced uses of the plugin.  
But still, be aware that you **must be an advanced user yourself** in order to properly understand and use these techniques in a reasonable and just manner. Because, while they are certainly a powerful tool, these techniques can be detrimental for you, either if used improperly or if relied on too heavily in the early stages of learning about the plugin

## Advanced Techniques {#advanced-techniques}

| Technique | Description |
| --- | --- |
| [Intratick Scheduling](https://wiki.mythiccraft.io/mythicmobs/Skills/Intratick-Scheduling) | Schedule chunks of a SkillTree to be executed later in the same tick |
| [Dynamic Metaskills](https://wiki.mythiccraft.io/mythicmobs/Skills/Dynamic-Metaskills) | Create and execute new inline Metaskills at runtime |
| [Placeholder Parsing](https://wiki.mythiccraft.io/mythicmobs/Skills/Placeholder-Parsing) | Additional info regarding how placeholder parsing is executed |
