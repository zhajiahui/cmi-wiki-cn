# Heightabove

## Description {#description}

Checks if the target's Y location is above a value

## Attributes {#attributes}

| Attribute | Aliases | Description | Default |
| --- | --- | --- | --- |
| height | h | The height they must be above |  |

## Examples {#examples}

```yaml
  Conditions:
  - heightabove{h=50} true
```
