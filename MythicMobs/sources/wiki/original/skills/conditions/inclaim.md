# In Claim

## Description {#description}

Checks if the target location is inside a supported Land Protection claim.

Supported Plugins:

- GriefPrevention
- Lands
- CrashClaim
- PlotSquared
- Residence

## Attributes {#attributes}

*This condition has no attributes*

## Examples {#examples}

```yaml
  Conditions:
  - inclaim false
```

```yaml
  TargetConditions:
  - inclaim false
```
