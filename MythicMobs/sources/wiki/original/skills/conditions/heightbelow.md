# Heightbelow

## Description {#description}

Checks if the target's Y location is below a given value

## Attributes {#attributes}

| Attribute | Aliases | Description | Default |
| --- | --- | --- | --- |
| height | h | The height they must be below |  |

## Examples {#examples}

```yaml
  Conditions:
  - heightbelow{h=50} true
```
