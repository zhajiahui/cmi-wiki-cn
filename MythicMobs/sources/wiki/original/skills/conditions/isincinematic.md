# Is In Cinematic

## Description {#description}

Checks if the target player is currently in an active cinematic camera path.

Returns true while the player is being moved by a [cinematicCamera](https://wiki.mythiccraft.io/mythicmobs/Skills/Mechanics/CinematicCamera) mechanic, and false once the cinematic has ended or been cancelled.

## Attributes {#attributes}

*This condition has no attributes*

## Examples {#examples}

```yaml
  Conditions:
  - isInCinematic true
```

## Aliases {#aliases}

- incinematic
- incine
- cinematicactive
