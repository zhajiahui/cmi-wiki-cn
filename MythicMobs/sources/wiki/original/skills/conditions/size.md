# Size

## Description {#description}

Checks the size of the target entity.  
Valid entities: `Slime`, `Magmacube`, `Phantom`

## Attributes {#attributes}

| Attribute | Aliases | Description | Default |
| --- | --- | --- | --- |
| size | s | The size to check for |  |

## Examples {#examples}

```yaml
  TargetConditions:
  - size{s=>1} true
```

## Aliases {#aliases}

- mobSize
