# Height

## Description {#description}

Checks if the target's Y location is within a range

## Attributes {#attributes}

| Attribute | Aliases | Description | Default |
| --- | --- | --- | --- |
| height | h | The range of the Y location of the target |  |

## Examples {#examples}

```yaml
  Conditions:
  - height{h=<50} true
```
