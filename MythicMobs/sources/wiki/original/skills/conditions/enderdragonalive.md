# Ender Dragon Alive

## Description {#description}

Checks if there is at least one EnderDragon alive in the world of the targeted location

## Attributes {#attributes}

> *This condition has no attributes*

## Examples {#examples}

```yaml
  Conditions:
  - enderdragonalive true
```

## Aliases {#aliases}

- isdragonalive
- dragonalive
