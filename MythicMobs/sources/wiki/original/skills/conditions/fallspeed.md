# Fallspeed

## Description {#description}

If the fall speed of the target is within the given range

## Attributes {#attributes}

| Attribute | Aliases | Description | Default |
| --- | --- | --- | --- |
| speed | s | The velocity to match |  |

## Examples {#examples}

```yaml
  Conditions:
  - fallspeed{s=>5} true
```

## Aliases {#aliases}

- fallingspeed
