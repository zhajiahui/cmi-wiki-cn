# Is Invulnerable

## Description {#description}

Checks whether the target entity is invulnerable

## Attributes {#attributes}

> *This mechanic has no attributes*

## Example {#example}

```yaml
  TargetConditions:
  - isInvulnerable false
  Skills:
  - damage{a=1}
```

## Aliases {#aliases}

- isInvincible
