# Isflying

## Description {#description}

Checks if the evaluated player is flying. Only really works for creative-type fly. To check if an entity is gliding via the use of an elytra, use the [Gliding condition](https://wiki.mythiccraft.io/mythicmobs/skills/conditions/gliding).

## Attributes {#attributes}

*This condition has no attributes*

## Examples {#examples}

```yaml
  TargetConditions:
  - isFlying true
```

## Aliases {#aliases}

- flying
