# Xdiff

## Description {#description}

Checks the difference in x value between the target entity and the caster.

## Attributes {#attributes}

| Attribute | Aliases | Description | Default |
| --- | --- | --- | --- |
| difference | diff, d | The x difference to check |  |

## Examples {#examples}

```yaml
  TargetConditions:
  - xDiff{diff=>5} true
```
