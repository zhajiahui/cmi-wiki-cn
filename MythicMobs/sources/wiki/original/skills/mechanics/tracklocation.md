# Tracklocation

## Description {#description}

Sets the casting mob's tracked location to the targeted location.  
Please note that a player cannot have a tracked location.  
This location can then be used via the relevant [Targeter](https://wiki.mythiccraft.io/mythicmobs/Skills/Targeters/TrackedLocation) and [Condition](https://wiki.mythiccraft.io/mythicmobs/skills/conditions/distancefromtrackedlocation).

## Attributes {#attributes}

> *This mechanic has no attributes*

## Examples {#examples}

```yaml
  Skills:
  - tracklocation @targetlocation
```
