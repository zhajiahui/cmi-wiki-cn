# Ender

## Description {#description}

Plays the effect of an eye of ender breaking at the location of the targeter.

## Attributes {#attributes}

> *This mechanic has no attributes*

## Examples {#examples}

```yaml
EnderSkill:
  Skills:
  - ender @self ~onTimer:20
```
