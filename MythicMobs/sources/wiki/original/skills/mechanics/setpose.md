# Set Pose

## Description {#description}

Sets the entity's [pose](https://jd.papermc.io/paper/1.21.6/org/bukkit/entity/Pose.html)

## Attributes {#attributes}

| Attribute | Aliases | Description | Default |
| --- | --- | --- | --- |
| pose | p | The pose to assign |  |

## Examples {#examples}

```yaml
  Skills:
  - setpose{pose=DYING}
```
