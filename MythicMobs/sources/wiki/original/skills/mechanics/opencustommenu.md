# Open Custom Menu

## Description {#description}

Opens a [custom menu](https://wiki.mythiccraft.io/mythicmobs/Custom-Menus)

> **This feature requires either [MythicMobs Premium](https://wiki.mythiccraft.io/mythicmobs/Premium-Features) or [MythicRPG](https://mythiccraft.io/index.php?resources/mythicrpg-spells-classes-professions-more.129/) to be used!**

## Attributes {#attributes}

| Attribute | Aliases | Description | Default |
| --- | --- | --- | --- |
| menu | m | The menu to open | default |

## Examples {#examples}

```yaml
  Skills:
  - opencustommenu{m=ExampleMenu} @trigger ~onInteract
```

## Aliases {#aliases}

- openMenu
