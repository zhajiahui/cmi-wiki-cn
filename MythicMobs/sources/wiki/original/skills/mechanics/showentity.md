# Showentity

## Description {#description}

Shows the caster, if hidden via the use of the [hide](https://wiki.mythiccraft.io/mythicmobs/skills/mechanics/hide) mechanic, to the targeted players.

## Attributes {#attributes}

> *This mechanic has no attributes*

## Examples {#examples}

```yaml
  Skills:
  - showEntity @NearestPlayer{r=10}
```

## Aliases {#aliases}

- showplayer
