# Taunt

## Description {#description}

Modifies the threat level that the caster holds with the target entities

## Attributes {#attributes}

| Attribute | Aliases | Description | Default |
| --- | --- | --- | --- |
| mode | m | How the threat should be assigned | taunt |

> This mechanic inherits every attribute of the [threat](https://wiki.mythiccraft.io/mythicmobs/skills/mechanics/threat) mechanic

## Examples {#examples}

```yaml
  Skills:
  - taunt @EIR{r=20}
```
