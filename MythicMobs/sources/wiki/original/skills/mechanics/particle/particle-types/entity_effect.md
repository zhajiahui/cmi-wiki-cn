# Entity Effect

## Particle {#particle}

![img](https://wiki.mythiccraft.io/_media/mythicmobs/Skills/Mechanics/Particle/Particle-Types/images/ENTITY_EFFECT.gif)

## Attributes {#attributes}

| Attribute | Aliases | Description | Default |
| --- | --- | --- | --- |
| color | c | The color of the particle | #FF0000 |

> This particle has a [Color](https://wiki.mythiccraft.io/mythicmobs/Skills/Mechanics/Particle/Particle-Types#color) Datatype, and inherits all of its attributes

## Examples {#examples}

```yaml
  Skills:
  - particle{p=entity_effect;color=#FF0000}
```
