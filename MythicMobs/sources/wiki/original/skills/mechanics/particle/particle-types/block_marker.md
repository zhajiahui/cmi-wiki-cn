# Block Marker

## Particle {#particle}

![img](https://wiki.mythiccraft.io/_media/mythicmobs/Skills/Mechanics/Particle/Particle-Types/images/BLOCK_MARKER.gif)

## Attributes {#attributes}

| Attribute | Aliases | Description | Default |
| --- | --- | --- | --- |
| material | m | The material the blockdata particle will be based on | STONE |

> This particle has a [Blockdata](https://wiki.mythiccraft.io/mythicmobs/Skills/Mechanics/Particle/Particle-Types#blockdata) Datatype, and inherits all of its attributes

## Examples {#examples}

```yaml
  Skills:
  - particle{p=block_marker;material=STONE}
```
