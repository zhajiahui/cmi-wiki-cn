# Print Parent Tree

## Description {#description}

Prints debug information regarding the Metaskill executing the mechanic and its SkillTree

## Attributes {#attributes}

> *This mechanic has no attributes*

## Examples {#examples}

```yaml
Example1:
  Skills:
  - skill{s=Example2}

Example2:
  Skills:
  - skill{s=Example3}

Example3:
  Skills:
  - printParentTree
```
