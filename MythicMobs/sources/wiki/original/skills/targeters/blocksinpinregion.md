# Blocks In Pin Region

## Description {#description}

Targets the blocks in a region delimited by two pins

## Attributes {#attributes}

| Attribute | Aliases | Description | Default |
| --- | --- | --- | --- |
| pin1 | p1 | The first [pin](https://wiki.mythiccraft.io/mythicmobs/Pins) |  |
| pin2 | p2 | The second [pin](https://wiki.mythiccraft.io/mythicmobs/Pins) |  |

## Examples {#examples}

```yaml
  - particle @BlocksInPinRegion{p1=mypin;p2=anotherpin}
```
