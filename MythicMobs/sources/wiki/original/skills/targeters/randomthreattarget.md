# Random Threat Target

## Description {#description}

Targets a random entity on the casting mob's [Threat Table](https://wiki.mythiccraft.io/mythicmobs/Mobs/ThreatTables)

## Attributes {#attributes}

> *This targeter has no attributes*

## Examples {#examples}

```yaml
  Skills:
  - ignite @RandomThreatTarget
```
