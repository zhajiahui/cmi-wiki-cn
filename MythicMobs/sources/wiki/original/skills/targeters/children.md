# Children

## Description {#description}

Targets any child entities summoned by the caster.  
Works for player casters, if the [summon](https://wiki.mythiccraft.io/mythicmobs/skills/mechanics/summon) mechanic was used and the `summonerIsOwner` attribute was set to `true`.

## Attributes {#attributes}

> *This targeter has no attributes*

## Examples {#examples}

```yaml
  Skills:
  - heal{a=10} @Children
```

## Aliases {#aliases}

- child
- summons
