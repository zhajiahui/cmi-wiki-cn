# Entities In Ring Near Origin

## Description {#description}

Targets all the entities in a ring near the [origin](https://wiki.mythiccraft.io/mythicmobs/Skills/Targeters/Origin).  
Inherits all attributes from [EntitiesInRing](https://wiki.mythiccraft.io/mythicmobs/Skills/Targeters/EntitiesInRing)

## Attributes {#attributes}

> This mechanic inherits every attribute of the [EntitiesInRing](https://wiki.mythiccraft.io/mythicmobs/Skills/Targeters/EntitiesInRing) targeter

## Examples {#examples}

```yaml
  Skills:
  - ignite @entitiesInRingNearOrigin{min=2;max=10}
```
