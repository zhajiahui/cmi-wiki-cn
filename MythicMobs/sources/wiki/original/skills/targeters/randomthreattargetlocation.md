# Random Threat Target Location

## Description {#description}

Targets the location of a random entity on the casting mob's [Threat Table](https://wiki.mythiccraft.io/mythicmobs/Mobs/ThreatTables)

## Attributes {#attributes}

> *This targeter has no attributes*

## Examples {#examples}

```yaml
  Skills:
  - effect:particles{y=2} @RandomThreatTargetLocation
```

## Aliases {#aliases}

- RTTL
