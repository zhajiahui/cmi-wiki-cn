# Go To Location

## Description {#description}

Makes the mob go to the specified location. Notice: Followrange must more than the distance between location and mob

## Attributes {#attributes}

> *This aigoal has no attributes*

## Examples {#examples}

```yaml
  AIGoalSelectors:
  - clear
  - goto 10,20,30
```

## Aliases {#aliases}

- goto
