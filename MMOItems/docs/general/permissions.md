# 权限 {#🧑‍⚖️-permissions}

以下是权限及其功能的列表。

|权限|描述 |
| --- | --- |
| `mmoitems.admin` | 权限用于管理命令 |
| `mmoitems.bypass.level` | 绕过物品等级限制 |
| `mmoitems.bypass.item` | 绕过物品权限限制 |
| `mmoitems.bypass.ability` | 绕过能力权限限制 |
| `mmoitems.bypass.class` | 绕过MMOCore职业限制 |
| `mmoitems.update` | 允许使用 /updateitem 命令 |
| `mmoitems.edit.op` | 允许管理员编辑 config.yml 中 op-item-stats 列出的属性。 |
