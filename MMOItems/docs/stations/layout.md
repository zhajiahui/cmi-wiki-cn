# 合成站界面布局 {#🖼️-station-ui-layouts}

本页介绍如何在MMOItems中编辑合成站的布局。

> **信息**
>
> 此功能完全取代了MMOItems6.10.1开发版本中删除的“UI 布局”。

自MMOItems6.10.1开发构建以来，合成站的GUI布局现在都是可配置的。主UI布局可在`gui-layout`配置部分下配置，right-click预览UI可在`confirm-gui-layout`配置部分下配置。

语法与MMOCore和MMOProfilesUI 相同。你可以编辑物品的材料、位置、名称和知识。你还可以编辑物品栏名称和大小。

> **信息**
>
> 更多相关信息稍后将在MythicLibwiki 上提供，因为 UI 语法在所有 MMO 插件之间共享。
