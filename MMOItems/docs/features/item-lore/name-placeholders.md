# 名称占位符 {#🏷️-name-placeholders}

> **信息**
>
> 将来这些将扩展为完整的物品描述，而不仅仅是其物品名称

显示名称占位符旨在通过使物品名称统一和动态来使物品创建一致。每当定义物品的显示名称时，只需将用法占位符放在某处，它就会自动替换。

|占位符|用途 |描述 |
| --- | --- | --- |
| Tier Name | `<tier-name>` | 显示物品层的未格式化名称。 |
| Tier Color | `<tier-color>` | 充当物品层名称的颜色代码。 |
| Tier Color Cleaned | `<tier-color-cleaned>` | 与层颜色相同，但删除粗体、斜体、下划线、删除线和魔术。 |
| Type Name | `<type-name>` | 显示物品类型的未格式化名称。 |
