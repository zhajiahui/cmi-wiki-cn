# 描述格式 {#📜-lore-format}

描述格式决定了物品的描述的外观。你可以在 languages 文件夹中找到默认的lore-format.yml文件。可以将其他格式添加到语言内的lore-formats文件夹中。每当你启动服务器或重新加载插件时，你的格式都会加载。

另外，MMOItems支持【微信](https://docs.adventure.kyori.net/minimessage/format.html)！你现在可以在物品描述内使用 MiniMessage 颜色代码和文本装饰！

## 创建和使用描述格式 {#creating-and-using-a-lore-format}

要创建新的描述格式，只需将默认的copy-paste文件放入lore-format.yml文件夹中并开始编辑即可。你的新描述格式将被分配一个 ID，该 ID 等于文件夹内的文件名。使用此ID将新的lore-format分配给物品。
