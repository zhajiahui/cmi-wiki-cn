# PacketEvents 是什么？

<a id="minecraft-protocol-library"></a>

## Minecraft 协议库

PacketEvents 是面向 Minecraft Java 版的协议库，用于处理和传输数据包。该库由 [retrooper](https://github.com/retrooper) 于 2020 年 4 月 17 日创立。PacketEvents 依赖网络应用框架 Netty，因此可以在多种基于 Netty 的 Minecraft 平台上使用，例如 _Paper、Spigot、Velocity、BungeeCord、Fabric 和 Sponge_。

<a id="a-new-beginning"></a>

### 新的起点

_PacketEvents 2.0_ 的目标是让代码高效、便于移植，让开发者编写一次代码就能在多个平台运行。由于 PacketEvents 依赖 Netty，开发者甚至可以编写自己的 Minecraft 服务端实现，而无需过多操心网络部分。
