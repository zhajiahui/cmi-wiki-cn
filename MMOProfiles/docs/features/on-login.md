# 登录时的处理 {#😉-when-logging-in}

玩家登录后会进入无敌状态，并被要求在档案界面中选择档案，见下一页。选择后，该档案的全部数据会加载并应用到玩家身上。玩家可以在界面中创建或删除档案，但同时拥有的档案数量有上限，可通过组别系统完整自定义，详见后文。

以下列出了在档案之间保存和切换的全部原版数据：

- 生命值、饥饿值与饱和度
- 氧气值
- 等级与经验
- 上次所在位置与床的重生位置
- 物品栏、装备与末影箱
- 游戏模式
- 药水效果
- 原版属性
