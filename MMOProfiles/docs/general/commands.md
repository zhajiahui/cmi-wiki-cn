# 命令 {#💾-commands}

|命令 |描述 |
| --- | --- |
| `/mmoprofiles reload` | 重载插件和配置文件。注意，部分选项需要重启服务器后才会生效。 |
| `/mmoprofiles open <player-name>` | 为指定玩家打开档案选择界面。仅应在启用 `no-gui-on-login` 时使用。 |
| `/mmoprofiles export-data` | 将玩家数据从文件存储导出到 SQL。 |
