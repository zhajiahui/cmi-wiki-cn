# 🦾 Compatibility {#🦾-compatibility}

The main feature of this plugin is to enable other plugins to use its API and also have profile-based data. A plugin that supports MMOProfiles will have its data saved for the profile and not for the player, and changing profile will be as if you logged in with a different account.

## MMO Plugins {#mmo-plugins}

The full MMO plugin suite ([MMOCore](https://docs.phoenixdevt.fr/mmocore/), [MMOInventory](https://docs.phoenixdevt.fr/mmoinventory/), [MMOItems](https://docs.phoenixdevt.fr/mmoitems/), [MythicLib](https://docs.phoenixdevt.fr/mythiclib/)) **FULLY SUPPORTS** profile-based data storage.

## Vault Economy {#vault-economy}

MMOProfiles saves the player's Vault balance. This way, any Vault-based economy plugin is supported by MMOProfiles.

## CoreTools {#coretools}

CoreTools ([SpigotMC](https://www.spigotmc.org/resources/coretools.125126) - [Polymart](https://polymart.org/product/7372/coretools) - [Wiki](https://gitlab.com/ranetdev/CoreTools/-/wikis/home)) fully supports profile-based data storage.

## BeautyQuests new {#beautyquests}

[BeautyQuests](https://www.spigotmc.org/resources/beautyquests.39255) supports MMOProfiles, enabling profile-specific quest progression. To enable compatibility with BeautyQuests, download and install [AccountsHook](https://www.spigotmc.org/resources/accountshook.59491/), which exposes the MMOProfiles profile API to BeautyQuests.

> **INFO**
>
> You no longer need to install the addon called *AccountsHook-MMOProfiles*.

## BetonQuest {#betonquest}

BetonQuest is on its way to supporting MMOProfiles natively. The plugin already has a profile system ready for players to have multiple profiles, so MMOProfiles integration is on its way!
