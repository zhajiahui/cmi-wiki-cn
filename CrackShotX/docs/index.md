# CrackShotX 1.1.0 随包版

本页记录随包的 **CrackShotX 1.1.0**。它是依赖 CrackShot 的附属插件，注册的主命令为 `/csx`。

本批 1.1.0 与旧官方资料之间的对应关系尚未核实。以下内容仅依据随包版本的插件描述信息，不将旧版功能和命令直接套用到本批版本。

## 依赖

必需插件为 **CrackShot**。

软依赖为 ProtocolLib、packetevents、MythicMobs、AttributePlus、NeigeItems、PlaceholderAPI、WorldGuard、WorldEdit。

## 命令和权限声明

随包版本注册主命令 `/csx`，并声明以下权限节点：

```text
crackshotx.admin
crackshotx.panel
crackshotx.panel.others
crackshotx.panel.history
crackshotx.bypass.region
```

当前资料不足以确认各子命令的参数及这些节点的具体作用，因此不按节点名称推断操作方法。

## 来源

随包版本的插件描述未提供作者或官方网站，本次未确认对应的公开官方文档或仓库。
