# 台阶、楼梯、门等

### 台阶和楼梯

你无法创建具有实体碰撞的自定义台阶和楼梯。\
问题在于 Minecraft 不允许为自定义方块设置自定义碰撞箱。

未来，我可能通过一些变通办法实现，但目前还做不到。
