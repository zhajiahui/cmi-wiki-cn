# Geyser

### Geyser 尚未正式支持。

Geyser 是一个复杂的插件，将资源包插件集成到 Bedrock 和 Java 上以获得相同的体验并不容易。

将来我可能会写一些官方教程或官方兼容层，但目前我不建议在你的服务器上使用 Geyser。
