# 透明家具

要制作透明或半透明纹理，必须使用支持透明的原版物品作为基础物品。\
例如 **`WHITE_STAINED_GLASS`**

### 示例

```yaml
resource:
  material: WHITE_STAINED_GLASS
  generate: false
  model_path: item/your_model
```
