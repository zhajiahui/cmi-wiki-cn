# 自定义画（ItemsAdderAdditions）

自定义画由 [ItemsAdderAdditions](https://itemsadderadditions.com/en/docs/custom-paintings) 提供。

需要 **Paper 1.21.5 或更高版本**。

自定义画允许直接在 ItemsAdder YML 文件中注册真正的 Minecraft 画变体。玩家可以在游戏中遇到它们；启用相应配置后，原版画物品也可以随机选择这些变体。

完整文档见[这里](https://itemsadderadditions.com/en/docs/custom-paintings)。
