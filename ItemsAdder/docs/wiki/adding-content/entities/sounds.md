# 声音

## 播放声音

切换到“**Animate**”视图。

![](../../assets/8f0f164dd6f6d9c4927e.png)

选择一个动画。

![](../../assets/8bd9d23eb61260625a60.png)

选择魔杖图标“**Animate Effects**”

![](../../assets/5c2903c31d4dedd9cd27.png)

点击“**Sound**”效果类型旁的 **+** 图标，创建粒子关键帧。

![](../../assets/2e37713eaf3036dbe929.png)

在“**Keyframe**”面板中编辑数值。

* Name：声音名称，使用 Minecraft 游戏内声音名称，也可以使用资源包中的自定义声音。
* Volume：声音音量。
* Pitch：声音音高。<br>

![](../../assets/f9da06e70c390e848689.png)
