# 骑乘

## 示例


## 设置乘坐位置

使用 **Blockbench** 打开你的 `.iaentitymodel` 模型文件。

新建骨骼。

![](../../assets/cc95c94c8d5e08dfdc08.png)

右键点击骨骼，选择“**Bone Config**”

![](../../assets/a5597dd4d3e2d3ece843.png)

勾选“**Mount**”选项，再点击“**Confirm**”。

![](../../assets/b741c256ada415c762cb.png)

为需要创建的每个座位重复此操作。

![](../../assets/64279207bb7586c25ca0.png)

![](../../assets/001a35ad05ec86c8ddd3.png)

![](../../assets/70762cc1b26cae13c96e.png)

![](../../assets/934889efa13704cc9899.png)

然后照常导出模型。

[advanced-method.md](advanced-method.md)

## 如何骑乘

只需右键点击实体并驾驶它。

只有第一个坐上实体的玩家可以控制它。
