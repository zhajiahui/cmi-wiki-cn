# 碰撞箱

## 设置

### 配置头部骨骼

用 **Blockbench** 打开 `.iaentitymodel` 模型文件。\
新建一个骨骼，名称不限。

![](../../assets/6ce05589066d624ade16.png)

调整碰撞箱大小。



![](../../assets/5932b5f88c9815bbfbd4.png)

![](../../assets/a7c4bb94815fcb4e3b5b.png)

* XYZ 位置无关紧要。
* 只有 XY 尺寸重要，Z 尺寸不重要。这是 Minecraft 的限制，是游戏中碰撞箱的工作方式。

右键点击骨骼并选择“**Bone Config**”

![](../../assets/dbd2c9d872ff60affd61.png)

勾选“**Hitbox**”选项并按“**Confirm**”。

![](../../assets/242568436af32550a8fa.png)
