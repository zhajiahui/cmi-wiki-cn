# Font

#### 示例字体

![](../../assets/4e602d9a43ade848c763.png)

此字体由 Faithful 团队制作。

操作步骤：

* 从[这里](https://www.dropbox.com/s/06et55587zvcmr7/FaithfulFont.zip?dl=0)下载 Faithful 字体
* 将内容解压到 `plugins/ItemsAdder/contents/my_font/font/`
* 打开 config.yml 并设置 `custom-font enabled: true`

#### 自定义字体示例

![](../../assets/d718494d55075df72b59.png)

操作步骤：

* 从[这里](http://matteodev.it/spigot/itemsadder/res/v2/font.zip)下载日文字体
* 将内容解压到 `plugins/ItemsAdder/contents/my_font/minecraft/font/`
* 打开 config.yml 并设置 `custom-font enabled: true`

Minecraft 存在一个错误，使用自定义 TTF 字体时可能导致游戏崩溃。

此问题只出现在部分 Intel 集成显卡和较旧的游戏版本中，插件侧无从修复；[详情见这里](https://bugs.mojang.com/browse/MC-180529?jql=text%20~%20%22ttf%20crash%22)。
