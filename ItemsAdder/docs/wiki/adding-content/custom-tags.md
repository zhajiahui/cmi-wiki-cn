# 自定义标签（ItemsAdderAdditions）

自定义标签由 [ItemsAdderAdditions](https://itemsadderadditions.com/en/docs/custom-tags) 提供。

将内容 ID 分组后，即可在支持的 ItemsAdderAdditions 功能中重复使用。标签从任意 ItemsAdder 内容 YAML 文件顶层的 `tags` 配置节加载。

完整文档见[这里](https://itemsadderadditions.com/en/docs/custom-tags)。
