# iarename

此命令可用于重命名物品（原版和自定义）。

支持[字体图片](../../../adding-content/font-images/font-images.md)（表情符号）和[文本效果](../../../adding-content/text-effects-1.17+.md)。

使用示例：`/iarename test <r qqqqq> :smile: very nice`

![](../../../assets/0d06240e70bf840db0ad.png)

### 权限

`ia.admin.iarename`
