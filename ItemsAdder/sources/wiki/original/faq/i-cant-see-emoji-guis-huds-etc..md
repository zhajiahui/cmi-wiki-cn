
# I can't see emoji, GUIs, HUDs etc.

* Open `config.yml` of **ItemsAdder**
*   Enable this option:

    ```yaml
    fix_force_unicode_font_images: true
    ```
* Run `/iazip` to regenerate your resourcepack
* Follow the [hosting method tutorial](/plugin-usage/plugin-configuration/resourcepack-hosting.md) you decided during plugin installation
