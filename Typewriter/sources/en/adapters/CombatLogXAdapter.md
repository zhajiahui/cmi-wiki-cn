# Combat Log X Adapter

The CombatLogX Adapter allows you to create entries that are triggered when a player enters or leaves combat.

**Untested**

This adapter is untested. It may not work as expected. Please report any issues you find.

## Entries {#entries}

### Events {#events}

| Name | Description |
| --- | --- |
| [Player Enter Combat Event](https://docs.typewritermc.com/adapters/CombatLogXAdapter/entries/event/on_player_enter_combat) | When a player enters combat |
| [Player Exit Combat Event](https://docs.typewritermc.com/adapters/CombatLogXAdapter/entries/event/on_player_exit_combat) | When a player is no longer in combat |

### Facts {#facts}

| Name | Description |
| --- | --- |
| [Combat Fact](https://docs.typewritermc.com/adapters/CombatLogXAdapter/entries/fact/combat_fact) | If the player is in combat |
