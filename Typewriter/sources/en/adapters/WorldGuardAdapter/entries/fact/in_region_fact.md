# In Region Fact

A [fact](https://docs.typewritermc.com/docs/creating-stories/facts) that checks if the player is in a specific region. The value will be `0` if the player is not in the region, and `1` if the player is in the region.

This fact can only be **read**, not written to. Hence, it is only suitable for criteria.

## How could this be used? {#how-could-this-be-used}

This fact could be used to make a quest only available in a specific region.
