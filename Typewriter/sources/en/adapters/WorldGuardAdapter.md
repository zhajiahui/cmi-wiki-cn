# World Guard Adapter

The WorldGuard Adapter allows you to create dialogue that is triggered by WorldGuard regions.

## Entries {#entries}

### Audiences {#audiences}

| Name | Description |
| --- | --- |
| [Region Audience](https://docs.typewritermc.com/adapters/WorldGuardAdapter/entries/audience/region_audience) | Filter players based on if they are in a region |

### Events {#events}

| Name | Description |
| --- | --- |
| [Enter Region Event](https://docs.typewritermc.com/adapters/WorldGuardAdapter/entries/event/on_enter_region) | When a player enters a WorldGuard region |
| [Exit Region Event](https://docs.typewritermc.com/adapters/WorldGuardAdapter/entries/event/on_exit_region) | When a player exits a WorldGuard region |

### Facts {#facts}

| Name | Description |
| --- | --- |
| [In Region Fact](https://docs.typewritermc.com/adapters/WorldGuardAdapter/entries/fact/in_region_fact) | If the player is in a WorldGuard region |

### Groups {#groups}

| Name | Description |
| --- | --- |
| [Region Group](https://docs.typewritermc.com/adapters/WorldGuardAdapter/entries/group/region_group) | All players grouped by WorldGuard regions |
