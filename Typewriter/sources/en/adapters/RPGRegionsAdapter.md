# Rpg Regions Adapter

The RPGRegions Adapter is an adapter for the RPGRegions plugin. It allows you to use RPGRegions's discovery system in your dialogue.

**Untested**

This adapter is untested. It may not work as expected. Please report any issues you find.

## Entries {#entries}

### Actions {#actions}

| Name | Description |
| --- | --- |
| [Discover Region Action](https://docs.typewritermc.com/adapters/RPGRegionsAdapter/entries/action/discover_rpg_region) | Create a discover for an RPGRegions region |

### Events {#events}

| Name | Description |
| --- | --- |
| [Discover Region Event](https://docs.typewritermc.com/adapters/RPGRegionsAdapter/entries/event/on_discover_rpg_region) | When a player discovers an RPGRegions region |
| [Enter Region Event](https://docs.typewritermc.com/adapters/RPGRegionsAdapter/entries/event/on_enter_rpg_region) | When a player enters a RPGRegions region |

### Facts {#facts}

| Name | Description |
| --- | --- |
| [In Region Fact](https://docs.typewritermc.com/adapters/RPGRegionsAdapter/entries/fact/in_rpg_region_fact) | If the player is in a RPGRegions region |
