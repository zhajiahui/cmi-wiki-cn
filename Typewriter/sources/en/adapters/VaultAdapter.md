# Vault Adapter

The Vault Adapter is an adapter for the Vault plugin. It allows you to use Vault's economy system in your dialogue.

## Entries {#entries}

### Actions {#actions}

| Name | Description |
| --- | --- |
| [Deposit Balance Action](https://docs.typewritermc.com/adapters/VaultAdapter/entries/action/deposit_balance) | Deposit Balance |
| [Set Prefix Action](https://docs.typewritermc.com/adapters/VaultAdapter/entries/action/set_prefix) | Set Prefix |
| [Withdraw Balance Action](https://docs.typewritermc.com/adapters/VaultAdapter/entries/action/withdraw_balance) | Withdraw Balance |

### Facts {#facts}

| Name | Description |
| --- | --- |
| [Balance Fact](https://docs.typewritermc.com/adapters/VaultAdapter/entries/fact/balance_fact) | The balance of a player's account |
| [Permission Fact](https://docs.typewritermc.com/adapters/VaultAdapter/entries/fact/permission_fact) | If the player has a permission |
