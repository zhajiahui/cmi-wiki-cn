# Interact Entity Objective

The `InteractEntityObjective` class is an entry that represents an objective to interact with an entity.
When such an objective is active, it will show an icon above any NPC.

## Fields {#fields}

## Children

Required List

## Quest

Required

## Criteria

Inherited List

A list of facts that must be met by the player before this entry can be triggered.

## Entity

Required

The entity that the player needs to interact with.

## Override Display

Optional

The objective display that will be shown to the player. Use <entity> to replace the entity name.

## Priority Override

Optional
