# Mythic Mobs Adapter

The MythicMobs Adapter is an adapter for the MythicMobs plugin. It allows you handle mob-related things in Typewriter.

**Untested**

This adapter is untested. It may not work as expected. Please report any issues you find.

## Entries {#entries}

### Actions {#actions}

| Name | Description |
| --- | --- |
| [Despawn Mob Action](https://docs.typewritermc.com/adapters/MythicMobsAdapter/entries/action/despawn_mythicmobs_mob) | Despawn a mob from MythicMobs |
| [Execute Skill Action](https://docs.typewritermc.com/adapters/MythicMobsAdapter/entries/action/execute_mythicmob_skill) | Executes a MythicMobs skill |
| [Spawn Mob Action](https://docs.typewritermc.com/adapters/MythicMobsAdapter/entries/action/spawn_mythicmobs_mob) | Spawn a mob from MythicMobs |
