# Citizens Adapter

The Citizens adapter allows you to create custom interactions with NPCs.

## Entries {#entries}

### Cinematics {#cinematics}

| Name | Description |
| --- | --- |
| [Reference Npc Cinematic](https://docs.typewritermc.com/adapters/CitizensAdapter/entries/cinematic/reference_npc_cinematic) | A reference to an existing npc specifically for cinematic |
| [Self Npc Cinematic](https://docs.typewritermc.com/adapters/CitizensAdapter/entries/cinematic/self_npc_cinematic) | The player itself as an cinematic npc |

| Name | Description |
