# Chat Contains Text Event

The `Chat Contains Text Event` is called when a player sends a chat message containing certain text.

## How could this be used? {#how-could-this-be-used}

When a player mentions something, you could display dialogue to them.

## Fields {#fields}

## Triggers

Required List

## Text

Required Regex

The text to look for in the message.

[`Regular expressions`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_Expressions) can be used to match a pattern. For example, `^.*$` will match any string.

## Exact Same

Required

If the text should be matched exactly or not.
