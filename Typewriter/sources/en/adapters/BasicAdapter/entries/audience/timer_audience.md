# Timer Audience

The `Timer Audience` entry is an audience filter that triggers an action every specified duration when the player is in the audience.

**caution**

Very short durations can cause performance issues, and may be inaccurate.

## How could this be used? {#how-could-this-be-used}

This can be used to trigger a sequence every few seconds.

## Fields {#fields}

## Duration

Required

Durations can be specified in the following format: `1d 2h 3m 4s`. The following units are supported: `d` for days, `h` for hours,`m` for minutes and `s` for seconds.

## On Timer

Required
