# Quest Status Update Event

The `Quest Status Update Event` entry is triggered when a quest status is updated for a player.

When no quest is referenced, it will trigger for all quests.

## How could this be used? {#how-could-this-be-used}

This could be used to show a title or notification to a player when a quest status is updated.

## Fields {#fields}

## Triggers

Required List

## Quest

Required

When not set it will trigger for all quests.

## From

Optional

When not set it will trigger for all statuses.

## To

Required

The status the quest is updated to.
