# Set Item Action

The `Set Item Action` is an action that sets an item in a specific slot in the player's inventory.

## How could this be used? {#how-could-this-be-used}

This can be used to equip a player with an elytra, or give them a weapon.

## Fields {#fields}

## Criteria

Inherited List

A list of facts that must be met by the player before this entry can be triggered.

## Modifiers

Inherited List

A list of facts that will be modified for the player when this entry is triggered.

## Triggers

Required List

## Item

Required

The item to set.

## Slot

Required

The slot to set the item in.
