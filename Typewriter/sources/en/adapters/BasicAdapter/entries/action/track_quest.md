# Track Quest Action

The `Track Quest Action` is an action that tracks a quest when triggered.

Though quests are tracked automatically, this action can force a quest to be tracked.

## How could this be used? {#how-could-this-be-used}

Start tacking a quest, so it displays in the player's quest tracker.

## Fields {#fields}

## Criteria

Inherited List

A list of facts that must be met by the player before this entry can be triggered.

## Modifiers

Inherited List

A list of facts that will be modified for the player when this entry is triggered.
