# Stop Sound Action

The `Stop Sound` action is used to stop a or all sounds for a player.

## How could this be used? {#how-could-this-be-used}

This action can be useful in situations where you want to stop a sound for a player.
For example, when leaving a certain area, you might want to stop the music that was playing.

## Fields {#fields}

## Criteria

Inherited List

A list of facts that must be met by the player before this entry can be triggered.

## Modifiers

Inherited List

A list of facts that will be modified for the player when this entry is triggered.

## Triggers

Required List

## Sound

Optional

The sound to stop. If this field is left blank, all sounds will be stopped.
