# Simple Action

The `Simple Action` is an empty action that can be used to modify facts.

## How could this be used? {#how-could-this-be-used}

This action can be useful in situations where you need to modify facts, or want to filter different actions based om some criteria,
but don't need to perform any additional actions.

## Fields {#fields}

## Criteria

Inherited List

A list of facts that must be met by the player before this entry can be triggered.

## Modifiers

Inherited List

A list of facts that will be modified for the player when this entry is triggered.

## Triggers

Required List
