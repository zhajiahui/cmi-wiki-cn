# Switch Server Action

The `Switch Server Action` is an action that switches the player to another server.

## How could this be used? {#how-could-this-be-used}

This could be used to switch a player from one server to another when interacting with an entity, maybe clicking a button.

## Fields {#fields}

## Criteria

Inherited List

A list of facts that must be met by the player before this entry can be triggered.

## Modifiers

Inherited List

A list of facts that will be modified for the player when this entry is triggered.

## Triggers

Required List

## Server

Required

The server the player has switched to
