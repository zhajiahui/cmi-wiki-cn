# Firework Action

The `Firework Action Entry` is an action that spawns a firework.

## How could this be used? {#how-could-this-be-used}

This could be used to create a firework that displays a specific effect.

## Fields {#fields}

## Triggers

Required List

## Criteria

Inherited List

A list of facts that must be met by the player before this entry can be triggered.

## Modifiers

Inherited List

A list of facts that will be modified for the player when this entry is triggered.

## Location

Required

The location to spawn the firework.

## Effects

Required List

The effects to display on the firework.

## Power

Required

The power of the firework.
