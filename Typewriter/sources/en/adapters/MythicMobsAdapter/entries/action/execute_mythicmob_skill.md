# Execute Skill Action

The `Execute Skill Action` action executes a MythicMobs skill.

## How could this be used? {#how-could-this-be-used}

Create fancy particle animations.
For example, you can create a little animation when a player opens a door.

## Fields {#fields}

## Triggers

Required List

## Criteria

Inherited List

A list of facts that must be met by the player before this entry can be triggered.

## Modifiers

Inherited List

A list of facts that will be modified for the player when this entry is triggered.

## Skill Name

Required

The name of the skill to execute
