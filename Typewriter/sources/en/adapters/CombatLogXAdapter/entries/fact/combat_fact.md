# Combat Fact

A [fact](https://docs.typewritermc.com/docs/creating-stories/facts) that tells whether a player is in combat.

This fact can only be **read**, not written to. Hence, it is only suitable for criteria.

## How could this be used? {#how-could-this-be-used}

This could be used to disable certain actions when the player is in combat.
