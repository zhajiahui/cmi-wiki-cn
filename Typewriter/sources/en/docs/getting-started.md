# Getting Started

Typewriter is designed to be flexible with easy to use in mind, allowing you to create interactive experiences for your players without needing to write code all via a webpanel. This guide will help you install and configure Typewriter. The layout page will explain how the webpanel works.

## To get started, follow these pages: {#to-get-started-follow-these-pages}

## [Installation Guide](https://docs.typewritermc.com/docs/getting-started/installation)

Typewriter only works on paper servers. It will not work on Spigot or Bukkit servers.

## [Layout](https://docs.typewritermc.com/docs/getting-started/layout)

On this page, you will learn how to use the Typewriter Web panel and create certain things.

**Developers**

For developers interested in adding even more functionality to Typewriter, we recommend reading the [extensions development guide](https://docs.typewritermc.com/develop).
