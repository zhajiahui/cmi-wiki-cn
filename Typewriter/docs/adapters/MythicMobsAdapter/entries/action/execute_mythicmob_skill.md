# 执行技能（Execute Skill Action）

`Execute Skill Action`动作执行MythicMobs技能。

## 用途示例 {#how-could-this-be-used}

创建精美的粒子动画。
例如，你可以在玩家打开门时创建一个小动画。

## 字段 {#fields}

## 后续触发（Triggers）

必填 · 列表

## 条件（Criteria）

继承 · 列表

此条目触发前，玩家必须满足的事实条件列表。

## 修改器（Modifiers）

继承 · 列表

此条目触发时，要为玩家修改的事实列表。

## 技能名称（Skill Name）

必填

执行的技能名称
