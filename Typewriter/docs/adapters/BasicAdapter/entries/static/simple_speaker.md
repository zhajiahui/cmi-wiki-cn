# 简单说话者（Simple Speaker）

`Spoken Dialogue Action`是一个向玩家显示动画消息的动作。此操作使你能够显示具有指定说话者、文本和持续时间的消息。

## 用途示例 {#how-could-this-be-used}

可以用它来创建故事情节、向玩家提供说明或创建身临其境的角色扮演体验。也可以用于其他场景。

## 字段 {#fields}

## 显示名称（Display Name）

必填

## 声音（Sound）

必填
