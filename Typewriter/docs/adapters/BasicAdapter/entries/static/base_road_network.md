# 基础道路网络（Base Road Network）

`Simple Road Network`是道路网络的定义。
道路网络是一个由互连的节点和边缘组成的系统，代表了世界上的一个网络。

## 用途示例 {#how-could-this-be-used}

让NPC畅游世界。
并让玩家通过向他们展示前进的道路来探索世界。
