# 玩家自身说话者（Self Speaker）

`Self Speaker`是代表玩家本身的说话者。
该说话者用于从玩家的角度显示消息。

## 用途示例 {#how-could-this-be-used}

该说话者可用于从玩家的角度显示消息，
例如想法或内部对话。
它还可以用作玩家声音的声源。

## 字段 {#fields}

## 声音（Sound）

必填

## 覆盖名称（Override Name）

可选

覆盖说话者的显示名称
