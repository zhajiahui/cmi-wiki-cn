# 任务开始事件（Quest Start Event）

当玩家开始任务时，`Quest Start Event`条目就会被触发。

未指定任务时，所有任务都可触发此事件。

## 用途示例 {#how-could-this-be-used}

这可用于在任务开始时向玩家显示标题或通知。

## 字段 {#fields}

## 后续触发（Triggers）

必填 · 列表

## 任务（Quest）

必填

未设置时，它将触发所有任务。
