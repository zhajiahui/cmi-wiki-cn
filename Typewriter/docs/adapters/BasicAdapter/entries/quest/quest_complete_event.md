# 任务完成事件（Quest Complete Event）

当玩家完成任务时，会触发`Quest Complete Event`条目。

未指定任务时，所有任务都可触发此事件。

## 用途示例 {#how-could-this-be-used}

这可用于在任务完成时向玩家显示标题或通知。

## 字段 {#fields}

## 后续触发（Triggers）

必填 · 列表

## 任务（Quest）

必填

未设置时，它将触发所有任务。
