# 已追踪目标受众（Tracked Objective Audience）

`Tracked Objective Audience`条目根据受众是否有跟踪目标来过滤受众。
它会检查玩家是否从正在追踪的任务中显示出目标。

## 用途示例 {#how-could-this-be-used}

可根据玩家当前是否有正在显示的目标，决定是否显示 Boss 栏或侧边栏。
