# 处于受众中事实（In Audience Fact）

`In Audience Fact`是一个事实，指定玩家是否在受众中。

此事实仅供**读取**，无法写入，因此只适合用于条件判断。

## 用途示例 {#how-could-this-be-used}

如果玩家属于特定受众，这可用于过滤玩家。

## 备注（Comment）
