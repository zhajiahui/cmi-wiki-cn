# 会话事实（Session Fact）

该[事实](../../../../docs/creating-stories/facts.md)被存储直到玩家注销为止。

## 用途示例 {#how-could-this-be-used}

这可以用来慢慢累加玩家的总玩时间，并在达到一定时间时奖励他们徽章或其他奖励。

## 字段 {#fields}

## 备注（Comment）

继承 · 可选

用于跟踪该事实用途的注释。

## 组（Group）

必填
