# 倒计时事实（Countdown Fact）

`Cooldown Fact`是反映自上次设置值以来的时间的事实。

当该值设定后，它会从设定值开始每秒倒计时。

假设该值设置为 10。
3秒后，该值将变为7。

无论玩家在线/离线、服务器在线/离线，倒计时都会继续。

## 用途示例 {#how-could-this-be-used}

这可用于创建特定操作的冷却时间。
例如，玩家每天只能获得一次的每日奖励。
