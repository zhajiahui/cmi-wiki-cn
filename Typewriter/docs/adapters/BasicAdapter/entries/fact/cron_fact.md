# Cron 事实（Cron Fact）

保存到指定日期之前的[事实](../../../../docs/creating-stories/facts.md)，例如 (0 0 * * 1)。

## 用途示例 {#how-could-this-be-used}

这一事实可用于创建每周奖励，每周都会重置。或者模拟商店的营业时间。

## 字段 {#fields}

## 备注（Comment）

继承 · 可选

用于跟踪该事实用途的注释。

## 组（Group）

必填

## Cron 表达式

必填

事实过期时使用的 [Cron 表达式](https://www.netiq.com/documentation/cloud-manager-2-5/ncm-reference/data/bexyssf.html)。
