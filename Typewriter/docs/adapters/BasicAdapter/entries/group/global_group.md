# 全局组（Global Group）

`Global Group`是一个包含所有在线玩家的组。

## 用途示例 {#how-could-this-be-used}

这可以用来获得所有玩家都相同的事实，
就像所有参与者必须共同努力才能实现的全局目标一样。
