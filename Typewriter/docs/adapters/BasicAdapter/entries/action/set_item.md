# 设置物品（Set Item Action）

`Set Item Action`是一个将物品放置在玩家物品栏特定位置的操作。

## 用途示例 {#how-could-this-be-used}

这可以用来给玩家装备鞘翅，或者给他们武器。

## 字段 {#fields}

## 条件（Criteria）

继承 · 列表

此条目触发前，玩家必须满足的事实条件列表。

## 修改器（Modifiers）

继承 · 列表

此条目触发时，要为玩家修改的事实列表。

## 后续触发（Triggers）

必填 · 列表

## 物品（Item）

必填

要设置的物品。

## 槽位（Slot）

必填

放置物品的槽位。
