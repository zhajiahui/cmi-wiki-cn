# 切换服务器（Switch Server Action）

`Switch Server Action`是将玩家切换到另一个服务器的操作。

## 用途示例 {#how-could-this-be-used}

这可用于在与实体交互时（可能单击按钮）将玩家从一个服务器切换到另一个服务器。

## 字段 {#fields}

## 条件（Criteria）

继承 · 列表

此条目触发前，玩家必须满足的事实条件列表。

## 修改器（Modifiers）

继承 · 列表

此条目触发时，要为玩家修改的事实列表。

## 后续触发（Triggers）

必填 · 列表

## 服务器（Server）

必填

玩家要切换到的服务器。
