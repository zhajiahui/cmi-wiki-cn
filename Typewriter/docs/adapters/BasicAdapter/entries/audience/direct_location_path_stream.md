# 直达位置路径流（Direct Location Path Stream）

`Direct Location Path Stream`条目是一个路径流，显示到特定位置的路径。
当玩家有此条目时，将显示到指定位置的路径流。

## 用途示例 {#how-could-this-be-used}

这可以用来显示通往世界上特定位置的路径。

## 字段 {#fields}

## 道路（Road）

必填

## 目标位置（Target Location）

必填
