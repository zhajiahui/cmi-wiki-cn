# 触发受众（Trigger Audience）

`Trigger Audience`条目是受众过滤器，当玩家进入或退出受众时会触发序列。

## 用途示例 {#how-could-this-be-used}

这可以用来弥合受众和序列页面之间的差距。

## 字段 {#fields}

## 进入时（On Enter）

必填

玩家加入受众时触发的序列。

## 离开时（On Exit）

必填

玩家离开受众时触发的序列。
