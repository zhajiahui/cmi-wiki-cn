# 组员路径流（Group Members Path Stream）

`Group Members Path Stream`条目是一个路径流，显示到每个组成员的路径。
“组成员”由与玩家处于同一组的组成员决定。

当没有设置组时，路径流不会显示任何内容。

## 用途示例 {#how-could-this-be-used}

这可用于显示一组玩家中每个组成员的路径。
当玩家想要找到任何其他组员时，他们可以沿着各自的路径进行寻找。

## 字段 {#fields}

## 道路（Road）

必填

## 组（Group）

必填
