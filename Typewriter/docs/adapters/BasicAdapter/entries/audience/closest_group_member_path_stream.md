# 最近组员路径流（Closest Group Member Path Stream）

`Closest Group Member Path Stream`条目是一个路径流，显示到最近的组成员的路径。
“最近组员”按地理位置与玩家的距离判断，
**不是按路径距离计算。**

当没有设置组时，路径流不会显示任何内容。
玩家必须位于同一个世界，路径流才会考虑他们。

## 用途示例 {#how-could-this-be-used}

这可用于显示到达一组玩家中最近的组成员的路径。
当玩家迷路时，他们可以沿着路径找到最近的组员。

## 字段 {#fields}

## 道路（Road）

必填

## 组（Group）

必填
