# Cron 受众（Cron Audience）

`Cron Audience`条目根据真实时间是否与 cron 表达式匹配来过滤受众。
这将使用服务器的时间，而不是玩家的时间。

## 用途示例 {#how-could-this-be-used}

这可以用于限时事件，例如假期。
