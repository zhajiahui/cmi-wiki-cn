# 位置目标路径流（Location Objectives Path Stream）

`Location Objectives Path Stream`条目是一个路径流，显示每个跟踪位置目标的路径。
当玩家有位置目标并且跟踪该目标的任务时，将显示路径流。

## 用途示例 {#how-could-this-be-used}

这可用于显示任务中到达每个位置目标的路径。

## 字段 {#fields}

## 道路（Road）

必填
