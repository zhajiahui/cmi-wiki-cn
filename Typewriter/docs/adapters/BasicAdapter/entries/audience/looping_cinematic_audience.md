# 循环过场动画受众（Looping Cinematic Audience）

`Looping Cinematic Audience`条目用于向受众展示循环播放的过场动画。

**建议此条目受位置或区域限制，
以防止玩家收到他们看不到的过场动画的数据包。**

**注意**

过场动画只能具有与循环兼容的条目（非主条目）。
任何不能同时激活两个或多个实例的方法都将不起作用。

## 用途示例 {#how-could-this-be-used}

循环显示粒子，例如喷泉。
或从断裂电线中冒出的火花。

## 字段 {#fields}

## 过场动画 ID（Cinematic Id）

必填
