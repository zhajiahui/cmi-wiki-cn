# 玩家列表页眉与页脚（Tab List Header Footer）

`TabListHeaderFooterEntry` 用于设置玩家列表的页眉和页脚。
该条目接受页眉和页脚的文本行，
并在玩家列表中显示。

## 字段 {#fields}

## 页眉（Header）

必填 · 列表

玩家列表页眉要显示的文本行。

## 页脚（Footer）

必填 · 列表

玩家列表页脚要显示的文本行。

## 优先级覆盖（Priority Override）

可选
