# 玩家接近位置事件（Player Near Location Event）

`PlayerNearLocationEventEntry`类表示当玩家位于某个位置的特定范围内时触发的事件。

## 用途示例 {#how-could-this-be-used}

这可用于创建身临其境的游戏体验，例如当玩家接近特定位置时触发特殊事件或对话。
例如，当玩家接近隐藏的宝藏时，可能会显示提示或生成守护者。

## 字段 {#fields}

## 后续触发（Triggers）

必填 · 列表

## 位置（Location）

必填

玩家应该靠近的位置。

## 范围（Range）

必填

事件应触发的范围。
