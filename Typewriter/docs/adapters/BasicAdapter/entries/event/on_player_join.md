# 玩家加入事件（Player Join Event）

当玩家加入服务器时，会调用`Player Join Event`事件。

## 用途示例 {#how-could-this-be-used}

这可以与[事实](../../../../docs/creating-stories/facts.md)一起使用，向新玩家发出欢迎消息，或欢迎新玩家回来。你还可以使用它为新玩家提供起始物品，或者通过[Vault 适配器](../../../VaultAdapter.md)为他们提供起始金额。
