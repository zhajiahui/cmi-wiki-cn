# 放置方块事件（Block Place Event）

玩家在世界中放置方块时，触发 `Block Place Event`。

## 用途示例 {#how-could-this-be-used}

可用于创建放置时播放粒子或声音的自定义方块，也可以让方块放置后变成一座建筑。

## 字段 {#fields}

## 后续触发（Triggers）

必填 · 列表

## 位置（Location）

可选

放置的方块的位置。

## 方块（Block）

必填

放置的块。
