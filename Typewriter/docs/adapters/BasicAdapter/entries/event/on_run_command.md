# 运行命令事件（Run Command Event）

运行命令时会触发`Run Command Event`事件。此事件可用于向服务器添加自定义命令。

**注意**

此事件用于创建**尚不存在**的命令。如果要检测玩家执行已有命令，请使用 [`Detect Command Ran Event`](on_detect_command_ran.md)。
