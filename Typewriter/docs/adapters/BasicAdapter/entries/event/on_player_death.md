# 玩家死亡事件（Player Death Event）

当任何玩家死亡时，`Player Death Event`就会被触发。如果你愿意，此事件允许你选择死亡原因。如果你想检测其他玩家何时杀死玩家，请使用[`Player Kill Player Event`](on_player_kill_player.md)。

## 用途示例 {#how-could-this-be-used}

你可以为某些类型的死亡创建自定义死亡消息，例如坠落、溺水或被其他玩家杀死。

## 字段 {#fields}

## 后续触发（Triggers）

必填 · 列表

## 死亡原因（Death Cause）

可选

如果指定，死亡原因必须与死亡原因匹配才能触发事件。
