# 破坏方块事件（Block Break Event）

当玩家打破方块时，`Block Break Event`就会被触发。

## 用途示例 {#how-could-this-be-used}

这可以让你用自定义掉落物制作自定义矿石，在打破一定数量的方块后给玩家奖励。

## 字段 {#fields}

## 后续触发（Triggers）

必填 · 列表

## 方块（Block）

可选

被破坏的方块。

## 位置（Location）

可选

被破坏的方块的位置。

## 手中物品（Item In Hand）

必填

当方块被破坏时玩家必须持有的物品。
