# 拾取物品事件（Pickup Item Event）

当玩家拿起物品时，`Pickup Item Event`就会被触发。

## 用途示例 {#how-could-this-be-used}

当玩家拿起特定物品时，此事件可用于触发任务或触发过场动画。

## 字段 {#fields}

## 后续触发（Triggers）

必填 · 列表

## 物品（Item）

必填

要收听的物品。
