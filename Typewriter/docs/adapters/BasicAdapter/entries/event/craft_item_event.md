# 合成物品事件（Craft Item Event）

当玩家制作物品时，`Craft Item Event`会被触发。
来源可以是工作台、熔炉、锻造台、营火或其他合成方式。

## 用途示例 {#how-could-this-be-used}

这可以用于完成玩家必须制作特定物品的任务，或者在玩家制作特定物品时给予玩家奖励。

## 字段 {#fields}

## 后续触发（Triggers）

必填 · 列表

## 合成的物品（Crafted Item）

必填

被制作出来的物品。
