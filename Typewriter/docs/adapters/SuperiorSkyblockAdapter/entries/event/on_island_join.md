# 加入岛屿事件（Island Join Event）

当玩家加入岛屿时，`Island Join Event`就会被触发。

## 用途示例 {#how-could-this-be-used}

此事件可用于“更好地在一起”系统，玩家可以加入岛屿并因此获得奖励。
