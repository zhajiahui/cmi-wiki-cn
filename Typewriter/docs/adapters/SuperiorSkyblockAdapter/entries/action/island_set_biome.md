# 设置岛屿生物群系（Island Set Biome Action）

`Island Set Biome`动作用于设置玩家岛屿的生物群系。

## 用途示例 {#how-could-this-be-used}

这可以用来模拟一年中的季节，或者改变岛屿的生物群系以匹配岛屿的主题。

## 字段 {#fields}

## 条件（Criteria）

继承 · 列表

此条目触发前，玩家必须满足的事实条件列表。

## 修改器（Modifiers）

继承 · 列表

此条目触发时，要为玩家修改的事实列表。

## 后续触发（Triggers）

必填 · 列表

## 生物群系（Biome）

必填

将岛屿设置为的生物群系
