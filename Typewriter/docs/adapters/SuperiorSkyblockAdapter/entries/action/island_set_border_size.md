# 设置岛屿边界大小（Island Set Border Size Action）

`Island Set Border Size`操作用于设置玩家岛屿的边界大小。

## 用途示例 {#how-could-this-be-used}

它可以用来奖励玩家完成任务或达到一定水平。

## 字段 {#fields}

## 条件（Criteria）

继承 · 列表

此条目触发前，玩家必须满足的事实条件列表。

## 修改器（Modifiers）

继承 · 列表

此条目触发时，要为玩家修改的事实列表。

## 后续触发（Triggers）

必填 · 列表

## 大小（Size）

必填

设置岛屿边界的大小
