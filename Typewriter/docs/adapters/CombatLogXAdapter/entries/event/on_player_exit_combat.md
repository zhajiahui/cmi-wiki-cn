# 玩家退出战斗事件（Player Exit Combat Event）

当玩家退出战斗时，`Player Exit Combat Event`就会被触发。

## 用途示例 {#how-could-this-be-used}

这可用于在玩家退出战斗时触发消息。或者统计玩家在某个区域退出战斗的次数并改变 NPC 的行为。
