# 玩家进入战斗事件（Player Enter Combat Event）

当一名玩家与另一名玩家进入战斗时，`Player Enter Combat Event`就会被触发。

## 用途示例 {#how-could-this-be-used}

这可用于在玩家与另一玩家战斗时播放声音效果。

## 后续触发（Triggers）

必填 · 列表

## 攻击者触发项（Aggressor Triggers）

必填 · 列表

为发起攻击的攻击者触发的条目。
