# 引用 NPC（Reference Npc）

引用 Citizens 插件中的 NPC 的标识符。但不管理NPC。

## 用途示例 {#how-could-this-be-used}

这可以用来引用世界上已有的 NPC。这可以用来创建一个要求玩家与 NPC 交谈的任务。

## 字段 {#fields}

## 显示名称（Display Name）

必填

## 声音（Sound）

必填

## NPC ID（Npc Id）

必填

Citizens插件中NPC的id。
