# 引用 NPC 过场动画（Reference Npc Cinematic）

**弃用警告**

此条目已被标记为已弃用，并将在未来版本中删除。

推荐替代方案：`Use the EntityAdapter instead`（改用 EntityAdapter）。

`Reference NPC Cinematic`条目在参考 NPC 上播放录制的动画。
激活时，原始 NPC 将被隐藏，并会在其位置生成一个克隆。

## 用途示例 {#how-could-this-be-used}

这可用于创建玩家与 NPC 交谈的动画。
就像走进商店并与店主交谈一样。
