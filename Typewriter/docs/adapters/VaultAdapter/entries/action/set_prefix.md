# 设置前缀（Set Prefix Action）

`Set Prefix Action`操作设置玩家消息的前缀

## 用途示例 {#how-could-this-be-used}

这可以用于徽章系统。
当玩家完成某项任务时，比如杀死boss，
他们可以被赋予一个显示在聊天中的前缀，例如`[Deamon Slayer]`

## 字段 {#fields}

## 条件（Criteria）

继承 · 列表

此条目触发前，玩家必须满足的事实条件列表。

## 修改器（Modifiers）

继承 · 列表

此条目触发时，要为玩家修改的事实列表。

## 后续触发（Triggers）

必填 · 列表

## 前缀（Prefix）

必填

要设置的前缀。
