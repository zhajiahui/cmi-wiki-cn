# 余额组（Balance Group）

`Balance Audience` 根据余额是否满足条件对玩家分组。
判断玩家所属的组时，会逐个检查余额条件。
第一个满足的条件，决定玩家所属的组。

## 用途示例 {#how-could-this-be-used}

可用于让余额达到某一门槛的 VIP 玩家共用事实。
