# 权限组（Permission Group）

`Permission Group`是玩家拥有一定权限的组。
为了确定玩家是否属于该组，需要检查该玩家的权限。
如果玩家拥有所有权限，则他们是该组的一部分。

## 用途示例 {#how-could-this-be-used}

向所有捐赠者发送消息。
