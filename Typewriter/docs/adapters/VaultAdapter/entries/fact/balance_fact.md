# 余额事实（Balance Fact）

表示玩家余额的[事实](../../../../docs/creating-stories/facts.md)。

此事实仅供**读取**，无法写入，因此只适合用于条件判断。

## 用途示例 {#how-could-this-be-used}

可用于记录玩家的游戏内余额。例如，余额充足的玩家可以进入 VIP 区域，余额不足时则无法进入。

## 字段 {#fields}

## 备注（Comment）

继承 · 可选

用于跟踪该事实用途的注释。

## 组（Group）

必填
