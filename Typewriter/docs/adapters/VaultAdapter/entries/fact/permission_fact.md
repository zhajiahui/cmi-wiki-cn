# 权限事实（Permission Fact）

[事实](../../../../docs/creating-stories/facts.md)检查玩家是否具有特定权限。

## 用途示例 {#how-could-this-be-used}

该事实可用于检查玩家是否具有特定权限，例如检查玩家是否是管理员。

必填
