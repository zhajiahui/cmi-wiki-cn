# 发现区域事件（Discover Region Event）

当玩家发现一个区域时，`Discover Region Event`就会被触发。

## 用途示例 {#how-could-this-be-used}

当玩家发现某个区域时，此事件可用于触发向玩家发送的消息，例如欢迎消息。
或者当他们发现一个区域时，它可能会触发一个任务来开始并开始对话或过场动画。

## 字段 {#fields}

## 后续触发（Triggers）

必填 · 列表

## 区域（Region）

必填

要检查的区域。确保这是区域 ID，而不是区域的显示名称。
