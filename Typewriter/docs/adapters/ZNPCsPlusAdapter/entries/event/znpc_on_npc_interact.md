# NPC 交互事件（Npc Interact Event）

**弃用警告**

此条目已被标记为已弃用，并将在未来版本中删除。

推荐替代方案：`Use the EntityAdapter instead`（改用 EntityAdapter）。

当玩家与 NPC 互动时，`NPC Interact Event`就会被触发。

## 用途示例 {#how-could-this-be-used}

这可用于创建 NPC 和玩家之间发生的各种交互。例如，你可以创建一个 NPC，当玩家与之交互时，该 NPC 会为玩家提供一个物品。

## 标识符（Identifier）

必填

需要交互的NPC。
