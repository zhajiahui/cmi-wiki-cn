# 玩家自身 NPC 过场动画（Self Npc Cinematic）

**弃用警告**

此条目已被标记为已弃用，并将在未来版本中删除。

推荐替代方案：`Use the EntityAdapter instead`（改用 EntityAdapter）。

`Self NPC Cinematic` 使用带有玩家皮肤的 NPC，向玩家回放录制的动画。
如果NPC录音没有任何盔甲，则会使用播放过场动画时玩家的盔甲。

## 用途示例 {#how-could-this-be-used}

这可用于创建玩家与 NPC 交谈的动画。
就像走进商店并与店主交谈一样。
