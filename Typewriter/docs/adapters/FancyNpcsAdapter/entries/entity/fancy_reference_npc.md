# 引用 NPC（Reference Npc）

**弃用警告**

此条目已被标记为已弃用，并将在未来版本中删除。

推荐替代方案：`Use the EntityAdapter instead`（改用 EntityAdapter）。

引用 FancyNpcs 插件中 NPC 的标识符。但不管理NPC。

## 用途示例 {#how-could-this-be-used}

这可以用来引用世界上已有的 NPC。这可以用来创建一个要求玩家与 NPC 交谈的任务。

## 字段 {#fields}

## 显示名称（Display Name）

必填

## 声音（Sound）

必填

## NPC ID（Npc Id）

必填

FancyNpcs插件中NPC的id。
