# 碰撞箱定义（Hit Box Definition）

`HitBoxDefinition` 定义实体的碰撞箱，以便玩家与不同实体交互。

## 用途示例 {#how-could-this-be-used}

例如，展示实体本身没有可供交互的碰撞箱，就可能需要此定义。

## 字段 {#fields}

## 基础实体（Base Entity）

必填

## 偏移（Offset）

必填

碰撞箱相对于基础实体的偏移。

## 宽度（Width）

必填

命中框的宽度。

## 高度（Height）

必填

命中框的高度。
