# 具名实体定义（Named Entity Definition）

`NamedEntityDefinition`是一个以其他已定义实体为基础的实体，
显示名称和头上的指示器。

## 用途示例 {#how-could-this-be-used}

这可用于允许所有实体具有名称和指示符。
