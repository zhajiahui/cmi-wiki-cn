# 堆叠实体定义（Stacked Entity Definition）

`StackedEntityDefinition`类是代表实体堆栈的条目。

**注意**

所有属性将在所有实体之间共享。
即使它仅在一个实体上定义。

只有底部实体才会具有`StackedEntity`实例的位置。

## 用途示例 {#how-could-this-be-used}

这可用于将实体堆叠在一起。
就像生物上方有全息图一样。

## 字段 {#fields}

## 定义列表（Definitions）

必填 · 列表

将相互堆叠的实体。第一个实体将是底部实体。
