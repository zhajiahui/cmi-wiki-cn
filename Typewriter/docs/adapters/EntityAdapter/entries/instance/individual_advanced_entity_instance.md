# 个人高级实体实例（Individual Advanced Entity Instance）

`Individual Advanced Entity Instance`条目是一个实体实例
它具有每个查看实例的玩家独有的活动。

这意味着两个玩家可以在不同的地方看到同一个实例。

## 用途示例 {#how-could-this-be-used}

用于护送任务，玩家需要跟随npc，例如向导。
