# 直达实体实例路径流（Direct Entity Instance Path Stream）

`Direct Entity Instance Path Stream`条目是一个路径流，显示到特定实体实例的路径。
当玩家拥有此条目时，将显示到指定实体实例的路径流。

## 用途示例 {#how-could-this-be-used}

这可以用来显示世界上特定实体实例的路径。

## 字段 {#fields}

## 道路（Road）

必填

## 目标（Target）

必填
