# 目标位置活动（Target Location Activity）

`TargetLocationActivityEntry`是一项使实体导航到特定位置的活动。

仅当实体超出一定范围时，该活动才会激活。

## 用途示例 {#how-could-this-be-used}

这可用于使实体导航到特定位置。

## 字段 {#fields}

## 道路网络

必填

## 目标位置（Target Location）

必填

## 待机活动（Idle Activity）

必填

当实体位于目标位置时将使用的活动。
