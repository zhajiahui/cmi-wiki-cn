# 巡逻活动（Patrol Activity）

`PatrolActivity`是一项使实体在一组位置周围移动的活动。
该实体将按顺序移动到集合中的每个位置。
一旦实体到达最后一个位置，它将从第一个位置开始返回。

## 用途示例 {#how-could-this-be-used}

这可以用来让警卫在一组地点周围巡逻。
