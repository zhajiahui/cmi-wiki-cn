# 受众活动（Audience Activity）

`Audience Activity` 根据玩家所属的受众选择活动。
它会依次检查各个受众，
选择玩家所属的第一个受众对应的活动。

这只能用于单个实体实例。

## 用途示例 {#how-could-this-be-used}

例如，让保镖因某件事分心并走开，而且这种行为只对该玩家生效。

## 字段 {#fields}

## 活动（Activities）

必填 · 列表

## 默认活动（Default Activity）

必填

当玩家不在任何受众中时将使用的活动。
