# 路径活动（Path Activity）

`Path Activity`是一项沿着预定义路径移动的活动。
该实体将按顺序移动到集合中的每个位置。
一旦实体到达最后一个位置，它将执行空闲活动。

## 用途示例 {#how-could-this-be-used}

这可以用来让导游沿着重要的路径移动。

## 字段 {#fields}

## 道路网络

必填

## 节点（Nodes）

必填 · 列表

## 待机活动（Idle Activity）

必填

当实体位于最终位置时将使用的活动。
