# 近距离注视活动（Look Close Activity）

`LookCloseActivityEntry` 让实体看向离它最近的玩家。

这个活动按玩家分别生效，实体会看向相应的玩家。

## 用途示例 {#how-could-this-be-used}

这可以用来让实体看着最接近它的玩家。
