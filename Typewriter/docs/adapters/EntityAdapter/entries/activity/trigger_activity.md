# 触发活动（Trigger Activity）

`Trigger Activity`条目是一个活动，当活动开始或停止时会触发序列。

## 用途示例 {#how-could-this-be-used}

当实体到达某个位置时，这可以用来触发对话。
就像一个导游，当实体到达一个兴趣点时触发对话。

## 字段 {#fields}

## 活动（Activity）

必填

当此活动处于活动状态时要使用的活动。

## 开始时（On Start）

必填

活动开始时触发的序列。

## 停止时（On Stop）

必填

活动停止时触发的序列。
