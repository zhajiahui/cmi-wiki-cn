# 实体交互目标路径流（Interact Entity Objectives Path Stream）

`Interact Entity Objectives Path Stream`条目是一个路径流，显示每个交互实体目标的路径。
当玩家具有交互实体目标并且跟踪该目标的任务时，将显示路径流。

`Ignore Instances`字段是显示路径时应忽略的实体实例列表。

## 用途示例 {#how-could-this-be-used}

这可用于显示任务中每个交互实体目标的路径。

## 字段 {#fields}

## 道路（Road）

必填

## 忽略实例（Ignore Instances）

必填 · 列表
