# RPGRegions 适配器（Rpg Regions Adapter）

RPGRegions Adapter 是 RPGRegions 插件的适配器。它允许你在对话中使用 RPGRegions 的发现系统。

**未经测试**

该适配器未经测试。它可能无法按预期工作。请报告你发现的任何问题。
