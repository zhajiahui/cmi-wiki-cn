# SuperiorSkyblock 适配器（Superior Skyblock Adapter）

Superior Skyblock 适配器允许你将 Superior Skyblock 插件与Typewriter一起使用。
它包括许多供你在对话中使用的事件，以及一些操作和条件。

**未经测试**

该适配器未经测试。它可能无法按预期工作。请报告你发现的任何问题。
