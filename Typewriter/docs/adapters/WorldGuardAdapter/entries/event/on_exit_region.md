# 离开区域事件（Exit Region Event）

当玩家离开区域时，`Exit Region Event`被触发。

## 用途示例 {#how-could-this-be-used}

该事件可用于在玩家离开某个区域时触发消息，并向他们发送告别消息。
或者，如果你想创建一个区域，使其成为玩家无法受到攻击的“安全区”，则可以使用此事件在玩家离开该区域时触发消息。

## 字段 {#fields}

## 后续触发（Triggers）

必填 · 列表

## 区域（Region）

必填

玩家必须离开才能触发事件的区域。
