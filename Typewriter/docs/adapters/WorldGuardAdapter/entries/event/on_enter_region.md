# 进入区域事件（Enter Region Event）

当玩家进入某个区域时，会触发`Enter Region Event`。

## 用途示例 {#how-could-this-be-used}

此事件可用于在玩家进入某个区域时触发向玩家发送的消息，例如欢迎消息。
或者当他们进入一个区域时，可能会触发一个任务来开始并开始对话或过场动画。

## 字段 {#fields}

## 后续触发（Triggers）

必填 · 列表

## 区域（Region）

必填

玩家必须进入才能触发事件的区域。
