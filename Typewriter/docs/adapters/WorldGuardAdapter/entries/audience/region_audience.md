# 区域受众（Region Audience）

`Region Audience`用于根据玩家是否位于特定 WorldGuard 区域来过滤玩家。

## 用途示例 {#how-could-this-be-used}

当玩家进入特定区域时显示玩家信息。
例如，当玩家进入一个城镇时，你可以向他们显示有关该城镇的信息。

## 字段 {#fields}

## 子条目（Children）

必填 · 列表

## 区域（Region）

必填

根据区域过滤玩家

## 反转（Inverted）

必填
