# 界面布局（Layout）

在此页面上，你将学习如何使用Typewriter网页面板并创建某些内容。

## 创建页面 {#creating-a-page}

要创建页面，只需单击按钮`Add Page`，然后输入页面名称。它不能与已存在的页面重复名称。选择四种类型之一：

- **序列**：创建可以依次播放的交互。
- **静态**：引用在程序生命周期内不会更改的数据。
- **过场动画**：定时动作序列。
- **呈现**：在运行时计算的交互状态。

<video controls preload="metadata" src="../../assets/f450773f8ae2-add-page.webm"></video>

现在我们已经创建了序列页面，我将解释不同布局的工作原理。

## 基本布局 {#base-layout}

![序列页面布局](../../assets/20130e6c9f73-layout.6f3aedd.1920.avif)

1. **页面列表**：在这里你可以看到你创建的所有页面。你还可以在此处创建新页面。
2. **动作栏**：通过单击从左到右的按钮可以执行多种操作：
   - **暂存指示器**：橙色表示修改尚未在服务器上生效，绿色表示已经生效。将鼠标移到指示器上，会出现“Publish”按钮；点击即可将暂存页面发布到服务器。
   - **搜索栏**：使用此搜索条目或创建新条目。
   - **+ 按钮**：单击此处创建新条目。

**属性面板**：你可以在此处编辑所选条目的属性。

3. **条目信息**：在这里你可以查看条目的所有信息，例如 ID、名称等。
4. **字段**：使用此部分编辑条目的属性。
5. **操作**：此部分包含你可以对条目执行的各种操作。

## 序列、静态和呈现页面的布局 {#sequence-static-and-manifest-layout}

- 中心显示你的所有条目。
- 使用鼠标滚轮放大或缩小。
- 单击一个条目可在属性面板中将其打开。
- 长按条目几秒后，可以拖动它并连接其他条目。

## 过场动画页面布局 {#cinematic-layout}

![过场动画页面布局](../../assets/cb9ef78927d4-layout-cinematic.566ba42.1920.avif)

1. **片段**：过场动画条目中可以创建片段，并在轨道上显示。同一条目的片段无法重叠。
2. **轨道**：你可以在此处查看已创建的所有片段并编辑其显示持续时间。
3. **轨道时长**：在这里编辑轨道持续时间，单位为 Minecraft tick，20 tick 等于 1 秒。
