# 入门（Getting Started）

Typewriter 通过网页面板创建交互内容，无需编写代码。本指南介绍安装和配置，界面布局页面则说明网页面板的用法。

## 入门可按顺序阅读： {#to-get-started-follow-these-pages}

## [安装指南](getting-started/installation.md)

Typewriter 仅适用于 Paper 服务端，不支持 Spigot 或 Bukkit 服务端。

## [界面布局](getting-started/layout.md)

在此页面上，你将学习如何使用Typewriter网页面板并创建某些内容。

对于有兴趣向Typewriter添加更多功能的开发人员，我们建议你阅读[开发文档](../develop.md)。
