# 添加对话（Adding dialogues）

**开始前**

在开始本教程之前，最好先阅读[过场动画](../cinematics.md)。

在本教程中，你将学习如何在交互中添加对话。

## 添加对话 {#adding-a-dialogue}

过场动画支持多种对话，例如 `spoken`、`actionbar`、`title`、`subtitle`。这里使用动作栏对话，其他类型的用法相似。

首先点击面板右上角的 + 图标，搜索`Add Actionbar Dialogue Cinematic`。单击 + 图标将其添加到你的页面。

### 配置对话 {#configuring-the-dialogue}

现在我们需要配置对话。

先为对话添加[第一个交互](../interactions.md#configuring-the-speaker)，然后通过操作菜单点击 `Add Segment`，添加片段。

### 配置对话片段 {#configuring-the-dialogue-segment}

现在，在该段内，你可以转到文本字段并添加类似`<white>This is a cool actionbar text!</white>`的文本。

![添加对话片段](../../../assets/2f9d2b10cc7b-adding-dialogue-segment.fa49beb.587.avif)
