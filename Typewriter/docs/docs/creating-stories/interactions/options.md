# 添加选项（Adding Options）

**开始前**

在开始本教程之前，最好先阅读[第一个交互](../interactions.md)。

在本教程中，你将学习如何在交互中创建和使用选项。

## 创建选项 {#creating-an-option}

要创建选项，请按照下列步骤操作：

1. 右键单击你的条目并选择`+ Link with ...`。
2. 搜索`Add Option`并单击 + 图标将其添加到你的序列中。

## 配置选项 {#configuring-a-option}

让我们通过执行以下步骤来配置该选项：

1. 在字段`Text`中输入你要向玩家询问的问题，例如`Am I a beautiful flower?`。
2. 为选项选择合适的[第一个交互](../interactions.md#configuring-the-speaker)。

![配置选项条目](../../../assets/69e3dc334078-configure-option.1c862f6.539.avif)

### 添加选项 {#adding-options-1}

1. 单击字段`Options`旁边的 + 图标并展开`Options #1`。
2. 在字段`Text`中输入选项 1 的问题答案，如`Yes you are!`。
3. 按`Options #1`内字段触发器中的 + 图标并展开`Triggers #1`。
4. 点击 `Select a triggerable`，在搜索菜单中创建玩家选择此选项后要触发的条目。例如，添加内容为 `Yay thank you!` 的逐字对话。
5. 重复这些步骤以创建更多选项，例如`No you are not.`。

![将选项添加到选项条目](../../../assets/70b1d5480e83-adding-options.479007b.542.avif)
