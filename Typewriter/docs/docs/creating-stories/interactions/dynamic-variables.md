# 随机对话（Random Dialogue）

**开始前**

本教程以[第一个交互](../interactions.md)教程为基础。最好首先阅读[事实](../facts.md)文档。

在本教程中，你将学习如何使用动态变量并使用它们创建随机逐字对话。

## 创建随机对话 {#creating-random-dialogue}

打开[第一个交互](../interactions.md)中创建的逐字对话的属性面板，点击 Text 字段上方的动态变量图标，选择 `Add random Variable`。

添加随机变量

返回给定值的随机值的变量

+

这将在静态页面内创建一个随机变量。

## 配置随机变量 {#configuring-the-random-variable}

创建随机变量后，打开随机变量的属性面板。在这里，你可以向随机变量添加多个值。现在，每次触发逐字对话时，都会从该随机变量中显示不同的消息。
在本教程中，我们选择添加以下行，但这可以是你想要的任何内容：
`Hello! I am a flower.`、`Wow, you found me.`、`Hey you!`
你的动态变量现在应该如下所示：

![随机变量示例](../../../assets/926c27910b95-random-variable.38f29c4.552.avif)

## 移除随机变量 {#removing-the-random-variable}

点击动态变量旁的移除图标，即可移除该动态变量。

## 结果 {#result}

现在，每次触发逐字对话时，都会从随机变量中显示一条随机消息。
