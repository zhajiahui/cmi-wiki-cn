# 快捷键（Shortcuts）

此页面包含使用Typewriter时可以使用的键盘快捷键列表。
但首先你的操作系统是什么？

**Windows**

|快捷方式 |描述 |
| --- | --- |
|`ctrl + k`或`ctrl + space`|打开搜索框 |
|`tab`或`ctrl + n`|下一项 |
|`shift + tab`或`ctrl + p`|上一条 |
|`ctrl + shift + p`|发布页面 |

**macOS**

|快捷方式 |描述 |
| --- | --- |
|`⌘ + k`或`⌘ + space`|打开搜索框 |
|`tab`或`⌘ + n`|下一项 |
|`shift + tab`或`⌘ + p`|上一条 |
|`⌘ + shift + p`|发布页面 |

## 搜索 {#search}

在搜索菜单中还有一些快捷方式。

|快捷方式 |描述 |
| --- | --- |
|`!ae`或`!ne`|仅显示**新**条目 |
|`!ee`或`!a`|仅显示**现有**条目。 |

按搜索菜单中的 Tab 键可以轻松浏览所有条目。它还在底部操作中向你显示一个菜单，例如：`+Add`或`Open wiki`。
