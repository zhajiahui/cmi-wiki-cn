# 命令（Commands）

Typewriter 提供以下命令：

**参数说明**

`[]` 中的参数可选，`<>` 中的参数必填。
条目参数支持填写条目 ID 或条目名称。

| 命令 | 说明 | 权限 |
| --- | --- | --- |
| `/tw connect` | 连接 Typewriter 面板。 | `typewriter.connect` |
| `/tw clearChat` | 按 Typewriter 的方式清除自己的聊天内容。 | `typewriter.clearChat` |
| `/tw cinematic <start/stop> <pageName> [player]` | 为指定玩家播放选定的过场动画。 | `typewriter.cinematic.start/stop` |
| `/tw reload` | 重载插件。 | `typewriter.reload` |
| `/tw facts [player]` | 获取指定玩家的全部事实。 | `typewriter.facts` |
| `/tw facts set <factEntry> <value> [player]` | 设置指定玩家的事实。 | `typewriter.facts.set` |
| `/tw facts reset` | 重置指定玩家的全部事实。 | `typewriter.facts.reset` |
| `/tw trigger <entry> [player]` | 为指定玩家触发条目。 | `typewriter.trigger` |
| `/tw assets clean` | 清理所有未使用的资源。 | `typewriter.assets.clean` |
| `/tw fire <entry> [player]` | 触发 Fire Trigger Event 条目。 | `typewriter.fire` |
| `/tw manifest inspect [player]` | 检查玩家当前激活的呈现条目。 | `typewriter.manifest.inspect` |
| `/tw quest track <questEntry> [player]` | 为指定玩家开始追踪任务。 | `typewriter.quest.track` |
| `/tw untrack [player]` | 取消追踪指定玩家的任务。 | `typewriter.quest.untrack` |
| `/tw roadNetwork edit <roadNetworkEntry>` | 编辑道路网络。 | `typewriter.roadNetwork.edit` |
