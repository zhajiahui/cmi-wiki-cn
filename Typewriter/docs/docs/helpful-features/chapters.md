# 章节（Chapters）

章节为你的Typewriter工作流程增添了一些便利，类似于书中熟悉的章节结构。与 PC 上形成文件夹的文件类似，Typewriter的章节系统在章节内组织页面。

### 设置章节 {#setting-chapters}

通过右键单击页面并选择`Change Chapter`轻松创建章节。输入所需的章节名称并单击`Change`。

<video controls preload="metadata" src="../../assets/f0dc424fce88-chapters.webm"></video>

### 设置子章节 {#setting-sub-chapters}

创建子章节非常简单。只需使用主章节名称并添加`.`例如`hello.test`将生成一个子章节。如下图：

![子章节](../../assets/89402a80945e-sub-chapters.54301bd.266.avif)

请随意根据需要添加尽可能多的子章节来扩展故事。例如，`hello.test.morning`就可以。Typewriter自动收集具有相同章节名称的页面并将它们分组在一起。
