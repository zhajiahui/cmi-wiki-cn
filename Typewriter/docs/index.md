# Typewriter 是什么？（What is Typewriter?）

Typewriter 是 Minecraft 交互内容插件。通过网页面板，无需编写代码，就可以为服务器创建交互内容。

## 主要功能 {#key-features}

- **对话与任务：**根据玩家选择设计对话、分支剧情和动态任务。
- **过场动画：**创建动态镜头路径、NPC 动画交互和剧情过场。
- **NPC 与实体：**自定义活动和外观，创建按玩家分别显示的实体。
- **自定义命令：**无需编程，即可创建触发自定义内容的服务器命令。
- **可视化配置：**通过可视化网页面板管理内容。
- **扩展系统：**通过模块化组件扩充 Typewriter，接入自定义插件，创建不同的游戏体验。

## 为什么选择 Typewriter？ {#why-choose-typewriter}

- **无需编程**：通过可视化网页面板创建复杂交互。
- **实时协作**：与团队成员同时编辑服务器内容。
- **可扩展**：通过扩展适应服务器的不同需求。
- **适合正式环境**：设计时考虑了繁忙服务器中的性能需求。
