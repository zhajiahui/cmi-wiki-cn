# 0.7.X 的 API 变更（All API changes to 0.7.X）

v0.7.X 版本包含新的动态变量。
要了解如何使用它们，请参阅[变量条目](../entries/static/variable.md)。

## PlaceholderEntry 变更 {#placeholderentry-changes}

**旧版**

```kotlin
override fun display(player: Player?): String? {
    return "Hello, ${player?.name ?: "World"}!"
}
```

**新版**

```kotlin
override fun parser(): PlaceholderParser = placeholderParser {
    supply { player ->
        "Hello, ${player?.name ?: "World"}!"
    }
}
```

占位符现在返回一个解析器，而不是直接解析。
这允许创建更复杂的占位符。
例如，使用子占位符。

例如，`TimedFact`默认返回事实`%typewriter_<entry id>%`的事实值。
但如果你想要事实过期的时间，你可以使用`%typewriter_<entry id>:time:expires:relative%`
其中`:time:expires:relative`是子占位符。
