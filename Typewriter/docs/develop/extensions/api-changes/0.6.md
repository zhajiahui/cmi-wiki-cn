# 0.6.X 的 API 变更（All API changes to 0.6.X）

随着Typewriter从`Adapters`更改为`Extensions`，API 发生了显着变化。
建议重新阅读[创建扩展](../getting_started.md)指南，以更好地了解如何创建扩展。

## Messager 的 tick 参数 {#messager-tick-parameter}

**旧版**

```kotlin
override fun tick(playTime: Duration) {
    super.tick(playTime)
    // Do something to show the message
}
```

**新版**

```kotlin
override fun tick(context: TickContext) {
    super.tick(context)
    // Do something to show the message
}
```

`tick`参数已更改为`context`，以允许将更多上下文传递给`tick`方法。
