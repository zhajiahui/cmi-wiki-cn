# 扩展开发（Extensions）

## 介绍 {#introduction}

Typewriter是一个支持扩展开发的动态平台，扩展是增强整体功能的模块化组件。
扩展是独立的，易于共享，并顺利集成到Typewriter系统中。
它们允许你创建自定义条目并将其显示在网页面板中。
本指南旨在指导你完成创建扩展的过程，适合初学者和经验丰富的开发人员。

**Java开发**

需要用Kotlin编写扩展，因为它是Typewriter的主要语言。**无法在 Java 中创建扩展。**
