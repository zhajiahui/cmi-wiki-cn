# 开发文档（Development）

Typewriter有不同的部件可供开发。

- **扩展：**这些是独立的构建块，可以轻松共享并添加到系统中。
- **插件：**这些是Typewriter工作原理的核心部分。欢迎提供所有帮助，但请先讨论，因为这些更改可能会影响很多用户。
- **UI：**这是用 Flutter 编写的，是Typewriter最复杂的部分。这也是最有趣的工作，因为在这里你可以真正看到你的工作成果。

**重要**

这部分文档仍在构建中。如果你想提供帮助，请通过[Discord](https://discord.gg/HtbKyuDDBw)联系我们。
