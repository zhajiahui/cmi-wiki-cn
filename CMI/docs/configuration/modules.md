# 功能模块（Modules.yml）

文件：`plugins/CMI/Settings/Modules.yml`

来源：用户提供的配置文件；本文仅收录原注释的中文翻译。

## `silentChest`

可关闭不使用的模块，以节省服务器资源<br>
这会完全关闭相应功能<br>
需要完整重启服务器才生效<br>
部分模块关闭时也会禁用对应命令，例如 cuffed 禁用 cuff，silentChest 禁用 silentChest<br>
被禁用的命令不出现在 Tab 补全中，执行时提示命令不存在

静默打开箱子<br>
适用于 1.7.x 及以上服务器
