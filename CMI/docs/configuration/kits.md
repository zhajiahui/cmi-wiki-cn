# 礼包（Kits.yml）

文件：`plugins/CMI/Kits/Kits.yml`

来源：用户提供的配置文件；本文仅收录原注释的中文翻译。

## `Newbie`

使用指定礼包需要 cmi.kit.\[kitName\] 权限<br>
例如 cmi.kit.newbie 允许使用 newbie 礼包<br>
可用自定义变量：{USERNAME} {DISPLAYNAME} {WORLDNAME} {KITNAME} {RANDOMPLAYER}<br>
请在游戏内通过 /cmi kiteditor 编辑礼包，避免格式错误<br>
命令支持特殊指令格式
