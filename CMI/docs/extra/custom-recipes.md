# 自定义合成配方

## 基本用法

执行 `/cmi customrecipe` 打开自定义配方界面，需要权限 `cmi.command.customrecipe`。

![](../assets/images/4a7af22747-customrecipe1.png)

点击第一个绿色羊毛图标，打开下面的界面：

![](../assets/images/31fc3e3811-customrecipe2.png)

**放入材料后直接关闭界面，会损失这些材料。**

创建有序配方时，按实际合成需要的形状摆放材料，再把产物放入右侧槽位：

![](../assets/images/f9b01a21c4-customrecipe3.png)

摆放完成后，点击左侧的绿色羊毛保存配方。

![](../assets/images/0d89b058b4-customrecipe4.png)

配方会以产物图标显示在主界面中。创建无序配方时，材料在合成栏中的排列方式不影响结果，只需满足指定的材料组合。

创建自定义熔炉配方时，仍用上述指令打开界面，但点击熔炉图标，而不是绿色羊毛。

![](../assets/images/48556d9239-customrecipe5.png)

熔炉界面有两个位置，分别指定投入的材料和烧炼产物。

![](../assets/images/4e4270bc21-customrecipe6.png)

放入自定义熔炉配方的材料：

![](../assets/images/082da425f1-customrecipe7.png)

点击左侧的绿色羊毛保存配方。

![](../assets/images/5359ceec25-customrecipe8.png)

## 提议中的功能

- 合成配方时收取经验或金钱。提议者：@EODSteven。
- 自定义熔炉燃料，例如用水瓶作燃料，烧炼后获得经验瓶。提议者：@EODSteven。
