# pStats

pStats 为插件作者提供使用统计，例如有多少服务器正在使用其插件。这一用途由随包原始配置注释说明，注释指向的项目站点为 [pStats](https://pstats.devs.beer/)。

这批资料以 **pStats 配置目录**随包提供，清单未列出独立 pStats JAR，**版本未标明**。其他随包插件的 `depend` 和 `softdepend` 中均未出现 pStats，现有资料未指明具体调用方。

随包原始注释说明了统计用途，没有列出完整采集字段、独立管理命令或权限节点。随包选项见[配置说明](configuration/index.md)。

## 项目来源

- [pStats 项目站点](https://pstats.devs.beer/)：由随包原始配置注释提供。
