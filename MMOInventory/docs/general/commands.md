# 命令 {#💾-commands}

|命令 |描述 |
| --- | --- |
| `/mmoinv reload` | 重新加载插件 |
| `/mmoinv export-data` | 将玩家数据从YAML平面存储导出到SQL数据库 |
| `/mmoinv open <inventory> <owner>` | 打开自定义物品栏到玩家 |
| `/mmoinv open <inventory> <owner> <player> <can_edit>` | 打开`owner`的自定义物品栏到玩家`player`。`can_edit`可以设置为`true`（权限可以装备/取消装备物品）或`false`（不能装备/取消装备物品） |
| `/mmoinv inspect <inventory> <owner>` | 检查玩家的定制物品栏 |

以下命令别名也有效：`/mmoinv`、`/rpginv`、`/rpginventory`。
