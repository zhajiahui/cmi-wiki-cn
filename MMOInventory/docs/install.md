# 安装指南 {#🔌-installation-guide}

- 下载并安装[MythicLib](https://www.spigotmc.org/resources/mmolib-mythiclib.90306/)。它是MMOInventory的唯一硬依赖项。
- 下载MMOInventoryJAR 文件并将其安装在`/plugins`文件夹中。
- 如果你在服务器上运行MMOItems，我们建议你阅读[此 wiki 页面](compatibility/mmoitems.md)。
- 下载默认的MMOInventory服务器资源包并安装它（或将其与现有服务器包合并）。

## 资源包版本 {#resource-pack-versions}

|版本 |链接 |
| --- | --- |
| 1.14至1.21.2 | [Dropbox](https://www.dropbox.com/s/1lftxmzh0q4b5yu/mmoinv_rp_3.zip?dl=1) |
| 1.21.4+ | [Gitlab](https://gitlab.com/phoenix-dvpmt/mmoinventory-default-resource-pack) |
