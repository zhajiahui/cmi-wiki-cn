# 首页 {#🏠-home}

![](assets/2d5b6e805112-banner.Bhx_rwBZ.png)

一般问题和 Bug 请提交到 [GitLab 问题跟踪器](https://gitlab.com/phoenix-dvpmt/bounty-hunters/-/issues)。可以在 [SpigotMC](https://www.spigotmc.org/resources/72142/) 购买插件，也可以[免费下载旧版](https://www.spigotmc.org/resources/bountyhunters-legacy.40610/)，旧版兼容 1.8 至 1.14。

如果仍在使用 1.8 服务器，请从 [Spigot 下载最新版 BountyHunters Legacy](https://www.spigotmc.org/resources/bountyhunters-legacy.40610/)。Legacy 是已过时的插件版本；从 Legacy 升级到 Premium，必须重置配置和数据。

> **信息**
>
> 此 Wiki 尽量跟进最新 Premium 构建。BountyHunters Legacy 没有对应的 Wiki。

BountyHunters 可以直接安装使用。将 JAR 放入 plugins 文件夹，再重启服务器即可。
