# 命令 {#💾-commands}

## 玩家命令 {#player-commands}

|用途 |描述 |
| --- | --- |
| `/addbounty <player> <amount>` | 创建一个悬赏/向当前的悬赏添加资金。 |
| `/bounties` | 显示当前悬赏。 |
| `/hunterlb` | 显示悬赏猎人排行榜。 |
| `/bounties titles` | 显示拥有的标题。 |
| `/bounties animations` | 显示拥有的悬赏动画。 |
| `/redeembountyheads` | 从受害者身上赎回人头。 |

## 管理命令 {#admin-commands}

| 用途 | 描述 |
| --- | --- |
| `/bounties help` | 显示帮助页面。 |
| `/bounties remove <player>` | 删除玩家上的悬赏。 |
| `/bounties edit <player>` | 编辑悬赏（编辑奖励和贡献者）。 |
| `/bounties reload` | 重新加载插件配置文件。 |

当以管理员身份执行`/addbounty`时，你可以在语法末尾添加`-bmm`以完全绕过最小/最大悬赏奖励限制。你还可以使用`-nt`完全抵消悬赏创建税。
