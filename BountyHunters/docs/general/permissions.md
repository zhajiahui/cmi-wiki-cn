# 权限 {#🧑‍⚖️-permissions}

## 玩家权限 {#player-permissions}

|格式|描述 |
| --- | --- |
| `bountyhunters.list` | 访问`/bounties` |
| `bountyhunters.add` | 权限创建或增加一个悬赏。 |
| `bountyhunters.claim` | 权限**领取悬赏**。 |
| `bountyhunters.remove` | 允许你删除自己的悬赏。 |
| `bountyhunters.leaderboard` | 进入悬赏猎人排行榜GUI。 |
| `bountyhunters.title` | 获得猎人头衔。 |
| `bountyhunters.animation` | 访问悬赏动画。 |
| `bountyhunters.redeem-heads` | 访问`/redeembountyheads` |

## 管理员权限 {#admin-permissions}

| 格式 | 描述 |
| --- | --- |
| `bountyhunters.admin` | 访问管理命令。 |
| `bountyhunters.update-notify` | 当有新更新可用时，加入服务器时会收到通知。 |
| `bountyhunters.immunity` | 玩家不得将悬赏置于你身上。 |
| `bountyhunters.immunity.bypass` | 绕过之前的悬赏免疫力。 |
| `bountyhunters.untargetable` | 玩家不得针对你。 |
| `bountyhunters.untargetable.bypass` | 绕过先前的目标免疫。 |
