# 占位符 {#🏷️-placeholders}

|格式|用途 |
| --- | --- |
| `%bountyhunters_top_name_<rank>%` | 排名必须介于1和16之间。返回猎人排行榜上的n-th玩家 |
| `%bountyhunters_top_bounties_<rank>%` | 在排行榜中声称了一些玩家的悬赏 |
| `%bountyhunters_top_heads_<rank>%` | 部分玩家成功进入排行榜的悬赏数量 |
| `%bountyhunters_top_level_<rank>%` | 排行榜中的玩家等级 |
| `%bountyhunters_level%` | 显示个人猎人等级 |
| `%bountyhunters_successful_bounties%` | 玩家金额悬赏成功领取 |
| `%bountyhunters_illegal_streak%` | 自上次重生以来玩家的非法击杀数量 |
| `%bountyhunters_illegal_kills%` | 非法杀害的玩家总数（即目标上没有悬赏） |
| `%bountyhunters_current_bounty%` | 当前悬赏在玩家的头上 |
| `%bountyhunters_title%` | 当前猎人头衔（​​如果没有，则为“无头衔”） |
| `%bountyhunters_progress%` | 猎人进度条（升级前必须领取的悬赏数量） |
| `%bountyhunters_before_level_up%` | 玩家升级前必须领取悬赏的金额 |
