# 性能计时系统（旧版文档）

性能计时系统于 2.7.2 引入，可以测量各插件及各数据包监听器消耗的处理器时间，便于找出引发问题的插件。

执行以下命令即可使用：

```
/protocol timings
```

收集到足够数据后，通常十分钟就够，再次执行此命令。这会停止测量，并将报告写入 *plugins/ProtocolLib* 文件夹，格式如下：
