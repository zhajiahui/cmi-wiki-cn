# Cracks

<a id="This_Page"></a><h2 id="this-page">本页</h2>
<p>如果您被发送到此页面，您是 running:</p>
<ul>
<li>一个 <strong>Minecraft破解版</strong></li>
<li>支持Minecraft用户的服务器破解</li>
<li>或者出于任何给定原因在 <strong>离线模式</strong> 中运行的服务器。</li>
<li>有时这也被用作破解插件的参考，并且此页面上的大多数（尽管不是全部）内容仍然适用。</li>
</ul>
<a id="Common_Misunderstandings"></a><h2 id="common-misunderstandings">常见的误解</h2>
<a id='"Premium"'></a><h3 id="premium">“高级”</h3>
<p>重要的是要注意，不存在“<strong>溢价</strong>”Minecraft 帐户这样的东西。</p>
<p>您要么拥有帐户（有效注册并购买的 Mojang 帐户），要么没有。</p>
<p>如果您没有帐户并且仍在玩Minecraft，则您正在运行破解的客户端。</p>
<a id='"But_Offline_Is_A_Built-In_Feature"'></a><h3 id="but-offline-is-a-built-in-feature">“但离线是一个内置功能”</h3>
<p>一些用户声称离线模式不可能是非法的，因为它是一个内置功能。</p>
<p>这是一个简单的误解：离线模式确实不违法……但是使用离线模式可以让破解版的minecraft加入你的服务器<strong>是</strong>。</p>
<p><code>online-mode=false</code> 的实际用途正如其包装上所言，仅此而已：当您无法访问互联网时。离线模式让你可以在离线状态下在 LAN 上玩我的世界。</p>
<a id='"But_I_Need_It_To_Test_Multiple_Players"'></a><h3 id="but-i-need-it-to-test-multiple-players">“但我需要它来测试多个玩家”</h3>
<p>一些用户声称他们已经下载了一个破解程序来测试多个玩家的某些插件或脚本。</p>
<p>下载破解就是下载破解。运行破解就是运行破解。没有借口。你仍然面临着恶意软件的风险，你仍然在犯罪。</p>
<p>您的测试选项 are:</p>
<ul>
<li>答：如果您确实需要自己测试，请购买第二个帐户。</li>
<li>B：尽可能使用 NPC 或类似产品。</li>
<li>C：就……请人来帮你测试一下。如果您能够找到在服务器上玩的人，那么您绝对也应该能够找到愿意帮助测试的人。只需戳一个朋友，让他们打开我的世界并在您的测试服务器上闲置即可。</li>
</ul>
<a id="Legality"></a><h2 id="legality">合法性</h2>
<p>Minecraft 破解是<strong>非法软件盗版</strong>。</p>
<p>创建、下载、使用、拥有或分发 Minecraft 破解版属于 <strong>犯罪</strong>。</p>
<p>您绝不应该下载、使用或分发非法软件。</p>
<a id="Safety_Warning"></a><h2 id="safety-warning">安全警告</h2>
<p>众所周知，大多数 Minecraft 破解都包含 <strong>恶意软件</strong>（这对于大多数盗版软件来说通常是常见的）。</p>
<p>如果您安装或已经安装了 Minecraft 破解版，您的计算机可能面临风险或已感染恶意软件。</p>
<a id="Cracked_Servers_Are_Limited"></a><h2 id="cracked-servers-are-limited">破解服务器有限</h2>
<p>破解客户端和离线模式服务器的一个重要限制是功能的减少和/或改变。</p>
<p>破解的客户端和离线模式服务器 <em>无法访问</em> Minecraft 的某些功能在合法安装中可用。</p>
<p>因此，<em>即使</em>我们选择支持离线模式的服务器，我们将是<em>不能</em>。</p>
<p>许多错误和奇怪的行为是由托管离线模式服务器引起的，并且通常根本不会出现在在线模式服务器上。</p>
<p>因此，离线模式服务器上的问题无法像解决在线模式服务器上发现的问题那样得到解决。</p>
<a id="Supportability"></a><h2 id="supportability">支持性</h2>
<p>虽然在大多数情况下，<strong>插件可以运行并且可以工作</strong> 通常会在任何问题页面、论坛线程、聊天室或其他支持热线中提供 <strong>我们不能也不会支持离线模式</strong> 服务器。</p>
<p>对于 Discord，根据 <a href="https://discord.com/guidelines">不和谐准则</a>，我们被明确禁止向破解服务器提供支持：<code>Do not distribute or provide access to content involving the hacking, cracking, or distribution of stolen goods, pirated content, or accounts. This includes sharing or selling game cheats or hacks.</code> 如果您运行的破解版 Minecraft 服务器在 Discord 上有社区，则该社区也可能违反此 Discord 平台规则。</p>
<a id="Consequences_Of_Offline-Mode"></a><h2 id="consequences-of-offline-mode">离线模式的后果</h2>
<p>还要注意，即使服务器暂时处于离线模式，然后再更改为在线模式，也可能会产生持久的后果，从而使“快速更改为离线以测试某些内容”之类的操作变得危险。</p>
<p>如果您正在运行离线模式服务器并且要修复该问题，那么降低出现问题风险的最佳方法是删除玩家数据（存储在每个世界中标记为“playerdata”的文件夹中）。</p>
<a id="General_Risks_of_an_Offline-Mode_Server"></a><h2 id="general-risks-of-an-offline-mode-server">离线模式服务器的一般风险</h2>
<p>除了技术支持警告之外，还应该指出的是，离线模式服务器容易受到在线模式服务器上不可能的攻击，例如虚假玩家洪水攻击和被禁止的用户以不同的用户名（有时也使用不同的 IP 地址）返回。</p>
<p>此外，在离线和在线模式服务器上都可能发生的攻击（例如 DDoS 攻击）在离线模式服务器上更为常见（部分原因是由于对愤怒玩家的后果的恐惧程度较低），并且在某些情况下甚至更容易完成（由于缺乏像帐户验证器这样的官方 Minecraft 安全系统，以及在离线模式下无法正常工作的东西的可用性）。</p>
<a id="How_To_Do_It_Right"></a><h2 id="how-to-do-it-right">如何正确做事</h2>
<p>您的服务器应该 <strong>总是</strong> 处于在线模式（这是 <code>server.properties</code> 文件中的设置，应该有一行读取 <code>online-mode=true</code>）。</p>
<a id="Bungee"></a><h3 id="bungee">Bungee</h3>
<p>可以在服务器上使用离线模式的唯一情况是在使用 Bungee 时。 Bungee 是一个具有自己的在线模式功能的代理，应该启用该功能，并且您的服务器应该将除 Bungee 端口之外的所有端口都由防火墙阻止（否则 Bungee 在线模式功能可能会被绕过和破坏）。此外，确保 <code>spigot.yml</code> 中的 <code>bungeecord</code> 设置为 true。</p>
<a id="Velocity"></a><h3 id="velocity">速度</h3>
<p>速度代理的工作方式与上述 Bungee 相同，唯一的变化是您需要在 <code>config/paper-global.yml</code> 中启用 <code>velocity: enabled:</code>，而不是 'spigot.yml' 中的 'bungeecord'</p>
