<a id="Flags_2"></a><h3 id="flags">旗帜</h3>
<p><strong>-p</strong> - 玩家</p>
<p><strong>-m</strong> - 生物</p>
<p><strong>-g</strong> - 权限组（支持PermissionsBukkit、bPermissions和PermissionsEx）</p>

<a id="Usage"></a><h2 id="usage">用途</h2>
<a id="Flags_2"></a><h3 id="flags_1">旗帜</h3>
<p>旗帜是守卫的核心特征。它们定义守卫应将哪些实体作为目标（或不作为目标），并使用 /guard addflag 命令创建。旗帜可以针对怪物、玩家和团体。组定位功能仅适用于 PermissionsBukkit。</p>
<p>默认情况下，标志是黑名单 - 但是，白名单也是可能的。通过使用“-”作为目标的第一个字符，该标志被指定为白名单标志。例如，“fullwall”是黑名单目标，而“-fullwall”是白名单目标。</p>
<p>标志也可以采用优先级，范围从 1 到 20，数字越小优先级越高。本质上，当面对两个目标时，守卫会攻击优先级较高的实体。如果发现多个目标具有最高优先级，守卫将攻击最接近它的实体。该功能主要用于对守卫的高级配置，优先级默认为1。</p>
<a id="Types"></a><h3 id="types">NPC 类型</h3>
<p>目前守卫可以切换为两种类型：贴身护卫（bodyguard）和区域守卫（bouncer）。</p>
<a id="Bouncers"></a><h4 id="bouncers">区域守卫（bouncer）</h4>
<p>区域守卫主要用于保护一片区域。它们通常原地驻守，防御目标规则指定的实体。击败敌人后，它们会沿路返回原来的位置。如果敌人离开保护半径，守卫会停止追踪，必要时传送回原位。</p>
<a id="Bodyguards"></a><h4 id="bodyguards">贴身护卫（bodyguard）</h4>
<p>贴身护卫用于保护个人，会跟随你并在需要时提供保护。它们会主动寻找目标规则指定的实体；如果离开保护半径，就会传送回你身边。</p>
<a id="Soldiers"></a><h4 id="soldiers">士兵</h4>
<p>注：仅适用于 post-1.1.2。
士兵本质上是可指挥的警卫。玩家可以选择自己拥有的士兵并命令他们攻击玩家、小怪并移动到方块。</p>
<a id="Future"></a><h2 id="future">未来</h2>
<p>库存热栏，用于武器切换和治疗。
也许更多的是防守类型。</p>
