# 角色类型

<p>角色是使用 <a href="https://wiki.citizensnpcs.co/API" title="API">Citizens API</a> 向现有 NPCs 添加功能的插件。下载并安装其插件 JAR 到 <em>/plugins</em> 目录中。</p>
<p>Citizens NPCs 可以同时包含多个特征。见<a href="multiple-traits.md" title="Multiple Traits">多个特征</a></p>
