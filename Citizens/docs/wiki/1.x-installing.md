<p>如何下载 Citizens 插件并将其安装到您的 Bukkit 服务器。</p>
<a id="New_Installation"></a><h3 id="new-installation">新安装</h3>
<ol>
<li>转到 <a href="http://dev.bukkit.org/server-mods/citizens/">BukkitDev Citizens 页面</a> 并点击右上角的“下载”。</li>
<li>再次点击“下载”，下载最新的Citizens包。将 zip 保存到您的插件文件夹中</li>
<li>将 zip 包的内容解压到plugins 文件夹中。您最终应该得到 Citizens.jar 和一个名为 Citizens 的文件夹</li>
<li>按照通常生成 <a href="configuration.md" title="Configuration">配置</a> 文件的方式启动服务器。然后再次关闭它</li>
<li>根据您的个人喜好编辑 <a href="configuration.md" title="Configuration">配置</a> 文件。</li>
<li>像平常一样启动服务器。</li>
<li>授予您的玩家权限。有关详细节点信息，请参阅 <a href="https://wiki.citizensnpcs.co/index.php?title=Commands_and_Permissions&amp;action=edit&amp;redlink=1" title="Commands and Permissions (page does not exist)">命令与权限</a> 页面。</li>
<li>???</li>
<li>Profit.</li>
</ol>
<p>有问题吗？参见 <a href="troubleshooting.md" title="Troubleshooting">故障排查</a>。</p>
<a id="Updating_from_1.1.x"></a><h3 id="updating-from-11x">从 1.1.x 更新</h3>
<ol>
<li>停止你的服务器</li>
<li>解压从 Bukkit-Dev 获得的下载。</li>
<li>覆盖 Citizens.jar 和每个角色类型 .JAR 文件。</li>
<li>启动你的服务器。享受！</li>
</ol>
<p>有问题吗？参见 <a href="troubleshooting.md" title="Troubleshooting">故障排查</a>。</p>
<a id="Updating_from_earlier_versions"></a><h3 id="updating-from-earlier-versions">从早期版本更新</h3>
<p>建议从 Citizens 的早期版本更新时从头开始，但是旧的任务文件和配置文件可能仍然有效。新的 .JAR 文件应覆盖旧版本</p>
