<a id="Rewards_node"></a><h1 id="rewards-node">奖励节点</h1>
<p><a href="https://wiki.citizensnpcs.co/index.php?title=Quests.yml&amp;action=edit&amp;redlink=1" title="Quests.yml (page does not exist)">Quests.yml</a>中的奖励节点用于告诉询问者在满足条件时奖励玩家什么。如果所有目标都完成，则奖励：节点被触发。</p>
<p>例如：</p>
<div class="highlight"><pre>rewards:
    '0':
        type: item    # Rewards an item
        id: 15        # iron_ore
        amount: 30
    '1':
        type: quest   # Rewards a quest.  This quest will start immediately.
        quest: "Part II"
</pre></div>
<p>您可能有多种奖励，也可能只有一种。奖励也可以细分为目标，以在目标完成时奖励玩家。格式是一样的。</p>
<a id="Rewards_Types"></a><h1 id="rewards-types">奖励类型</h1>
<a id="Command"></a><h2 id="command">命令</h2>
<p>命令奖励 (command:) - 执行命令。
由 command: 节点指定。使用 &lt;player&gt; 作为变量，该变量将替换为获得奖励的玩家的姓名。使用 &lt;world&gt; 作为变量，该变量将替换为玩家当前所在世界的名称。使用 server: true 从控制台执行命令。</p>
<div class="highlight"><pre>'0':
    type: command
    command: give &lt;player&gt; 1 100
    server: false
</pre></div>
<a id="NPC"></a><h2 id="npc">NPC</h2>
<p>NPC 奖励 (npc:) - 向玩家授予一个 npc。
使用 name: 节点指定 npc 的名称，以及 types: 节点中以逗号分隔的切换列表（例如，商人、任务 NPC、守卫）。将创建一个由完成任务的玩家拥有的 NPC，并生成 UID。</p>
<div class="highlight"><pre>'0':
    type: npc
    npcid: 1   # optional - gives the ownership of npc specified by this id to the player
    name: 'Bill'
    types: 'guard,trader,quester'
    location:
        x: 10
        y: 10
        z: -50
        world: 'world'</pre></div>
<a id="Rank"></a><h2 id="rank">排名</h2>
<p>排名奖励（排名）- 向玩家授予一个组（“排名”）。
由 rank: 节点指定。</p>
<div class="highlight"><pre>'0':
    type: rank
    rank: 'admin'</pre></div>
<a id="Permission"></a><h2 id="permission">权限</h2>
<p>权限奖励（权限）- 授予玩家权限。
由 permission: 节点指定。</p>
<div class="highlight"><pre>'0':
    type: permission
    permission: 'quests.admin'
</pre></div>
<a id="Quest"></a><h2 id="quest">任务</h2>
<p>任务奖励（quest）- 向玩家授予任务。请注意，它不能从玩家手中夺走。
由 quest: 节点指定。</p>
<div class="highlight"><pre>'0':
    type: quest
    quest: 'builder'</pre></div>
<p><em>aufdemrand: 的注释 需要测试在子目标奖励中使用任务奖励的行为。很快就会报告我的发现。</em></p>
<a id="Item"></a><h2 id="item">项目</h2>
<p>物品奖励（物品）- 向玩家提供物品。
从 item: 节点加载。</p>
<div class="highlight"><pre>'0':
    type: item
    item:
        id: 10
        amount: 50
        data: 0</pre></div>
<a id="Health"></a><h2 id="health">健康</h2>
<p>健康奖励（健康）- 为玩家提供健康。
从 amount: 节点加载。</p>
<div class="highlight"><pre>'0':
    type: health
    amount: 10
</pre></div>
<a id="Money"></a><h2 id="money">钱</h2>
<p>金钱奖励（金钱）- 给玩家金钱。
从 money: 节点加载。</p>
<div class="highlight"><pre>'0':
    type: money
    money: 100</pre></div>
<a id="Teleport"></a><h2 id="teleport">传送</h2>
<p>传送奖励（传送）- 将玩家传送到某个位置。
从 location: 节点加载。</p>
<div class="highlight"><pre>'0':
    type: teleport
    location:
        x: 10
        y: 50
        z: -10
        world: 'main'</pre></div>
