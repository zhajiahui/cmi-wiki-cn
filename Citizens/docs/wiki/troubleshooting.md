# 故障排查

<p>Citizens 有问题吗？请参阅 <a href="frequently-asked-questions.md" title="Frequently Asked Questions">常见问题</a>，或通过频道 #citizens 访问我们的 <a href="https://discord.gg/Q6pZGSR">不和谐</a>。</p>
<p>如果您需要寻求帮助，请准备好发布您的 <a href="logs.md" title="Logs">日志</a>。</p>
<p>或者，如果您在使用 Citizens 的特定部分时遇到问题，请查看相应的页面，因为每个页面都有专门的常见问题解答。</p>
<p>目前，我们在问题页面上看到过多的支持问题，因此在发布之前，请检查当前建立的支持的所有途径。</p>
