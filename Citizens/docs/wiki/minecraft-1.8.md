# Minecraft 1.8

<p>您好，如果您已链接到此页面，则您正在运行 Minecraft 1.8 服务器。</p>
<p>在撰写本页时，Minecraft 1.8 是 <strong>10岁</strong>（2014 年发布！）。</p>
<p>过时的服务器（虽然仍然能够正常运行，包括现代插件）显然无法得到任何合理的开发工作的支持。因此，我们准备了此页面来帮助您将服务器更新到可支持的版本。</p>
<p>首先，一些信息：<strong>你可以</strong> 运行更现代的服务器 <strong>同时仍然允许老游戏客户端加入</strong>，如果您愿意，可以享受 <strong>旧式 PvP</strong>。</p>
<a id="Additional_Warning"></a><h2 id="additional-warning">附加警告</h2>
<p>Minecraft 1.8.x 和其他类似的旧版本 (pre-1.12) 可能容易受到 <strong>Log4Shell安全漏洞</strong> 变体的影响，因为这些旧版本的补丁不完善。更新到最新版本对于您和服务器的安全至关重要。</p>
<a id="How_To_Update_Properly"></a><h2 id="how-to-update-properly">如何正确更新</h2>
<a id="Current_Spigot_or_Paper_Jar"></a><h3 id="current-spigot-or-paper-jar">当前 Spigot 或 Paper 罐子</h3>
<p>您当然需要收集最新的 Spigot 或 Paper 版本。最简单的方法是从 <a href="https://papermc.io/downloads">https://papermc.io/downloads</a> 下载 Paper（Paper 是 Spigot 的一个分支，更容易安装并且运行更好，但与 Spigot 插件完全兼容）。</p>
<a id="Letting_In_Older_Clients"></a><h3 id="letting-in-older-clients">让老客户进来</h3>
<p>要允许旧客户端连接，您可以使用协议插件。</p>
<ul>
<li>其中一个插件是 "ProtocolSupport"，可在此处找到：<a href="https://www.spigotmc.org/resources/protocolsupport.7201/">https://www.spigotmc.org/resources/protocolsupport.7201/</a></li>
<li>您还可以考虑名为 "ViaRewind" 的插件，它是插件 "ViaBackwards" 的扩展。这些是流行插件 "ViaVersion" 的反向版本。您可以在这里找到这个插件：<a href="https://www.spigotmc.org/resources/viarewind.52109/">https://www.spigotmc.org/resources/viarewind.52109/</a></li>
</ul>
<a id="Legacy-Style_PvP"></a><h3 id="legacy-style-pvp">传统风格 PvP</h3>
<p>要启用旧式 PvP，有多种选项可用，例如：<a href="https://www.spigotmc.org/resources/oldcombatmechanics-disable-1-9-hit-cooldown.19510/">https://www.spigotmc.org/resources/oldcombatmechanics-disable-1-9-hit-cooldown.19510/</a> 或只需在 Spigot 资源部分搜索“1.8 PvP”并选择您最喜欢的。</p>
<a id="Note_If_You_Don't_Follow_This_Guide"></a><h2 id="note-if-you-dont-follow-this-guide">如果您不遵循本指南，请注意</h2>
<p>如果您运行 1.8 Minecraft 服务器，并且不按照本指南更新您的服务器（而是保留旧版本），我们维护了 9 年的支持，但时间早已到来，<strong>你不会得到任何支持</strong> 来自帮助者，解答您可能遇到的任何问题/等。</p>
<p>~~<strong>Citizens及相关插件</strong>（Sentinel等）<strong>所有功能在当前版本中均能正常运行</strong>（最新版本和开发<a href="versions.md" title="Versions">版本</a>）<strong>在 1.8.8 Spigot 服务器上</strong>，但是您可能无法使用所有可用功能（主要是那些只能在较新的Minecraft版本中使用的功能），并且如果出现问题（例如作为出现的错误消息），不能保证我们可以做很多事情来帮助解决这个问题。~~</p>
<p>~~<strong>Denizen</strong>是一个例外，不再支持1.8~~</p>
<p>自 2024 年起，我们的插件将不再在此类古老版本上运行。</p>
<p>这里重要的是，Minecraft 1.8 此时是 <strong>10岁以上</strong> 并且继续老化，运行那么旧的版本是无意义的 - 特别是当你从上面的信息中看到，你不需要在服务器上运行旧版本来获得 1.8 的任何流行功能时。</p>
