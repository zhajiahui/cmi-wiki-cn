# 权限

<a id="Citizens_2.0.x_Permissions"></a><h2 id="citizens-20x-permissions">Citizens 2.0.x 权限</h2>
<p>此页面可能已过时：仔细检查 <a href="https://github.com/CitizensDev/Citizens2/blob/master/main/src/main/resources/plugin.yml">https://github.com/CitizensDev/Citizens2/blob/master/main/src/main/resources/plugin.yml</a> 上的 plugin.yml 以获得最新权限</p>
<p>所有权限的默认值为 OP</p>
<ul>
<li>citizens.admin.*</li>
<li>citizens.admin 这允许玩家编辑“服务器”拥有的 NPCs</li>
<li>citizens.admin.avoid-limits 允许用户创建任意数量的 NPCs</li>
<li>citizens.help /公民帮助</li>
<li>citizens.npc.*:</li>
<li>citizens.npc.age /NPC年龄</li>
<li>citizens.npc.position.assume /NPC年龄</li>
<li>citizens.npc.behaviour /NPC行为</li>
<li>citizens.npc.create /NPC创建</li>
<li>citizens.npc.create.[mobtype 或 *] /npc create [mobtype]</li>
<li>citizens.npc.controllable /npc可控</li>
<li>citizens.npc.copy /NPC副本</li>
<li>citizens.npc.despawn /npc 消失</li>
<li>citizens.npc.edit.*<ul>
<li>citizens.npc.edit.equip /NPC装备</li>
<li>citizens.npc.edit.path /NPC路径</li>
</ul>
</li>
<li>citizens.npc.help /NPC帮助</li>
<li>citizens.npc.limit.# 限制该玩家创建 # 数量的 NPCs (适用于 1-100</li>
<li>citizens.npc.list /npc列表</li>
<li>citizens.npc.lookclose /NPC 近视</li>
<li>citizens.npc.moveto /npc 移动</li>
<li>citizens.npc.owner /npc所有者</li>
<li>citizens.npc.path /NPC路径</li>
<li>citizens.npc.power /npc电源</li>
<li>citizens.npc.profession /NPC职业</li>
<li>citizens.npc.remove /npc 移除</li>
<li>citizens.npc.remove.all /npc 全部移除</li>
<li>citizens.npc.rename /npc重命名</li>
<li>citizens.npc.select /NPC选择</li>
<li>citizens.npc.spawn /npc 生成</li>
<li>citizens.npc.speed /NPC速度</li>
<li>citizens.npc.talk 通过点击或走近聆听 NPCs</li>
<li>citizens.npc.text /NPC文本</li>
<li>citizens.npc.trait.*<ul>
<li>citizens.npc.trait /特征</li>
<li>citizens.npc.trait-configure</li>
<li>citizens.npc.trait-configure.*</li>
<li>citizens.npc.tp /npc tp</li>
<li>citizens.npc.tphere /npc 球体</li>
</ul>
</li>
</ul>
