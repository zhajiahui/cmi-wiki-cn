# 可操控 NPC

<p>可控NPCs是使用/npc controllable命令创建的。对于像 EnderDragon 这样棘手的生物类型，<code>/npc mount</code> 命令会将您置于 NPC。否则，右键安装NPC，然后在骑行时潜行+右键下车。</p>
<p>陆地生物是使用标准移动控制来控制的。潜行+左键跳跃。
空中小怪向你的光标移动。</p>
<p>要在陆地和空中之间切换，您可以使用 <code>/traitc controllable -g</code> 进行地面操作，使用 -f 进行飞行操作。</p>
<p>可控的 NPCs 也尊重你的 NPC 的速度，所以你可以使用 /npc speed 2 在安装时走得更快。</p>
