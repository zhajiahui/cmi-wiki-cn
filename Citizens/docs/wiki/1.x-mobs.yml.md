<a id="Mobs.yml"></a><h1 id="mobsyml">Mobs.yml</h1>
<p>mobs.yml 控制 Mob 类型 <a href="characters.md" title="Characters">角色类型</a>。目前，唯一的怪物角色是<a href="https://wiki.citizensnpcs.co/index.php?title=Evil_NPCs&amp;action=edit&amp;redlink=1" title="Evil NPCs (page does not exist)">敌对 NPC</a>。一般：节点控制所有小怪。邪恶：节点控制<a href="https://wiki.citizensnpcs.co/index.php?title=Evil_NPCs&amp;action=edit&amp;redlink=1" title="Evil NPCs (page does not exist)">敌对 NPC</a>。</p>
<a id="Example_mobs.yml"></a><h2 id="example-mobsyml">示例 mobs.yml</h2>
<div class="highlight"><pre>general:
  spawn:
    delay: 1  # Aufdemrand: Need to confirm whether this is ticks or minutes.

evil:
  spawn:
    max: 10
    chance: 100
    spawn: true

  items:
    tame-item: 377 
    drops: 264,265,266,

  misc:
    tame-chance: 50
    names: Bandit,Thief,
    health: 20
    failed-tame-messages: The blaze powder fails to calm your subject.;POOF! Nothing.
</pre></div>
<a id="Related_Permissions"></a><h2 id="related-permissions">相关权限</h2>
<p>有关如何使用权限的信息，请参阅 <a href="permissions.md" title="Permissions">权限</a>。下面列出的权限节点与 Mobs.yml 和 Evil NPCs 相关。</p>
<div class="highlight"><pre>citizens.evils.immune   # Those with this node will not be attacked by Evil NPCs</pre></div>
