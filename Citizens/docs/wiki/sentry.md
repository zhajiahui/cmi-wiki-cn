<p>老page:</p>
<p><strong>Sentry</strong> 是 Citizens 2.0 <a href="characters.md" title="Characters">性格特征</a>，它使 NPCs 能够：</p>
<ul>
<li>自动攻击特定的怪物、玩家或群体。</li>
<li>杀死玩家、怪物和环境，以及被它们杀死。</li>
<li>守卫位置、路径、玩家或其他 NPCs。</li>
<li>使用远程或近战武器。</li>
<li>配置力量、护甲、速度和夜视等统计数据。</li>
<li>坐骑！</li>
<li><a href="sentry-sentry-and-denizen.md" title="Sentry/Sentry and Denizen">与 Denizen 合作</a> 创建在死亡时运行脚本的 NPCs。</li>
</ul>

<p>查看help:</p>
<p>:   <strong><code>/sentry help</code></strong></p>
<p>要重新加载 config.yml：</p>
<p>:   <strong><code>/sentry reload</code></strong></p>
<p>下面的所有 /sentry 命令通常需要选定的 NPC。使用 /npc select # 来执行此操作。或者你可以使用

<p>示例：<code>/sentry 3 add target entity:monster</code> 会将怪物目标添加到 npcID 3 的哨兵中。</p>

<a id="Targets"></a><h3 id="targets">目标</h3>
<p>哨兵有 2 个列表：<strong>目标</strong> 和 <strong>忽略</strong>。这些列表包含实体。实体可以是怪物、被动生物、玩家或玩家群体。哨兵会查看其范围内所有可能看到的实体，如果它不在 <strong>忽略</strong> 列表中且在 <strong>目标</strong> 列表中，则 Sentry 将攻击它。如果实体位于视线之外或者对于 Sentry 的夜视仪而言太暗，则无法看到该实体</p>
<ul>
<li>近战哨兵会追逐目标，直到目标死亡、超出范围或另一个有效目标更接近为止。</li>
<li>远程哨兵不会跟随目标，但会停留在其位置/路径上并向目标开火，直到目标死亡、超出 <em>射弹</em>* 范围或另一个有效目标已接近为止。</li>
</ul>

<a id="Warn/Greet"></a><h4 id="warngreet">警告/问候</h4>
<p>哨兵可以选择警告或问候附近的玩家，让玩家知道 Sentry 是敌对还是友好。默认情况下此功能处于关闭状态。要打开它，请将 WARNINGRANGE 设置为高于 0。这是 Sentry 将寻找玩家警告/问候的超出范围的块数。例如，如果范围为 10，警告范围为 5，则 10-15 个方块外的玩家将收到 Sentry 的敌意警报。</p>
<p>可以为每个 Sentry 定制警告和问候消息。</p>
<p>设置警告 message:</p>
<p>:   <strong><code>/sentry warning 'New Warning Message'</code></strong></p>

<p>:   <strong><code>/sentry greeting 'New Greeting Message'</code></strong></p>

<li>&lt;PLAYER&gt; 和 &lt;NPC&gt; 可以在消息中用作玩家姓名或 Sentry 姓名的占位符。</li>

<a id="Guarding"></a><h3 id="guarding">守护</h3>
<p>哨兵有2名modes:瞭望员和保镖守卫。</p>
<a id="Lookouts"></a><h4 id="lookouts">了望台</h4>
<p>这是新 Sentry 的默认模式。瞭望台将站在单个航路点上或以默认的 NPC 速度在航路点之间行驶。他们将寻找并攻击任何目标。</p>
<ul>
<li>如果了望台被“卡住”，它将放弃其目标并传送回其航路点。</li>
<li>瞭望员应始终指定路径点，否则当目标死亡时，他们就会停止移动。使用 <strong><code>/npc path</code></strong> 设置一个或多个航路点。</li>
<li>瞭望员会忽略 PvP 保护，并且在所有情况下都会造成或受到伤害。</li>
</ul>
<p>如果 changed: 已设为此模式，则将 Sentry 设置回此模式</p>
<p>:   <strong><code>/sentry guard</code></strong></p>
<a id="Bodyguards"></a><h4 id="bodyguards">贴身护卫（bodyguard）</h4>
<p>保镖将守护跟随另一个生物体（他们的守护目标）。守卫目标可以是玩家或另一个 NPC。如果保镖准备进行报复}，它将与任何攻击其守卫目标或自身的物体交战。它还将积极参与已配置的任何目标。</p>
<ul>
<li>保镖不会对其守卫目标或守卫该目标的任何其他保镖造成伤害，也不会受到来自其的伤害。</li>
<li>如果保镖被卡住，它会在几秒钟后传送到其守卫目标。</li>
<li>如果守卫目标是玩家，并且玩家退出，保镖将留在原地，不会受到伤害或参与战斗，直到玩家返回在线并进入范围内。</li>
<li>保镖将尊重当前世界或地区可能活跃的任何 PvP 保护。 （可以在配置中更改）</li>
</ul>
<p>将 Sentry 设置为目标 NPC 或玩家的保镖：</p>
<p>:   <strong><code>/sentry guard [Name]</code></strong></p>
<ul>
<li>Notes:</li>
<li>[名称]区分大小写！</li>
<li>设置时指定的生物必须位于 NPC 的范围内。</li>
<li>默认情况下，此命令检查附近实体的指定名称，如果未找到，则检查在线玩家列表。如果这种行为是不可取的，您可以使用 <code>/sentry guard -p [Name]</code> 仅检查在线玩家列表或 <code>/sentry guard -l [Name]</code> 仅检查哨兵附近的实体。</li>
</ul>

<a id="Equipment"></a><h3 id="equipment">设备</h3>
<p>可以使用 Citizens <code>/npc equip</code> 编辑器将设备添加到 Sentries。或 <code>/sentry equip [item|none]</code> 命令。有什么区别？</p>
<ul>
<li>/npc equip</li>
<li>只能由游戏内玩家使用</li>
<li>Takes items from the player and gives it to the NPC</li>
<li>移除后会掉落所有物品</li>
<li>/sentry equip [item|none]</li>
<li>可以从控制台/脚本使用</li>
<li>不需要该项目</li>
<li>移除时不会掉落任何东西。</li>
</ul>

<a id="Dealing_Damage"></a><h3 id="dealing-damage">造成伤害</h3>
<p>Sentry攻击目标时造成的伤害等于哨兵的力量。</p>
<p>通常玩家的生命值是 20。默认情况下，Sentry 具有 1 强度，因此会造成 1 点伤害。</p>
<a id="Receiving_Damage"></a><h3 id="receiving-damage">收到损坏</h3>
<p>哨兵可以受到任何来源的伤害，就像怪物一样。如果 Sentry 设置为报复，它将瞄准任何攻击它的生物体，忽略任何当前目标。</p>
<p>如果Sentry设置为无敌，它根本不会受到伤害或击退！</p>
<p>如果 Sentry 打开了暴击，任何传入的伤害都会随机产生正常命中、未击中或几种程度的暴击之一。如果攻击者是玩家，则会根据攻击类型显示一条消息。</p>
<p>如果 Sentry 的护甲值 &gt; 0，则伤害将减少护甲值。如果伤害降至零，则攻击会导致格挡。被格挡的攻击不会造成伤害，但会造成击退！</p>
<a id="Death"></a><h3 id="death">死亡</h3>
<p>如果Sentry的生命值下降到0，它就会死亡。</p>
<p>如果 Sentry 设置为死亡时掉落，那么当它死亡时，它会像普通怪物一样掉落装备。农民们要小心了！</p>
<p>重生延迟（默认为 10 秒）后，Sentry 将重生。如果respawn设置为0，则必须手动重新生成Sentry。</p>
<p>了望台将在其生成位置重生，默认情况下，这是它们创建的位置。这可以通过 <em>/sentry spawn</em> 进行更改</p>
<p>保镖会在他们的守卫目标附近重生。</p>
<a id="Mounts"></a><h2 id="mounts">坐骑</h2>
<p>哨兵可以安装，也可以用作坐骑。</p>
<a id="Mounted_Sentries"></a><h3 id="mounted-sentries">哨兵</h3>
<p>要安装 Sentry，请使用命令 <em>/sentry mount</em>。该命令创建一匹新的永久马型 NPC 供哨兵骑乘。此 NPC 可以按照您认为合适的任何方式进行编辑。</p>
<ul>
<li>默认情况下，坐骑是马，但可以使用 <em>/npc type</em> 命令更改为任何生物类型。</li>
<li>攻击时，骑乘哨兵的移动速度是骑手速度的两倍。 (<em>/sentry speed</em>)</li>
<li>巡逻或跟随时，安装哨兵的移动速度是骑手 <em>/npc speed</em> 的两倍</li>
<li>要使安装式 Sentry 巡逻机为 <em>安装</em> 提供路径点</li>
<li>坐骑可以被杀死，哨兵将继续步行，但是如果 Sentry 在骑乘时被杀死，坐骑也会死亡。</li>
<li>坐骑重生时带有 Sentry。</li>
</ul>
<a id="Sentries_as_mounts"></a><h3 id="sentries-as-mounts">哨兵作为坐骑</h3>
<ul>
<li>要使用马-Sentry 作为玩家的坐骑，它必须是该玩家的保镖。 (<em>/sentry guard player</em>)</li>
<li>马哨兵可以正常骑乘，但如果给定目标，它们可能会忽略你的输入并自行攻击。</li>
</ul>

<a id="Known_Issues"></a><h2 id="known-issues">已知问题</h2>
<ul>
<li>PEX 附带的 Modifyworld 插件已知会导致“0 损坏”问题并阻止哨兵安装。</li>
<li>在 server.config 中关闭 PvP 将阻止攻击 NPCs。 MultiVerse 中的 pvp 设置也是如此。</li>
<li>英雄会对玩家型哨兵做出各种有趣的事情。</li>
<li>在 Sentry NPC 死机时使用命令可能会导致错误。 （/npc 生成是安全的）</li>
<li>将鞍座放在 Sentry 的安装座上将使其停止移动。</li>
</ul>
