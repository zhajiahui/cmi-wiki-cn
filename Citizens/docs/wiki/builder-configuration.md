# Builder / 配置

<p>第一次加载 Builder 时，它将创建 /Builder/config.yml。此文件可用于调整 Builder 的服务器范围选项。更改此文件后，调用 <em>/builder reload</em> 重新加载它。</p>
<p>如果 Builder 的新版本已存在，则 <strong>不</strong> 会创建一个新文件，因此请密切关注此页面，以防添加或更改更多选项。</p>
