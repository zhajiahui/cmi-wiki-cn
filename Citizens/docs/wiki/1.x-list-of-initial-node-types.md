<a id="Initial_node"></a><h1 id="initial-node">初始节点</h1>
<p><a href="https://wiki.citizensnpcs.co/index.php?title=Quests.yml&amp;action=edit&amp;redlink=1" title="Quests.yml (page does not exist)">Quests.yml</a> 中的缩写节点用于在任务开始时执行操作。</p>
<p>初始动作的配置结构与奖励相似。这是 例如：</p>
<div class="highlight"><pre>initial:
    '0':
        type: item     # Gives an item when conditions are met.
        id: 268        # wooden_sword
        amount: 1   
        take: false    # Optional. By default, take: is false.
</pre></div>
<p>可以配置多个初始动作。</p>
<a id="Initial_Types"></a><h1 id="initial-types">初始类型</h1>
<a id="Command"></a><h2 id="command">命令</h2>
<p>命令节点 (command:) - 执行命令。
由 command: 节点指定。使用 &lt;player&gt; 作为变量，该变量将替换为玩家的姓名。使用 &lt;world&gt; 作为变量，该变量将替换为玩家当前所在世界的名称。使用 server: true 从控制台执行命令。</p>
<div class="highlight"><pre>'0':
    type: command
    command: give &lt;player&gt; 1 100
    server: true
</pre></div>
<a id="NPC"></a><h2 id="npc">NPC</h2>
<p>NPC 节点 (npc:) - 向玩家授予一个 npc。
使用 name: 节点指定 npc 的名称，以及 types: 节点中以逗号分隔的切换列表（例如，商人、任务 NPC、守卫）。将创建一个由开始任务的玩家拥有的 NPC，并带有生成的 UID。</p>
<div class="highlight"><pre>'0':
    type: npc
    npcid: 1   # optional - gives the ownership of npc specified by this id to the player
    name: 'Bill'
    types: 'guard,trader,quester'
    location:
        x: 10
        y: 10
        z: -50
        world: 'world'</pre></div>
<a id="Rank"></a><h2 id="rank">排名</h2>
<p>等级节点（rank）- 向玩家授予一个组（“等级”）。
由 rank: 节点指定。</p>
<div class="highlight"><pre>'0':
    type: rank
    rank: 'admin'</pre></div>
<a id="Permission"></a><h2 id="permission">权限</h2>
<p>权限节点（permission）——授予玩家权限。
由 permission: 节点指定。</p>
<div class="highlight"><pre>'0':
    type: permission
    permission: 'quests.admin'
</pre></div>
<a id="Item"></a><h2 id="item">项目</h2>
<p>物品节点（item）- 向玩家提供项目。
从 item: 节点加载。</p>
<div class="highlight"><pre>'0':
    type: item
    item:
        id: 10
        amount: 50
        data: 0</pre></div>
<a id="Health"></a><h2 id="health">健康</h2>
<p>生命值节点（health）- 为玩家提供健康。
从 amount: 节点加载。</p>
<div class="highlight"><pre>'0':
    type: health
    amount: 10
</pre></div>
<a id="Money"></a><h2 id="money">钱</h2>
<p>金钱节点（money）- 给玩家金钱。
从 money: 节点加载。</p>
<div class="highlight"><pre>'0':
    type: money
    money: 100</pre></div>
<a id="Teleport"></a><h2 id="teleport">传送</h2>
<p>传送节点（teleport）- 将玩家传送到某个位置。
从 location: 节点加载。</p>
<div class="highlight"><pre>'0':
    type: teleport
    location:
        x: 10
        y: 50
        z: -10
        world: 'rivers'</pre></div>
