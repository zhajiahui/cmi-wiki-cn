<p>Citizens 配置了一些 YAML 文件。首次安装Citizens时会自动生成配置文件。如果文件缺少设置，它将自动生成。</p>
<a id="Configuration_files"></a><h2 id="configuration-files">配置文件</h2>
<p><a href="citizens.yml.md" title="Citizens.yml">citizens.yml</a>控制核心部件Citizens.<br/>
<a href="https://wiki.citizensnpcs.co/index.php?title=Mobs.yml&amp;action=edit&amp;redlink=1" title="Mobs.yml (page does not exist)">mobs.yml</a> 包含 <a href="https://wiki.citizensnpcs.co/index.php?title=Evil_NPCs&amp;action=edit&amp;redlink=1" title="Evil NPCs (page does not exist)">敌对 NPC</a>.<br/> 的配置节点
<a href="https://wiki.citizensnpcs.co/index.php?title=Npc_profiles.yml&amp;action=edit&amp;redlink=1" title="Npc profiles.yml (page does not exist)">npc_profiles.yml</a> 包含有关可切换 <a href="characters.md" title="Characters">角色类型</a>.<br/> 的信息
<a href="https://wiki.citizensnpcs.co/index.php?title=Quests.yml&amp;action=edit&amp;redlink=1" title="Quests.yml (page does not exist)">quests.yml</a> 包含 <a href="https://wiki.citizensnpcs.co/index.php?title=Quester&amp;action=edit&amp;redlink=1" title="Quester (page does not exist)">任务 NPC</a> 的任务文件。</p>
