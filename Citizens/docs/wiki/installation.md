# 安装

<p>安装 Citizens 2.0 很容易。这就像安装任何其他 Bukkit 插件一样。如果您不知道该怎么做，请参阅下文。</p>
<a id="Installing_Citizens_2.0"></a><h2 id="installing-citizens-20">安装Citizens 2.0</h2>
<ol>
<li>下载 Citizens <a href="downloads.md" title="Downloads">这里</a>。</li>
<li>将 Citizens 2.0 jar 放入 <em>/plugins</em> 目录中。</li>
<li>下载任何所需的 <a href="characters.md" title="Characters">特征</a> 插件并将它们也放置在 <em>/plugins</em> 目录中。</li>
<li>重新加载或重新启动服务器。 Citizens 2 将创建一个plugins/Citizens 文件夹和一个config.yml 文件。</li>
<li>使用 config.yml 根据您的喜好配置 Citizens。请参阅 <a href="configuration.md" title="Configuration">配置</a> 页面以获取更多帮助。</li>
<li>重新加载或重新启动服务器。</li>
<li>开始创建和编辑NPCs！</li>
<li>请务必设置 <a href="permissions.md" title="Permissions">权限</a>，以便您的玩家可以与 NPCs 交互。</li>
<li><strong>请注意，玩家需要 citizens.npc.talk 权限才能听到 NPCs！</strong></li>
</ol>
