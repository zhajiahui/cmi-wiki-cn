# DtlTraders / 交易

<a id="Using_the_trader"></a><h2 id="using-the-trader">使用商人</h2>
<ol>
<li>空手右键点击 NPC</li>
<li>要在买入/卖出之间切换，请点击右下角的石灰/青色羊毛。</li>
</ol>
<a id="Buy_menu"></a><h2 id="buy-menu">购买菜单</h2>
<ol>
<li>点击某个项目会显示价格或弹出金额选择菜单。</li>
<li>第二次点击该商品即可购买。</li>
</ol>
<p>在金额选择菜单中，您可以点击红色羊毛以返回到商人的主要库存。</p>
<a id="Sell_menu"></a><h2 id="sell-menu">销售菜单</h2>
<ol>
<li>点击某个项目一次即可显示您将获得该项目的价格。</li>
<li>第二次点击该物品即可将其出售。</li>
</ol>
<p><strong>Note:</strong> 除非您设置了接受的商品及其价格，否则 NPCs 不会购买任何东西。</p>
