# 版本

<p><strong>强烈建议您始终运行最新的 Minecraft 版本和最新的 Citizen 版本。如果您运行旧版本的 Citizen，则无法获得支持。</strong></p>
<p>Citizens支持Minecraft的多个版本。由于 Spigot 文件大小限制，主动支持的版本会随着时间的推移而变化。它不支持<em>每个</em>版本的Minecraft，仅支持一些。</p>
<p>对于每个 Minecraft 版本 1.xx.y，仅支持 <strong>最新的</strong> Minecraft 补丁版本。例如，在Minecraft 1.18中，最新补丁版本是1.18.2，因此Citizens的最新版本仅适用于Minecraft版本1.18.2，而不是1.18或1.18.1。</p>
<p>Minecraft 1.8.8 支持很特殊，因为它太旧了，在这里单独讨论：<a href="minecraft-1.8.md" title="Minecraft 1.8">Minecraft 1.8 服务器</a></p>
<p>Citizens目前支持的Minecraft版本列表可以在这里查看<a href="https://www.spigotmc.org/resources/citizens.13811/updates">[1]</a>。</p>
<p>Sentinel 和 Denizen 仅支持 3-4 个近期主要 Minecraft 更新 例如 1.17.1、1.18.2、1.19.4。他们不支持 1.8.8。</p>
