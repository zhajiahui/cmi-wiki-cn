<p><strong>任务 NPC</strong> 允许玩家进行多种不同类型的任务。他们可以收集或放置方块、攻击小怪、移动一定距离等等！ Quests 可在 <a href="1.x-quests.yml.md" title="1.x/Quests.yml">1.x/Quests.yml</a> 文件中完全自定义。您可以将这些任务分配给任务者，并让您的玩家执行有趣的任务。请参阅下文，了解有关设置任务者和自定义任务的信息。</p>

<a id="Usage"></a><h2 id="usage">用途</h2>
<p>要接受任务，请前往任务者 NPC 处。通过左键点击，您可以滚动浏览任务者分配给它并且您可以接受的每个可能任务的描述。右键点击接受任务。</p>
<p>任何时候只能接受一个任务 - 使用 /quest abort 放弃当前任务。</p>
<p>可以随时通过 /quest status 查看当前任务的状态。任务完成后，返回原来的任务者NPC并右键点击他们即可完成任务。</p>
<a id="Quest_Configuration"></a><h2 id="quest-configuration">任务配置</h2>
<p>有关编写和编辑任务结构的详细信息，请参阅 <a href="1.x-quests.yml.md" title="1.x/Quests.yml">1.x/Quests.yml</a>。</p>
<a id="Troubleshooting_Quests.yml"></a><h2 id="troubleshooting-questsyml">故障排除 Quests.yml</h2>
<p>任务文件的许多问题都是由格式不正确的 YAML 引起的。为了确保您的 YAML 任务文件能够被正确解析，这个方便的工具可能会有所帮助。 <a href="http://yaml-online-parser.appspot.com/">这个在线 YAML 解析器</a> 将在左侧窗口中获取输入语法，如果正确解析，将在右侧显示结果。如果出现错误，请检查您的 <a href="1.x-quests.yml.md" title="1.x/Quests.yml">1.x/Quests.yml</a> 格式并重试。</p>
<p>编写自定义任务时，请彻底检查格式，尤其是目标。 <a href="1.x-quests.yml.md" title="1.x/Quests.yml">1.x/Quests.yml</a> 页面概述了任务所需的每个节点。</p>
