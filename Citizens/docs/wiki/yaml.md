# YAML

<p>所有脚本和配置节点都在YAML中。记住！处理 YAML 文件时，间距至关重要。每个父节点和同级节点应遵循 YAML 1.0 标准规定的间距和格式指南。一般来说，您的缩进应该保持一致。在本指南中使用的所有示例中，均使用 2 个空格进行缩进。一般来说，无论您选择什么，都应该通过 YAML 文档进行维护。请记住：YAML 文件中不允许使用制表符。如果您使用记事本++编辑脚本，请务必更改首选项&gt;语言菜单/选项卡设置中的制表符-&gt;空格设置。</p>
<p>在所有denizen YAML 文件中，节点都是区分大小写的！例如，在 script.yml 中，“脚本：”将起作用。 “scripts:”不会！所有节点的首字母大写，其余单词小写。脚本名称也遵循这个规则！另外：命令/要求通常是 ALL 大写，但我们会讲到这一点。</p>
<p>YAML 教程可能会令人生畏，但 <a href="http://wiki.ess3.net/wiki/YAML_Tutorial">Essentials wiki 上的这个小教程</a> 对于基本 YAML 非常有用，这是 Denizens 使用的范围。</p>
