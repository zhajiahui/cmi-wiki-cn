<p>为了帮助通用目标设计，每个目标可以使用一组通用的 variables: 金额、余量、字符串、materialid、位置、项目和 npcdestination（目标 NPC ID）之一。</p>
<p>每种目标类型可以使用这些变量中的一个或多个。</p>
<p>项目节点具有三个子节点，其中两个必须包含，一个可选。</p>
<ul>
<li><em>编号</em> 子节点指定项目/块 ID。</li>
<li><em>金额</em> 子节点指定项目金额。</li>
<li>可选的 <em>数据</em> 子节点指定要使用的项目数据值。</li>
</ul>
<p>位置节点有 4 个必需的子节点，两个可选。</p>
<ul>
<li><em>世界</em> 节点指定位置的世界名称。</li>
<li><em>x</em>、<em>y</em> 和 <em>z</em> 节点指定 x、y 和 z 值。</li>
<li>可选的 <em>音高</em>/<em>偏航</em> 节点指定位置的旋转（想想飞机）。</li>
</ul>
<p>可以包含其他可选节点以获得更多功能。这些都不是必需的。</p>
<ul>
<li><em>在这里完成</em>节点可以指示任务在该步骤完成。默认情况下，要完成任务，您必须与原始任务者交谈。</li>
<li>当目标完成时，<em>留言</em> 节点将向玩家显示文本。</li>
<li><em>奖励</em> 节点的设置与任务奖励完全相同，只不过是在玩家完成子目标时授予的。</li>
<li><em>可选的</em>节点可以设置一个可选的目标。这通常是通过“支线任务”能力的子目标奖励来支持的。</li>
</ul>
<a id="Objective_Types"></a><h1 id="objective-types">目标类型</h1>
<p>以下是目标类型及其所需的标志。请记住：任务子目标还可以有其他可选节点。</p>
<a id="Build"></a><h2 id="build">构建</h2>
<p>建造任务需要玩家放置一定数量的方块。</p>
<div class="highlight"><pre>'0':
    '0':    
        type: build      # Specifies build objective.
        materialid: 54  # Chest. Material player is required to build.
        amount: 1        # Number of items that must be placed.
</pre></div>
<a id="Chat"></a><h2 id="chat">聊天</h2>
<p>聊天任务需要在聊天中说些什么。</p>
<div class="highlight"><pre>'0':
    '0':
        type: chat
        string: 'I cracked the code!'
</pre></div>
<p>聊天任务可以进一步扩展。 string: 节点可以是所有可匹配文本的逗号分隔列表。特殊语法标志是 r: 来匹配正则表达式，c: 来检查文本是否包含其他内容。例如，“r:[0-9]”匹配任何 1 位数字，“c:hi”匹配任何包含“hi”的文本。</p>
<p>通过设置leeway:和npcid:参数，可以将有效聊天限制在以NPC为半径的范围内。</p>
<a id="Location"></a><h2 id="location">地点</h2>
<p>位置任务（移动位置）要求玩家位于某个位置的特定范围内。</p>
<div class="highlight"><pre>'0':
    '0':    
        type: move location   # Specifies loaction objective.
        location:
            x: 150       # Coordinates of location required to visit.
            y: 47
            z: 420
            world: 'world'
        time: 10         # The time (in seconds) that the player has to stay in this location for.
        leeway: 1        # The leeway in blocks that the player can be away from the location before finishing.
</pre></div>
<p>在以前的版本中，块中的余地是通过 amount: 节点设置的。 1.1.6 开始，使用 leeway: 代替。此外，在 1.1.5 中，地点任务被破坏了。</p>
<a id="Hunt"></a><h2 id="hunt">亨特</h2>
<p>狩猎任务需要玩家杀死一定数量的怪物。</p>
<div class="highlight"><pre>'0':
    '0':    
        type: hunt   # Specifies hunt objective.
        amount: 10         # The amount of monsters the player needs to kill.
        string: LavaSlime, PigZombie    # Requires Magma Cubes and Zombie Pigmen to be killed to count.
                      # Using '-' as the first character makes a whitelist. '*' represents all.
</pre></div>
<p>有效实体类型已分类并列出 below:</p>
<p><strong>被动-</strong>
鸡、牛、蘑菇牛、奥泽洛特、猪、羊、鱿鱼、村民</p>
<p><strong>中性 -</strong>
末影人、狼、猪僵尸</p>
<p><strong>敌对的——</strong>
火焰、洞穴蜘蛛、苦力怕、恶魂、熔岩史莱姆、银鱼、骷髅、史莱姆、蜘蛛、僵尸</p>
<p><strong>实用程序 -</strong>
雪人、村民傀儡</p>
<p><strong>老板们——</strong>
末影龙</p>
<a id="Move_Distance"></a><h2 id="move-distance">移动距离</h2>
<p>移动距离任务要求玩家行走一定数量的方块。</p>
<div class="highlight"><pre>'0':
    '0':    
        type: move distance   # Specifies move distance objective.
        amount: 1000         # The amount of blocks required to traverse.
</pre></div>
<a id="Destroy_Block"></a><h2 id="destroy-block">摧毁方块</h2>
<p>摧毁方块任务要求玩家打破一定数量的方块。</p>
<div class="highlight"><pre>'0':
    '0':    
        type: destroy block   # Specifies hunt objective.
        amount: 10         # The amount of blocks to break.
        materialid: 1        # The type of block required.
</pre></div>
<a id="Delivery"></a><h2 id="delivery">发货</h2>
<p>运送任务要求玩家将指定物品“运送”到指定的NPC。</p>
<div class="highlight"><pre>'0':
    '0':
        type: delivery    # Delivery Quest type
        materialid: 341     # Slimeballs set as material to deliver.
        amount: 6      # Quantity: 6
        npcdestination: 22      # deliver to NPC ID
</pre></div>
<a id="Player_Combat"></a><h2 id="player-combat">玩家战斗</h2>
<p>战斗任务（玩家战斗）——杀死一定数量的玩家。</p>
<div class="highlight"><pre>'0':
    '0':
        type: player combat    # Player Combat type
        amount: 1    # Amount of players to kill
        string: Notch,fullwall,      # Which players should be killed. 
                # Using '-' as the first character makes a whitelist. '*' represents all. g:group represents groups.
</pre></div>
<a id="KillNPC"></a><h2 id="killnpc">杀死NPC</h2>
<ul>
<li>注意：需要 Citizens 1.1.6 或更高版本。</li>
</ul>
<p>杀死 NPC 任务要求玩家杀死守卫 NPC。注意：EvilNPC 很快就会得到支持。</p>
<div class="highlight"><pre>'0':
    '0':
        type: killNPC    # KillNPC type
        amount: 1
        string: Cantrell,Notch,      # Which NPCs should be killed. 
                # Using '-' as the first character makes a whitelist.  '*' represents all. NPC ID or Name can be used.
</pre></div>
<a id="Collect"></a><h2 id="collect">收集</h2>
<p>收集任务要求玩家拾取一定数量的物品。</p>
<div class="highlight"><pre>'0':
    '0':    
        type: collect   # Specifies hunt objective.
        amount: 10         # The amount of blocks to collect.
        materialid: 3        # The type of block required.
</pre></div>
<p>注意：要注册的物品，玩家必须从地上捡起它们。通过箱子/熔炉获得的材料不会注册。这也开启了一个可能的漏洞，玩家可以扔掉并捡起相同的物品，以使其多次计数。防止这种情况的一种方法是跟进一个交付任务，该任务需要将物品实际交付到 NPC 以检查数量是否正确。</p>
