<a id="Creating_your_first_NPC"></a><h2 id="creating-your-first-npc">创建您的第一个 NPC</h2>
<p>请务必阅读 <a href="commands.md" title="Commands">命令</a> 页面，深入了解可用于自定义 NPCs 的所有命令。目前，这是有关如何设置 NPC 的基本指南。</p>
<p>型号 <em>/npc create [name]</em>。将 <em>[姓名]</em> 替换为您的 NPC 的名称。或者，您可以将文本添加到 NPC。为此，只需在 NPC 名称后添加单词即可。示例：</p>
<div class="highlight"><pre>/npc create Notch I like cookies!</pre></div>
<p>就是这样！当然，您还可以使用基本 NPCs 执行各种其他操作，如 <a href="commands.md" title="Commands">命令</a> 中所示。</p>
