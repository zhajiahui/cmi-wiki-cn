# NPC 类型

<p>要创建不同类型的 NPC（人类除外），只需使用 --type 标志。</p>
<p><em><code>/npc create 'npc name' --type pig -b</code></em></p>
<p>这会产生一头小猪。去掉 -b 以创建成人。</p>
<p>要更改现有 NPC 的类型，请使用</p>
<p><em><code>/npc type pig</code></em></p>
<p>您可以使用任何 Spigot 实体类型：<a href="https://hub.spigotmc.org/javadocs/spigot/org/bukkit/entity/EntityType.html">https://hub.spigotmc.org/javadocs/spigot/org/bukkit/entity/EntityType.html</a></p>
