<p><strong>敌对 NPC</strong> 是所有 Citizens NPC 类型中最容易被误解的。他们一看到你就会发起攻击。通过使用可配置的驯服项目右键点击它们来驯服这些可怜的生物。一旦被驯服，它们就可以变成任何 NPC 类型。他们只是想融入其中！邪恶NPCs可以用<a href="https://wiki.citizensnpcs.co/index.php?title=Mobs.yml&amp;action=edit&amp;redlink=1" title="Mobs.yml (page does not exist)">mobs.yml</a>中的邪恶：节点来控制。</p>
<p>邪恶的 NPCs 包含在 Citizens 的核心中，因此不需要额外的类型 JAR。</p>
<a id="Configuration_Nodes"></a><h2 id="configuration-nodes">配置节点</h2>
<p>这些节点可以在<a href="https://wiki.citizensnpcs.co/index.php?title=Mobs.yml&amp;action=edit&amp;redlink=1" title="Mobs.yml (page does not exist)">mobs.yml</a>中找到。</p>
<div class="highlight"><pre>evil:
  spawn:
    spawn: true   # Whether to spawn evil NPCs. Default is false.
    max: 5        # Number of NPCs to spawn. Default is 2.
    chance: 100   # Chance of NPSs spawning after delay: node setting in mobs.yml.

  items:
    tame-item: 377          # Blaze Powder 
    drops: 260,357,2256,    # List of possible drops for an evil NPC.
                            # Note: Leave a trailing comma.

  misc:
    tame-chance: 50           # Percentage chance Evil NPC will be tamed 
                              # by right-clicking with tame-item.
    names: Bandit,Herobrine,  # Names of the Evil NPCs.
                              # Note: Leave a trailing comma.
    health: 20                # For reference, standard player health is 20
    failed-tame-messages: The blaze powder fails to calm your subject.;POOF! Nothing.
</pre></div>
<a id="Related_Permissions"></a><h2 id="related-permissions">相关权限</h2>
<p>有关如何使用权限的信息，请参阅 <a href="permissions.md" title="Permissions">权限</a>。下面列出的权限节点与 Mobs.yml 和 Evil NPCs 相关。</p>
<div class="highlight"><pre>citizens.evils.immune   # Those with this node will not be attacked by Evil NPCs</pre></div>
