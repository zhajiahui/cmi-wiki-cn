<p>权限对于控制 Citizens 的各个方面都至关重要。您可以使用它来微调您希望用户使用的功能。目前 Citizens 仅适用于 SuperPerms 插件，例如 Permissions EX。这些节点供您的权限插件提供的 permissions.yml 使用。有关确切用法，请参阅您的权限系统文档。</p>
<a id="Configuration_Examples"></a><h1 id="configuration-examples">配置举例</h1>
<a id="Very_Basic_Permissions_Configuration"></a><h2 id="very-basic-permissions-configuration">非常基本的权限配置</h2>
<p>要向公民授予所有功能，请使用此权限节点。它向您的用户授予所有功能。</p>
<div class="highlight"><pre>citizens.*</pre></div>
<p>您可能还想禁用以下节点，因为它本质上限制了功能而不是启用它。有关详细信息，请参阅 <a href="https://wiki.citizensnpcs.co/index.php?title=Evil_NPCs&amp;action=edit&amp;redlink=1" title="Evil NPCs (page does not exist)">敌对 NPC</a>。</p>
<div class="highlight"><pre>- citizens.evils.immune</pre></div>
<a id="Basic_Permission_Example"></a><h2 id="basic-permission-example">基本权限示例</h2>
<p>下面是一个稍微更强大的权限设置示例，非常适合 RPG 风格的服务器，其中“管理员”设置 NPCs 供玩家使用和交互。这允许管理员完全控制 Citizens，同时只授予普通玩家与 NPC 角色交互的权限。请参阅您的权限文档以了解确切的格式。</p>
<div class="highlight"><pre>admins:
citizens.*

default:
citizens.wizard.use.interact
citizens.quester.use.*
citizens.blacksmith.use.repair
citizens.trader.use.trade
citizens.healer.use.heal
</pre></div>
<a id="Advanced_Permissions"></a><h2 id="advanced-permissions">高级权限</h2>
<p>实际上有数千种使用权限的方法。下面我们引用了完整的权限节点列表，您可以授予或拒绝玩家创建特定的情况，仅受您的想象力限制。</p>
<p>对于 例如： 玩家一开始只能拥有任务者权限，并通过授予权限作为奖励来使用任务来授予其他 NPC 角色类型的使用权。</p>
<p>还有什么？ <a href="irc://irc.esper.net">你告诉我们！</a> 祝您微调愉快！</p>
