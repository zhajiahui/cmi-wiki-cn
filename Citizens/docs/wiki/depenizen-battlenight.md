<a id="Denizen_Commands"></a><h1 id="denizen-commands">Denizen 命令</h1>
<p>BattleNight 命令非常简单。您应该记住，任何 Denizen 命令都可以有一个“player:&lt;player&gt;”参数来更改指定的玩家。
例如，如果您想将不是当前附加玩家的玩家添加到战斗中，您可以使用“-bn add player:PlayerName”</p>
<a id="-_bn_add"></a><h2 id="-bn-add">- bn 添加</h2>
<p>将一名玩家添加到当前战斗中。</p>
<a id="-_bn_kick"></a><h2 id="-bn-kick">- bn 踢</h2>
<p>将一名玩家踢出当前战斗。</p>
<a id="-_bn_start"></a><h2 id="-bn-start">- bn 开始</h2>
<p>开始战斗。</p>
<a id="-_bn_end"></a><h2 id="-bn-end">- bn结束</h2>
<p>结束一场战斗。</p>
