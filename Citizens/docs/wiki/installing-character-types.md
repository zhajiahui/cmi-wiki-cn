# 安装角色类型

<p>安装角色类型因类型而异，但通常遵循此模式。</p>
<ol>
<li>关闭你的服务器</li>
<li>将角色类型的 jar 下载到您的插件文件夹中</li>
<li>启动您的服务器，然后再次关闭它</li>
<li>编辑该角色类型的任何必要的配置文件</li>
<li>重新打开服务器</li>
<li>???</li>
<li>Profit.</li>
</ol>
<p>有关该类型安装的具体详细信息，请参阅单个角色的 wiki 页面。</p>
