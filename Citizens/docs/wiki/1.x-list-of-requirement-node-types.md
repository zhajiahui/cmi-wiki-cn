<a id="Requirements_node"></a><h1 id="requirements-node">需求节点</h1>
<p><a href="https://wiki.citizensnpcs.co/index.php?title=Quests.yml&amp;action=edit&amp;redlink=1" title="Quests.yml (page does not exist)">Quests.yml</a> 中使用需求节点来告诉询问者在任务开始之前玩家需要什么。如果满足“要求：”节点中列出的所有要求，则授予该任务。要求与奖励有很多共同点，因为大多数奖励类型也可以用于要求。</p>
<p>例如：</p>
<div class="highlight"><pre>requirements:
    '0':
        type: item    # Requires an item.
        id: 371       # gold_nugget
        amount: 30
        take: true    # Takes the gold nuggets from the player.
    '1':
        type: quest   # Requires a quest to be completed prior.
        quest: "Example Quest"
</pre></div>
<p>您可能有多项要求，也可能只有一项要求。</p>
<a id="Requirement_Types"></a><h1 id="requirement-types">需求类型</h1>
<a id="NPC"></a><h2 id="npc">NPC</h2>
<p><em><a href="https://wiki.citizensnpcs.co/index.php?title=Notes_from_aufdemrand&amp;action=edit&amp;redlink=1" title="Notes from aufdemrand (page does not exist)">aufdemrand 的注释</a>： 很确定这有效，但需要测试才能确定。</em></p>
<p>NPC 要求 (npc:) - 要求玩家拥有 NPC。
使用 name: 节点指定 npc 的名称，以及 types: 节点中以逗号分隔的切换列表（例如，商人、任务 NPC、守卫）。将创建一个由完成任务的玩家拥有的 NPC，并生成 UID。</p>
<p>take: 节点可选。默认值为 take: false。</p>
<div class="highlight"><pre>'0':
    type: npc
    npcid: 1   # id of npc in which to check ownership
</pre></div>
<a id="Rank"></a><h2 id="rank">排名</h2>
<p>等级要求（等级）- 检查玩家是否有权访问某个组（“等级”），前提是该组使用兼容的权限系统。
由 rank: 节点指定。</p>
<p>take: 节点可选。默认值为 take: false。</p>
<div class="highlight"><pre>'0':
    type: rank     # Checks for rank
    rank: 'admin'  # Quest requires admin rank
</pre></div>
<a id="Permission"></a><h2 id="permission">权限</h2>
<p>权限要求（permission）——检查玩家是否拥有指定的权限。
由 permission: 节点指定。</p>
<p>take: 节点可选。默认值为 take: false。</p>
<div class="highlight"><pre>'0':
    type: permission   # Checks for permission
    permission: 'modifyworld.blocks.place.4' # Can user place cobblestone?
</pre></div>
<a id="Quest"></a><h2 id="quest">任务</h2>
<p>任务要求（quest）- 检查任务是否已完成。
由 quest: 节点指定。</p>
<p>Quest 需求节点不支持 take: 节点。</p>
<div class="highlight"><pre>'0':
    type: quest
    quest: 'Slime Slaying I'</pre></div>
<a id="Item"></a><h2 id="item">项目</h2>
<p>物品奖励（物品）- 在开始之前检查玩家是否有指定物品。也可以在接受任务时使用 take=true 来获取物品。
从 item: 节点加载。</p>
<p>take:节点是可选的。默认值为 take: false。
data: 节点可选。</p>
<div class="highlight"><pre>'0':
    type: item    # 
    item:
    id: 50
    amount: 50</pre></div>
<div class="highlight"><pre>   take: false   # Only checks for items, does not take them.
</pre></div>
<a id="Health"></a><h2 id="health">健康</h2>
<p><em><a href="https://wiki.citizensnpcs.co/index.php?title=Notes_from_aufdemrand&amp;action=edit&amp;redlink=1" title="Notes from aufdemrand (page does not exist)">aufdemrand 的注释</a>： 很确定这有效，但需要测试才能确定。</em></p>
<p>健康奖励（健康）- 为玩家提供健康。
从 amount: 节点加载。</p>
<p>take: 节点可选。默认值为 take: false。</p>
<div class="highlight"><pre>'0':
    type: health
    amount: 10
</pre></div>
<a id="Money"></a><h2 id="money">钱</h2>
<p>金钱奖励（金钱）- 检查玩家是否拥有指定金额的金钱。也可以用来在接受任务时获取金钱。
从 money: 节点加载。</p>
<p>take: 节点可选。默认值为 take: false。</p>
<div class="highlight"><pre>'0':
    type: money
    money: 100
    take: true  # Takes money from player </pre></div>
