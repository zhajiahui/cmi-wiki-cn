# Sentry / 配置

<p>第一次加载 Sentry 时，它将创建 /Sentry/config.yml。此文件可用于调整 Sentry 的服务器范围选项。更改此文件后，调用 /sentry Reload 来重新加载它。</p>
<p>如果 Sentry 的新版本已经存在，则不会创建新文件，因此请密切关注此页面，以防添加或更改更多选项。</p>
<p>注意：所有项目都可以通过名称或 ID 进行匹配。我知道有些用户想要匹配数据值和/或附魔值。将来会添加此功能。</p>
