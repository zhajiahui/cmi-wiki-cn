<p>Citizens 具有许多增强的消息功能 - 大多数消息应该支持这些功能（如果不支持，请告诉我们）。</p>
<p>如果您想到任何额外的功能，我们很乐意倾听。</p>
<a id="General"></a><h2 id="general">一般</h2>
<p>可以使用颜色代码和名称对消息进行着色。</p>
<ul>
<li>&lt;[colour code]&gt; - 例如。 “&lt;1&gt;你好。”打印出深蓝色的“Hello”。</li>
<li>&lt;colour name&gt; - 例如。 “&lt;gray&gt;你好。” - 请注意，名称遵循 Bukkit 的约定，其中深色替换为 d（“dred”而不是“深红色”），浅色替换为 l（“lpurple”而不是“浅紫色”）。 &lt;g&gt;和&lt;y&gt;是绿色和黄色的特殊捷径。</li>
</ul>
<p>换行符由 &lt; br&gt; 表示（替换前导空格）。
例如：“这是一段很长的 &lt; br&gt; 文本。”将会出来 as:
'这是一个长
一段文字。</p>
<p>消息可以通过使用延迟 <delay=ticks> 标签。请记住，每秒大约有 20 个刻度。
'这是 <delay=100> 一段文字。将首先显示“这是”，然后显示“一段文本”。五秒钟后。
您可以在一条消息中使用多个 &lt;delay&gt; 标签。</delay=100></delay=ticks></p>
<a id="Player_Messages"></a><h2 id="player-messages">玩家留言</h2>
<p>当玩家参与时（即大多数时间），可以使用以下功能。</p>
<ul>
<li>&lt;name&gt; - 被玩家的名字取代。</li>
<li>&lt;world&gt; - 替换为玩家当前世界的名称。</li>
<li>&lt;h&gt; - 被玩家的生命值取代。</li>
</ul>
<a id="NPC_Messages"></a><h2 id="npc-messages">NPC 消息</h2>
<p>当消息或消息周围的事件涉及NPC时，可以使用以下功能。</p>
<ul>
<li>&lt;npc&gt; - 替换为 NPC 的名称。</li>
<li>&lt;npcid&gt; - 替换为 NPC 的 ID。</li>
</ul>
