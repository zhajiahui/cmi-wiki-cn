# DtlTraders / 命令

<p>DtlTraders 力求尽可能方便用户，因此只需记住几个重要命令。大多数任务无需使用它们即可完成。</p>
<p><strong>[]</strong> - 强制 <br/>
<strong>()</strong> - 可选</p>
<p><strong>Command</strong> - 命令名称 <br/>
<strong>Args</strong> - 必须或可以解析的参数 <br/>
<strong>Mode</strong> - 该命令是否要求处于某种模式 <br/>
<strong>Description</strong> - 命令的简短描述</p>
<a id="Commands"></a><h2 id="commands">命令</h2>
<p><strong>命令</strong></p>
<p><strong>参数</strong></p>
<p><strong>模式</strong></p>
<p><strong>描述</strong></p>
<p><code>/trader</code></p>
<p><code>no arguments</code></p>
<p><code>no mode required</code></p>
<p><code>shows info about the current selected trader or just the plugin version</code></p>
