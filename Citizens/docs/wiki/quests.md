# Quests

<p>《Citizens1》中的“Quester”已停产。有一些很棒的选项可以完成 Quester 所做的一切和 more:</p>
<ul>
<li><a href="denizen.md" title="Denizen">Denizen</a> 可用于编写交互和事件脚本，从而对玩家 'questing' 进行高级控制，以及许多其他有趣的功能。</li>
<li><a href="http://www.theminequest.com/">探矿之旅</a> 是一个外部插件，可与 Citizens 2 NPCs 一起使用。见<a href="http://www.theminequest.com/threads/rpg-minequest-citizens-2-0-0-cb-1-2-5-r5-1.72/">这里</a></li>
<li>Blackvein 的 <a href="http://dev.bukkit.org/server-mods/quests/">Quests</a> 是一个外部插件，可与 Citizens 2 NPCs 一起使用，这提供了与 Citizens1 Quester 类似的功能。</li>
<li><a href="http://dev.bukkit.org/server-mods/quester/">任务 NPC</a> 可与 Citizens 2 NPCs 一起使用的外部插件。</li>
</ul>
