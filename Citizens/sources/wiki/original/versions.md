**IT IS VERY STRONGLY RECOMMENDED THAT YOU ALWAYS RUN THE LATEST MINECRAFT VERSION, AND LATEST CITIZENS VERSION. SUPPORT IS NOT POSSIBLE IF YOU ARE RUNNING AN OLD VERSION OF CITIZENS.**

Citizens supports multiple versions of Minecraft. Due to Spigot filesize limitations, the actively supported versions change over time. It does not support *every* version of Minecraft, just some.

For each Minecraft version 1.xx.y, only the **latest** Minecraft patch-version is supported. For example in Minecraft 1.18, the latest patch version is 1.18.2 and so the latest version of Citizens will only work with Minecraft Version 1.18.2, not 1.18 or 1.18.1.

Minecraft 1.8.8 support is special since it is so old and is discussed separately here: [Minecraft 1.8 Servers](https://wiki.citizensnpcs.co/Minecraft_1.8 "Minecraft 1.8")

Citizens' currently supported Minecraft version list is available here[[1]](https://www.spigotmc.org/resources/citizens.13811/updates).

Sentinel and Denizen only support the 3-4 recent major Minecraft updates e.g. 1.17.1, 1.18.2, 1.19.4. They do not support 1.8.8.
