## What is Depenizen?

Depenizen is a simple plugin that does exactly what its name implies: adds external plugin dependencies to Denizen. It adds commands, tags, events, etc for use with other plugins (such as mcMMO, Factions, and Towny) into Denizen, so you can control everything that goes on and maximize the RPG feel you want for your server.

## How do I install Depenizen?

1. [Install Citizens 2](https://wiki.citizensnpcs.co/Installation "Installation")
2. Download the latest development version of [Denizen](http://ci.citizensnpcs.co/job/Denizen/lastSuccessfulBuild/).
3. Download the latest development version of [Depenizen](http://ci.citizensnpcs.co/job/Depenizen/lastSuccessfulBuild/).
4. Place the plugins in your plugins folder and restart your server.

## Can I request a new plugin be supported by Depenizen?

Sure, just ask us on the GitHub issues page [here](https://github.com/DenizenScript/Depenizen/issues). Be sure to include the plugin name, a link to the BukkitDev page, and details about what commands, tags, or events you want implemented into Depenizen. We'll get back to you as soon as possible.
