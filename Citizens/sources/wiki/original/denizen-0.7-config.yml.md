<div class="mw-heading mw-heading3"><h3 id="Denizen_config.yml">Denizen config.yml</h3></div>
<div style="margin-right:2.0em;padding:10px; font-family:camingodos-web; font-size:110%;">The Denizen config.yml contains nodes to alter the default behavior and look of Denizen. 
<p>This file can be reloaded from disk to Denizen memory at any time by using /denizen reload. Some changes in the config.yml may require a restart of the server. This includes interact_delay_in_ticks, but is not limited to that config node.
</p><p>To change the Denizen defaults:
</p>
<ul><li>Open config.yml located in the plugins\Denizen\ directory.</li>
<li>Edit the defaults, save the file, and call /denizen reload from in-game or the console. Denizen will alert you of a successful reload.</li></ul>
</div>
