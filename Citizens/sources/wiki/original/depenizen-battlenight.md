# Denizen Commands

The BattleNight commands are pretty straight-forward. You should remember that any Denizen command can have a "player:<player>" argument to change the specified player.
For example, if you wanted to add a player to a battle that isn't the currently attached player, you can use "- bn add player:PlayerName"

## - bn add

Adds a player to the current battle.

## - bn kick

Kicks a player from the current battle.

## - bn start

Starts a battle.

## - bn end

Ends a battle.
