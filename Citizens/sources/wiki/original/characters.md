Characters are addons that use the [Citizens API](https://wiki.citizensnpcs.co/API "API") to add functionality to existing NPCs. Download and install their plugin JAR into the */plugins* directory.

Citizens NPCs can contain multiple traits at the same time. See [Multiple Traits](https://wiki.citizensnpcs.co/Multiple_Traits "Multiple Traits")

## Suggested Addons

There is no guarantee of any of these still being available/updated. If you would like to be added to the list please message the team on Discord.

There are also many addons available outside of the wiki.
