# Mobs.yml

The mobs.yml controls Mob type [Characters](https://wiki.citizensnpcs.co/Characters "Characters"). Currently, the only mob character are [Evil NPCs](https://wiki.citizensnpcs.co/index.php?title=Evil_NPCs&action=edit&redlink=1 "Evil NPCs (page does not exist)"). The general: node controls all mobs. The evil: node controls [Evil NPCs](https://wiki.citizensnpcs.co/index.php?title=Evil_NPCs&action=edit&redlink=1 "Evil NPCs (page does not exist)").

## Example mobs.yml

```
general:
  spawn:
    delay: 1  # Aufdemrand: Need to confirm whether this is ticks or minutes.

evil:
  spawn:
    max: 10
    chance: 100
    spawn: true

  items:
    tame-item: 377 
    drops: 264,265,266,

  misc:
    tame-chance: 50
    names: Bandit,Thief,
    health: 20
    failed-tame-messages: The blaze powder fails to calm your subject.;POOF! Nothing.
```

## Related Permissions

See [Permissions](https://wiki.citizensnpcs.co/Permissions "Permissions") for information on how to use permissions. The listed permission nodes below relate to Mobs.yml and Evil NPCs.

```
citizens.evils.immune   # Those with this node will not be attacked by Evil NPCs
```
