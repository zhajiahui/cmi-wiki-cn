Installing Citizens 2.0 is easy. It is like installing any other Bukkit plugin. If you don't know how to do that, see below.

## Installing Citizens 2.0

1. Download Citizens [here](https://wiki.citizensnpcs.co/Downloads "Downloads").
2. Place the Citizens 2.0 jar in your */plugins* directory.
3. Download any desired [Trait](https://wiki.citizensnpcs.co/Characters "Characters") plugins and place these in the */plugins* directory as well.
4. Reload or restart your server. Citizens 2 will create a plugins/Citizens folder and a config.yml file.
5. Configure Citizens to your liking with config.yml. See the [Configuration](https://wiki.citizensnpcs.co/Configuration "Configuration") page for more help.
6. Reload or restart your server.
7. Start creating and editing NPCs!
8. Be sure to set [Permissions](https://wiki.citizensnpcs.co/Permissions "Permissions") so your players can interact with NPCs.
   - **Note that players need the citizens.npc.talk permission to hear NPCs!**
