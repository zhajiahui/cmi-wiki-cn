Quester from Citizens1 has been discontinued. There are a few great options that will do everything Quester did and more:

- [Denizen](https://wiki.citizensnpcs.co/Denizen "Denizen") can be used for scripting interactions and events, giving a high level of control over player 'questing', among many other interesting things.
- [MineQuest](http://www.theminequest.com/) is an external plugin that can be used with Citizens 2 NPCs. See [here](http://www.theminequest.com/threads/rpg-minequest-citizens-2-0-0-cb-1-2-5-r5-1.72/)
- [Quests](http://dev.bukkit.org/server-mods/quests/) By Blackvein is an external plugin that can be used with Citizens 2 NPCs, this offers similar functionality to Citizens1 Quester.
- [Quester](http://dev.bukkit.org/server-mods/quester/) An external plugin that can be used with Citizens 2 NPCs.
