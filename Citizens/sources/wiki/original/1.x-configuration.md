Citizens is configured with a few YAML files. Configuration files will generate automatically when you first install Citizens. If a file is missing a setting, it will automatically generate.

## Configuration files

[citizens.yml](https://wiki.citizensnpcs.co/Citizens.yml "Citizens.yml") control the core components of Citizens.  
[mobs.yml](https://wiki.citizensnpcs.co/index.php?title=Mobs.yml&action=edit&redlink=1 "Mobs.yml (page does not exist)") contain configuration nodes for [Evil NPCs](https://wiki.citizensnpcs.co/index.php?title=Evil_NPCs&action=edit&redlink=1 "Evil NPCs (page does not exist)").  
[npc_profiles.yml](https://wiki.citizensnpcs.co/index.php?title=Npc_profiles.yml&action=edit&redlink=1 "Npc profiles.yml (page does not exist)") contain information about toggleable [Characters](https://wiki.citizensnpcs.co/Characters "Characters").  
[quests.yml](https://wiki.citizensnpcs.co/index.php?title=Quests.yml&action=edit&redlink=1 "Quests.yml (page does not exist)") contain your quest files for [Questers](https://wiki.citizensnpcs.co/index.php?title=Quester&action=edit&redlink=1 "Quester (page does not exist)").
