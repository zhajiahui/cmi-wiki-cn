Citizens is a popular Minecraft server plugin that allows you to create non player characters (NPCs) to provide varied gameplay and functionality for your server such as basic statues, shopkeepers, guards, scriptable NPCs and much more.

## Features

- NPCs can walk, stand and talk naturally to players.
- Easy to use [API](https://wiki.citizensnpcs.co/API "API") for developers that allow [Traits](https://wiki.citizensnpcs.co/Traits "Traits") to be built for specific functionality.
- [Support for all mob types](https://wiki.citizensnpcs.co/Types "Types") including Players, Pigs, and even non living ones like dropped items or arrow projectiles.
- [Commands](https://wiki.citizensnpcs.co/Commands "Commands") Extensive commands to customise NPCs.
- [Ridable NPCs](https://wiki.citizensnpcs.co/Controllable_NPCs "Controllable NPCs").
- Text editing.
- Basic GUI shops.
- Pathing.
- Much more.
