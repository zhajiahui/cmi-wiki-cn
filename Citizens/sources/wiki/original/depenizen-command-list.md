# BattleNight

```
	- bn add
	- bn kick
	- bn start
	- bn end
```

# mcMMO

```
	- mcmmo add [levels/xp] (skill:<skill>) (party:<party>)
	- mcmmo remove [levels/xp] (skill:<skill>) (party:<party>)
	- mcmmo set [levels/xp/xprate/vampirism/hardcore/leader] (skill:<skill>) (party:<party>) (state:{toggle}/true/false)
```

# Towny

```
	- towny add [resident/money/town/nation/townblock/bonus/plot/outpost] (<town>) (<location>) (<nation>) (qty:<#>)
	- towny remove [resident/money/town/nation/townblock/plot/outpost] (<town>) (<location>) (<nation>) (qty:<#>)
	- towny set [name:<name>/capital/open/public/mayor/surname/title/rank/board/war/maxsize/taxes/tag/spawn/perm/relation] (state:{toggle}/true/false) (<town>) (<nation>)
```

# Jobs

```
	- jobs promote [<job>] [<#>]
	- jobs demote [<job>] [<#>]
	- jobs join [<job>]
	- jobs quit [<job>]
```
