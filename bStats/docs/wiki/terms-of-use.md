# 使用条款

使用 bStats 前，请仔细阅读这些条款。访问或使用本服务的任何部分，即表示你同意受这些使用条款约束。

**最后更新：** 2025/12/04

<a id="1-introduction"></a>

## 1. 简介

**bStats**（下称“bStats”“我们”）是一项开源分析服务，插件或模组开发者将它接入软件，以收集技术性的使用数据。本使用条款（下称“**条款**”）适用于你访问和使用以下内容：

- bStats 网站（**bStats.org**）及相关子域名，统称“**网站**”。
- bStats 代码，包括嵌入插件的 Metrics 类，称“**bStats 代码**”或“**Metrics 类**”。
- bStats 提供的其他服务、仪表盘或工具，合称“**服务**”。

访问或使用服务的任何部分，即表示你同意受本条款约束。如果不同意，必须立即停止使用服务。

<a id="2-definitions"></a>

## 2. 定义

- **开发者**：在插件或模组中包含 Metrics 类的个人或实体。
- **服务器运营者**：运行游戏服务器，例如 Minecraft 或 Hytale 服务器，且服务器上运行了包含 Metrics 类的插件的个人或实体。
- **用户**：访问网站或服务的任何个人或实体，包括开发者、服务器运营者和访客。
- **自定义图表**：开发者自行定义并提交到服务的图表或字段。

<a id="5-metrics-class-integrity-use-of-the-service"></a>

## 5. Metrics 类的完整性（服务使用）

虽然 bStats 代码的开源许可证可能允许修改代码，但访问和使用*服务*，即 bStats 托管的数据收集端、仪表盘和相关基础设施，明确以**不修改 Metrics 类**为条件，*包名重定位除外*。唯一允许的修改是重定位包名：可以手动编辑 `package` 声明，或使用*仅执行包重定位*的 relocation/shading。

- **禁止其他所有修改。** 不得更改源码或字节码，不得重命名类、方法、字段，不得改变逻辑或所收集的数据，不得注入额外端点、封装或拦截调用，也不得以其他方式修改 Metrics 类。必须将 Metrics 类排除在混淆、裁剪、压缩、插桩或包重定位之外的任何转换处理之外。
- **退出机制完整性。** 不得移除、禁用、隐藏或干扰 bStats 的退出机制，或相关配置检查。
- **向非 bStats 服务器发送数据的分支。** 如果修改 Metrics 类或 bStats 代码，使其向 bStats 官方收集端以外的服务器发送数据，则*不得*使用本服务。这时必须：(i) 从代码、界面和文档中移除所有 bStats 品牌、名称和标识；(ii) 不得使用、分发、读取或修改任何 bStats 配置文件或目录，例如任何 “bStats” 配置，并确保修改后的代码不会联系 bStats 基础设施。
- **使用公开 API，避免修改 Metrics 类。** 如需额外统计，例如自定义图表，应通过插件或模组使用文档中的 bStats API 实现，保持 Metrics 类本身不变。
- **执行措施。** 我们可以屏蔽、限流或以其他方式限制违反本节的客户端，也可以移除或禁用相关仪表盘、数据集。
- **许可证说明。** 本节管理服务的访问权，不限制你在*不连接服务*的情况下，依照适用开源许可证使用代码的权利。

<a id="6-prohibited-data-including-custom-charts"></a>

## 6. 禁止收集的数据（包括自定义图表）

不得配置或使用 bStats 收集、提交或传输个人或敏感数据，包括但不限于：

- 完整或截断的 IP 地址、设备或硬件标识符、MAC 地址、广告 ID；
- 玩家用户名、玩家 UUID 或 ID，包括经过哈希或加盐处理的值、电子邮件、任何平台的账户 ID；
- 聊天记录、命令历史、可能包含个人数据的自由文本字段；
- 地理定位，包括 GPS 坐标、精确位置或地址；
- 服务器 IP 地址、域名或其他敏感的特定服务器信息；
- 机密信息、API 令牌、私钥、密码或身份验证材料。

对于通过收集禁止数据滥用服务的插件或开发者，bStats 保留调查和移除的权利，并可删除违规数据集。

<a id="7-data-roles-and-developer-obligations"></a>

## 7. 数据角色与开发者义务

1. **角色。** bStats 提供统计基础设施和仪表盘，并在服务设计中避免处理个人数据。对于 bStats 直接收集的服务和安全数据，例如服务器日志、滥用信号，bStats 作为独立的数据控制者。bStats *不是*开发者提交统计数据的数据处理者。使用本服务不会建立控制者与处理者关系，bStats 也不会签订数据处理协议（DPA）。如果你需要数据处理者或 DPA，就不得使用本服务。
2. **义务。** 对于你发送的任何数据，你声明已具备收集和传输这些数据的合法依据，并已提供必要告知。
3. **不提交个人数据。** 你不得提交个人数据，或可合理关联至个人的数据。如果意外提交了此类数据，必须及时通知我们并移除提交内容。
