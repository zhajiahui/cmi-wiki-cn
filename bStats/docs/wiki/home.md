# bStats 插件统计服务

想知道有多少服务器使用你的插件？

bStats 可以告诉你准确数量。它提供各主要 Minecraft 和 Hytale 服务端平台的服务器数量、版本使用情况及自定义统计。服务免费、尊重隐私，几分钟即可接入。

[几分钟开始使用](https://bstats.org/add-plugin) · [浏览插件列表](https://bstats.org/plugin-list)

<a id="integrate-bstats-in-2-easy-steps"></a>

## 两步接入 bStats

详细说明见[文档](getting-started.md)。

1. **注册插件**。免费注册账户，添加插件，获取唯一的插件 ID。[创建账户](https://bstats.org/register)。
2. **将 bStats 加入代码**。包含 `Metrics` 类，并使用插件 ID 初始化。支持各主要平台和构建工具。[启动接入向导](https://bstats.org/add-plugin)。

适用于 Bukkit、Spigot、Paper、Velocity、Hytale 等平台。
