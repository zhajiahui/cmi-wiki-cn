# 隐私政策

bStats 只收集提供有用统计所需的信息。以下分别说明插件端统计和网站账户系统的数据处理方式。

**最后更新：** 2025/12/04

<a id="bstats-plugin-privacy-policy"></a>

## bStats 插件隐私政策

如果你是安装了使用 bStats 的插件的服主，或只是访问网站的访客，本政策说明收集哪些数据、用途以及保存时间。如果你是在 bStats.org 注册账户的插件开发者，请参阅下方的 **bStats 网站隐私政策**。

<a id="2-scope-what-this-policy-covers"></a>

### 2. 范围：本政策涵盖什么

- **插件嵌入 bStats：** 本政策适用于服务器运行包含 bStats 脚本的插件时所收集的数据。
- **服主：** 通常你作为服主不会向 bStats 提供个人数据，传输的只有服务器环境的技术数据。
- **自定义统计：** 开发者可以在默认收集项以外添加自定义图表或指标。我们禁止收集个人信息；发现滥用后，会移除或封禁违规插件或作者。

<a id="3-data-we-collect-and-why"></a>

### 3. 收集的数据与用途

1. **服务器技术数据**

    - **示例：** 操作系统（OS）、Java 版本、CPU 架构、服务端版本，例如 Minecraft 或 Hytale 版本、插件或模组版本，以及用于去重和反滥用的假名化服务器标识符。
    - **目的与法律依据：** 为插件开发者提供分析，并运营、保护和改进服务。在此处理中，**bStats 作为独立的数据控制者**，依据 GDPR/UK GDPR 下的*合法利益*开展处理。开发者仍是独立的数据控制者，必须保证不向 bStats 发送个人数据。

2. **IP 地址（短期保存）**

    - 每次传输数据时，bStats 会收到 IP 地址，用于限流和防止滥用。
    - **保存时间（我们的系统）：** IP 地址最多保存 **60 分钟**，仅用于跟踪请求量，之后丢弃。绝不会关联到账户或个人档案。
    - **法律依据：** 我们在保持服务稳定、防止垃圾信息和滥用、保护基础设施方面的合法利益。

3. **自定义统计中禁止的个人数据**

    - 开发者不得通过自定义统计发送个人数据，包括姓名、电子邮件、IP、设备标识符，或任何能直接识别自然人的数据。我们会移除或封禁任何滥用行为。

<a id="4-legal-bases-for-processing-gdpruk-gdpr"></a>

### 4. 处理的法律依据（GDPR/UK GDPR）

- **合法利益：** 为维护服务完整性与安全，短暂处理 IP 地址，并使用假名化服务器标识符防止滥用、衡量插件使用情况。
- **反对权：** 对于基于合法利益的处理，你可以随时反对。服主实际可以通过关闭统计来行使选择，见第 5 节。

<a id="5-how-to-opt-out"></a>

### 5. 如何退出

- **配置文件：** 包含 bStats 的插件通常会生成一个全局配置文件。可在其中关闭 bStats，阻止任何插件继续发送数据。

<a id="6-data-retention"></a>

### 6. 数据保存

- **服务器统计：** 汇总、去标识化的非个人统计可以无限期保留在数据库中，以跟踪历史趋势。
- **IP 地址（我们的系统）：** 只在限流机制中最多保存 **60 分钟**，随后自动删除。
- **提供商安全日志：** CDN/WAF 和托管提供商可能依据其政策及我们的配置，短期保留有限的安全日志。我们会设置实际可行的最短保存期，不用这些日志建立用户画像。
- **备份：** 如保留备份，通常不会长期存储 IP 地址。任何短期日志都会定期覆盖。

<a id="7-security-measures"></a>

### 7. 安全措施

- **安全传输：** 通过 HTTPS/SSL 安全通道发送数据。
- **访问控制：** 只有获授权人员，例如网站维护者，才能访问原始日志。
- **基础设施防护：** 在可行时采取防火墙、入侵检测、定期安全检查等措施。

<a id="8-third-party-services-subprocessors-and-international-transfers"></a>

### 8. 第三方服务、分处理者与跨境传输

- **托管：** 基础设施由 [GameHosting.it](https://www.gamehosting.it/) 托管，代表我们处理数据。
- **Cloudflare：** 流量通过 Cloudflare 网络，以提供性能与安全保护。Cloudflare 可能临时处理 IP 地址及相关连接数据，并设置严格必要的 Cookie。
- **跨境传输：** 如果数据被传输到你所在司法辖区之外，例如从欧盟、欧洲经济区或英国传到其他国家，我们会依赖适当机制，包括充分性决定及认可框架、欧盟 2021 标准合同条款，以及适用时的英国附录或 IDTA，并定期评估传输风险。我们采用传输加密、严格访问控制和数据最小化措施。

<a id="9-your-rights-gdpr-and-similar-laws"></a>

### 9. 你的权利（GDPR 及类似法律）

根据当地法律，例如欧盟或英国的 GDPR，你可能对我们持有或处理的个人数据享有以下权利：

- **访问：** 确认我们是否处理你的个人数据。
- **删除或更正：** 由于保存窗口只有 60 分钟，数据很可能已经被删除，但你仍可以联系。
- **反对：** 反对基于合法利益的处理；除非有充分理由，我们会尊重此类反对。
- **投诉：** 向当地监管机构投诉。

我们会在一个月内回应 GDPR/UK GDPR 请求，在允许的情况下可延期。

<a id="2-scope-website-visitors-and-registered-users"></a>

### 2. 范围：网站访客与注册用户

- **公开访客：** 任何人都可以访问 bStats.org、查看插件统计，无需创建账户。
- **注册用户（插件开发者）：** 可以使用用户名和密码创建账户，或关联身份提供商，例如 GitHub。**电子邮件地址为可选项**。如果选择添加，我们会保存电子邮件及其验证状态，用于账户恢复和安全。

<a id="3-information-collected"></a>

### 3. 收集的信息

1. **账户注册与资料**

    - **数据：** 唯一用户 ID、显示名称、可选的用户名与显示用户名、可选头像、可选电子邮件及验证状态、账户状态，包括角色、封禁标记、封禁原因及到期时间，以及是否开启双重验证。
    - **密码安全：** 使用密码时，会通过行业标准密码哈希算法并为每个用户单独加盐后保存。绝不保存明文密码。
    - **目的与法律依据：** 提供并保护账户的合同必要性，以及平台安全方面的合法利益。

2. **身份验证会话与审计**

    - **数据：** 会话 ID 和令牌、创建与最后活动时间戳、到期时间，以及会话关联的 **IP 地址**和 **user agent**。
    - **Cookie：** 设置严格必要的身份验证 Cookie，例如会话令牌，让你保持登录。如果选择“记住”某个 2FA 设备，可能为此再设置一个严格必要的 Cookie。
    - **目的与法律依据：** 维持会话的合同必要性，以及防欺诈、减少滥用、排错和账户支持方面的合法利益。

3. **关联账户（OAuth 或社交登录）**

    - **数据：** 提供商标识、你在该提供商的账户 ID、登录所需令牌，例如访问、刷新和 ID 令牌及其有效期，以及授权范围。
    - **用途：** 仅用于身份验证及维持你要求的关联。我们不会收到你在这些提供商处的密码。你可以随时取消关联。
    - **法律依据：** 合同必要性，以及你关联提供商的请求或同意。

4. **验证**

    - **数据：** 用于电子邮件验证、重置密码、无密码登录等操作的一次性标识符或令牌及有效期。
    - **用途：** 完成请求的操作；到期后自动清除记录。

5. **双重验证（2FA）**

    - **数据：** 开启 2FA 时的 2FA 密钥与备用码。
    - **安全：** 安全存储，经过哈希和/或加密，仅用于验证登录。可以随时关闭 2FA 或重新生成代码。
    - **法律依据：** 账户安全方面的合法利益，以及你开启 2FA 的请求。

6. **Cookie 及相关技术**

    - **会话 Cookie：** 严格必要的 Cookie 用于保持登录和记住偏好。不使用第三方营销或行为追踪 Cookie。
    - **安全或边缘 Cookie：** CDN/WAF 可能为机器人管理和验证通过凭证设置必要的 Cookie。
    - **法律依据：** 严格必要的 Cookie 通常无需征求同意。

7. **基本服务器或访问日志**

    - 为安全和调试，可能处理最少量的访问日志，包括 IP。我们尽量让它们仅临时存在或短期保存。

<a id="4-how-we-use-your-data"></a>

### 4. 如何使用你的数据

- **提供网站服务：** 安全登录，包括密码和/或 OAuth、维持会话、支持 2FA、关联或取消关联提供商、将插件页面与账户关联、展示分析。
- **安全与可靠性：** 检测滥用、限制请求速率、保护基础设施、排查问题。少量按角色授权的工作人员可能为安全目的查看会话 IP 或 user-agent 数据。
- **事务性通信：** 如果提供电子邮件，我们可能发送验证、重置密码或安全通知。不发送营销邮件。电子邮件为可选项。

<a id="5-third-party-processing-subprocessors-and-international-transfers"></a>

### 5. 第三方处理、分处理者与跨境传输

- **账户管理软件：** 身份验证和账户功能运行在我们自己的基础设施上，账户数据保存在我们的数据库中。
- **OAuth 身份提供商（由你选择关联）：** 例如 GitHub 或 Google。我们接收提供商标识和登录所需的令牌，并保存它们以维持登录。你可以通过 bStats 或提供商设置撤销访问。提供商对数据的处理适用其自身隐私政策。
- **托管：** 网站和数据由 [GameHosting.it](https://www.gamehosting.it/) 托管。
- **Cloudflare：** 用于内容分发与防护，处理 IP 地址和相关连接数据，可能设置严格必要的 Cookie。
- **电子邮件投递（如使用电子邮件）：** 我们使用 Amazon Simple Email Service（*Amazon SES*，属于 Amazon Web Services）发送验证和安全邮件。发送时，AWS 会处理你的**电子邮件地址**、**邮件内容**和相关**元数据**，例如收件人、发件人、主题、时间戳，以投递邮件、处理退信和投诉。我们将 SES 配置为最少量保存，只为改善投递成功率使用抑制列表。邮件由我们配置的 AWS 区域中的 SES 处理，根据你的位置，可能涉及跨境数据传输。**提供电子邮件为可选项**；你可以随时在账户设置中移除，或联系我们移除。
- **跨境传输：** 适用时，我们依据充分性决定或认可框架、欧盟 2021 标准合同条款，以及英国附录或 IDTA。我们会评估传输风险，并采用加密、访问控制和数据最小化措施。

<a id="6-data-retention-and-deletion"></a>

### 6. 数据保存与删除

- **账户数据：** 资料，包括显示名称、用户名、可选电子邮件、可选头像，以及账户状态，包括角色、封禁状态，会保留到你删除账户。删除后会及时从活动系统中移除，并在常规备份轮换周期内从备份清除。
- **会话：** 保留到会话 `expires`，或你退出登录；过期旧会话会定期清除。相关会话 IP 和 user-agent 作为会话记录的一部分保存。
- **关联账户与令牌：** 保留到取消关联提供商或删除账户。
- **2FA 密钥与备用码：** 保留到关闭 2FA 或重新生成代码。
- **访问与安全日志：** 依据运营安全和提供商政策短期保存，并配置为实际可行的最短时间。

<a id="7-security-measures-1"></a>

### 7. 安全措施

- **密码保护：** 采用哈希与加盐，见第 3 节。
- **2FA 材料：** 密钥与备用码安全保存，经过哈希和/或加密，仅用于身份验证。
- **加密：** 传输数据通过 HTTPS 加密；会话令牌存储在安全、带 HttpOnly 属性的 Cookie 中。
- **访问控制：** 只有获授权人员才能管理网站基础设施和存储的数据。安全事件会进行调查，在法律要求时通知用户或监管机构。

### 8. 你的权利（GDPR、UK GDPR 及类似法律）

根据所在司法辖区，你可能享有访问、更正、删除、限制处理或反对处理的权利，以及数据可携带权和向监管机构投诉的权利。对于基于合法利益的处理，可以随时反对。

<a id="9-california-privacy-disclosures-cpraccpa"></a>

### 9. 加利福尼亚州隐私披露（CPRA/CCPA）

- **收集类别：** 标识符，包括用户 ID、用户名、可选电子邮件、提供商或账户标识符；在线标识符，例如会话令牌；互联网或技术信息，包括 IP 地址、user agent；资料信息，包括显示名称、可选头像；账户状态，包括角色、封禁状态。
- **敏感个人信息：** 账户登录凭据，例如哈希密码，以及 2FA 材料，包括密钥和备用码。仅用于提供安全身份验证，不用于推断个人特征。
- **目的：** 提供账户、安全与反滥用、运营分析。
- **出售或共享：** 不出售或共享所定义的个人信息，也不进行跨情境行为广告。
- **权利：** 访问、删除、更正和可携带权。我们会核实请求，例如通过账户登录或请求元数据，并在 45 天内回应，在允许的情况下可延期。
