# 常见问题

这里回答有关 bStats、账户和 Metrics 类的常见问题。还有疑问，可以在 [Discord](https://discord.gg/qTXtXuf) 求助，或在 GitHub 提交 Issue。

<a id="general"></a>

## 一般问题

<a id="will-bstats-stay-free"></a>

### bStats 会一直免费吗？

bStats 没有为现有功能收费的计划。感谢赞助商 [GameHosting](credits.md)，平台可以在没有订阅收入的情况下运行。未来即使增加高级付费功能，也会是可选的。

<a id="why-isnt-there-a-universal-category"></a>

### 为什么没有 “Universal” 通用分类？

将 Bukkit、BungeeCord、Hytale 等平台混在一起，会重复计算玩家并影响比较。分开分类可以让图表准确、易读。

<a id="is-there-an-api"></a>

### 有 API 吗？

有。bStats 为公开统计提供轻量的 REST API，入口是 [REST API 文档](https://bstats.org/docs/rest-api)。

<a id="map-charts"></a>

## 地图图表

<a id="why-are-map-charts-no-longer-shown"></a>

### 为什么不再显示地图图表？

没有哪一幅世界地图能让所有人都满意，作者已经为此争论过太多次，所以不再继续。

<a id="account"></a>

## 账户

<a id="how-do-i-change-my-password"></a>

### 如何修改密码？

可以在[修改密码页面](https://bstats.org/change-password)修改。

<a id="i-forgot-my-password"></a>

### 忘记密码了！

通过 Discord 或 GitHub Issues 留言，作者会核实账户归属并帮助重置。

<a id="metrics-class"></a>

## Metrics 类

<a id="how-do-i-add-bstats-to-my-plugin"></a>

### 如何把 bStats 加入插件？

进入[接入向导](https://bstats.org/add-plugin)，查看 Maven 和手动接入说明。

<a id="where-do-i-report-bugs-or-request-features"></a>

### 去哪里报告错误或请求新功能？

网站反馈请提交到 [bStats GitHub](https://github.com/Bastian/bStats/issues)，Metrics 类的改进请提交到 [bStats-Metrics](https://github.com/Bastian/bStats-Metrics/issues)。
