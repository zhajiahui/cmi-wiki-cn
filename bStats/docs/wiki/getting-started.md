# 文档目录

bStats 为主要 Minecraft 和 Hytale 服务端平台收集插件统计，可跟踪服务器数量、版本使用情况及自定义指标。服务免费、尊重隐私，几分钟即可接入。

<a id="add-your-plugin"></a>

## 添加插件

准备好收集统计了吗？逐步向导会指导你注册插件，并将 Metrics 类接入代码。

[启动接入向导](https://bstats.org/add-plugin)

<a id="custom-charts"></a>

## 自定义图表

使用自定义图表收集插件所需的指标。可以创建饼图、折线图和柱状图，展示功能使用情况、配置选择或使用模式。

[了解更多](custom-charts.md)

## REST API

通过 REST API，可以把插件统计嵌入自己的网站或工具。所有端点都是只读的，返回 JSON，无需身份验证。

[查看 API 参考](https://bstats.org/docs/rest-api)
