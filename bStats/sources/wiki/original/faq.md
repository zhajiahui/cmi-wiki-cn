# Frequently asked questions

Answers to common questions about bStats, accounts, and the Metrics class. Still
curious? Reach out on [Discord](https://discord.gg/qTXtXuf) or open an issue on GitHub.

## General

### Will bStats stay free?

bStats has no plans to charge for existing features. Thanks to our sponsor [GameHosting](./credits) the platform runs without subscription income. Any future premium functionality would
be optional.

### Why isn't there a "Universal" category?

Mixing Bukkit, BungeeCord, Hytale, and more in a single bucket would double-count
players and break comparisons. Separate categories keep charts accurate and easy
to read.

### Is there an API?

Yes. bStats exposes a lightweight REST API for public metrics. Start here: [REST API documentation](./docs/rest-api).

## Map charts

### Why are map charts no longer shown?

There is no world map that doesn't upset someone, and I've had this argument
enough times to stop having it.

## Account

### How do I change my password?

You can change your password on the [change password page](./change-password).

### I forgot my password!

Drop us a message on Discord or via GitHub Issues. We'll verify your ownership
and reset the account for you.
