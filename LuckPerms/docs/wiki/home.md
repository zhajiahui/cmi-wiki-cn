欢迎来到 LuckPerms Wiki。这里提供本插件的完整文档，介绍如何安装、设置、配置以及有效使用 LuckPerms。

<a id="where-to-start"></a>
### 从哪里开始？
如果你以前从未使用过权限插件，建议从最上面开始，按顺序往下阅读！

[入门指南](usage.md)页面详细介绍了权限的基础知识。

更简明的命令参考见[命令用法](command-usage.md)的各个子页面。

<a id="how-to-get-help"></a>
### 如何获取帮助

项目通过 [Discord](https://discord.gg/luckperms) 提供支持。

如果你能先尝试在本 Wiki 中查找问题的答案，我们会很感谢。这样我们就不用反复回答同样的问题了！

尤其请查看[常见问题](faq.md)页面和“操作指南（How To）”部分。 🙂

<a id="how-to-report-bugs"></a>
### 如何报告 Bug

请在 [GitHub](https://github.com/LuckPerms/LuckPerms/issues) 上提交 Bug 报告。

你需要先创建一个 GitHub 账号，然后新建一个“议题（issue）”。

报告 Bug 前，请确认问题确实由 LuckPerms 引起，或与 LuckPerms 有关。我们收到过很多问题报告，但其中的问题实际上是由其他原因引起的，请再仔细检查一遍！如果不确定，可以在提交报告*之前*先到 Discord 询问我们。

<a id="how-to-contribute-to-the-wiki"></a>
### 如何为 Wiki 作贡献

构成本 Wiki 的文本文件均已[开源](https://github.com/LuckPerms/wiki)，我们始终欢迎大家参与贡献！
