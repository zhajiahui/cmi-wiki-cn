# LoneLibs 官方发布说明

**已测试的 MC 主要版本：** `1.8`、`1.9`、`1.10`、`1.11`、`1.12`、`1.13`、`1.14`、`1.15`、`1.16`、`1.17`、`1.18`、`1.19`、`1.20`、`1.20.6`、`1.21`

**源代码：** <https://github.com/JavaPlugins/LoneLibs>

**捐赠链接：** <http://a.devs.beer/donate>

此插件已过时，作者目前的新版插件均不再需要它。  
你可能应该将它从服务器中移除。  
  
作者的部分插件使用的库。  
如果没有使用 ItemsAdder 或作者的其他插件，就无需安装它。  
  
所含库及其许可证：  

- [FastNBT](https://github.com/LoneDev6/FastNBT)
- [google.gson](https://github.com/google/gson)
- [NBT-API](https://github.com/tr7zw/Item-NBT-API)
- [headlib](https://github.com/DRE2N/HeadLib)
- [fastinv](https://github.com/MrMicky-FR/FastInv)
- [fastparticle](https://github.com/MrMicky-FR/FastParticles)
- [apache.commons](https://commons.apache.org/)
- [adventure](https://github.com/KyoriPowered/adventure-platform) （重定位到 lonelibs 包）
- [ArmorEquipEvent](https://github.com/Arnuh/ArmorEquipEvent) （重定位到 dev.lone.LoneLibs 包）

  
历史版本见[此处](https://github.com/JavaPlugins/LoneLibs/releases)。
