# LoneLibs

LoneLibs 汇集了作者部分插件使用的通用库。当前作者发布页已将其标为过时，并说明现代插件不再需要它。

随包版本为 **`1.0.65`**。LoneLibs 自身未声明必需插件，软依赖（`softdepend`）为 ViaVersion。本批其他插件的 `depend` 和 `softdepend` 均未指向 LoneLibs。

ItemsAdder 官方安装文档明确说明，**4.0.9 及以上版本无需 LoneLibs**。本批 ItemsAdder 为 `4.0.18`，适用这一条件。

随包未提供独立配置。已核对的官方简介没有列出服主管理命令或权限清单，随包插件声明中的命令和权限列表也为空。
