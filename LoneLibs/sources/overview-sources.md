# LoneLibs 官方资料摘录

核对日期：2026-10-19。随包版本为 `1.0.65`。

## 库的身份与维护状态

来源：[作者发布页](https://www.spigotmc.org/resources/outdated-lonelibs.75974/)。

> Libs used by some of my plugins

> This plugin is outdated and not needed by any of my modern plugins.

以上为作者当前发布页的说明；保留“现代插件”的范围，不将其扩大为所有历史版本都不需要。

## ItemsAdder 的版本条件

来源：[ItemsAdder 官方安装说明](https://wiki.itemsadder.com/plugin-usage/first-install/)。

> Put LoneLibs JAR inside the plugins folder (not required on 4.0.9 and greater)

对应中文：ItemsAdder 从 `4.0.9` 起无需 LoneLibs。本批 ItemsAdder 版本为 `4.0.18`，符合该条件。

## 随包元数据

随包 JAR 的 `plugin.yml` 中，LoneLibs 的 `depend` 为空，`softdepend` 仅有 ViaVersion；其他随包插件未在 `depend` 或 `softdepend` 中引用 LoneLibs。命令和权限列表为空，随包未提供独立配置。

本次查阅的作者简介没有独立配置手册或管理命令清单。
