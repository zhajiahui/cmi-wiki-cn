If you are using it in your Maven project, you can add this to you pom.xml file

```
</dependencies>  
  <dependency>  
    <groupId>com.github.Zrips</groupId>  
    <artifactId>CMILib</artifactId>  
    <version>1.5.4.6</version>  
    <scope>provided</scope>  
  </dependency>  
</dependencies>  
  
<repositories>  
  <repository>  
    <id>jitpack.io</id>  
    <url>https://jitpack.io</url>  
  </repository>  
</repositories>
```

CMILib is used in multiple plugins as a base core for most used actions like action bar messages, hover over messages, bossbar, material recognition, entity recognitions and so on. Try to always keep this plugin up to date to have best support for most versions out there.

This plugin was fully introduced with 1.17 minecraft version and was set to be required for plugins to work properly.
