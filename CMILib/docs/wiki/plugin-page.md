# CMILib 官方发布页

**主要适配的 MC 版本：** 1.21

**已测试的 MC 主要版本：** `1.7`、`1.8`、`1.9`、`1.10`、`1.11`、`1.12`、`1.13`、`1.14`、`1.15`、`1.16`、`1.17`、`1.18`、`1.19`、`1.20`、`1.20.6`、`1.21`

![[​IMG]](assets/1dff60337ec6-CMILLogo.png)​

集中提供多个插件共用的主要功能，便于维护，并减小插件的总体积。  
  
使用此库的插件：  

- **CMI** 从 9.x 版本起
- **Residence** 从 5.x 版本起
- **MobFarmManager** 从 2.x 版本起
- **SelectionVisualizer** 从 3.0.4.0 版本起
- **TryMe** 从 7.x 版本起
- **BottledExp** 从 3.x 版本起
- **JobsReborn** 从 5.x 版本起
- **TradeMe** 从 6.1.0.0 版本起
- **Recount** 从 3.5.0 版本起

安装：  

- 下载后放入 plugins 文件夹即可。
- 如果不希望自动更新，还可以在 CMIL 配置文件中修改自动更新功能。
