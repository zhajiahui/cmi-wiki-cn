# Residence 翻译约定

遵循工作区根目录 `../AGENTS.md`。

- 本目录只保存 Residence 的官方原文、译文、资源与核对备注。
- 中文正文位于 `docs/`；译稿位于 `sources/reviewed/`。修改译稿后用 `scripts/render-docs.py` 生成正文。
- `Residence` 保留项目名；residence 作为游戏区域译为“领地”，subzone 译为“子领地”，flag 译为“领地标志”。服务器权限单列为“权限节点”。
- 命令、权限节点、标志 ID、占位符、API、代码块保持原文；原文矛盾记录到 `notes/source-issues.md`。
- `Site/` 负责全站目录和构建，不在本目录写入 CMI 正文。
