创建领地有多种方式：可以手动选择区域，也可以在首次放置箱子时自动创建。

## 手动选择

拿出领地选区工具，默认是木锄。可以用 `/res tool` 查看服务器实际设置的工具。

主手拿着选区工具，分别用鼠标左键和右键选择区域的两个对角点。左键点击后，会收到类似下面的提示：

![选择第一个点后的提示](https://www.zrips.net/wp-content/uploads/2019/08/slectedPrimary.jpg)

选好第一个点后，走到领地的对角位置，右键点击方块，会收到第二个点的提示：

![选择第二个点后的提示](https://www.zrips.net/wp-content/uploads/2019/08/slectedSecondary.jpg)

选好两个点后，动作栏会显示选区大小，以及创建这块领地所需的费用。

![选区大小和创建费用](https://www.zrips.net/wp-content/uploads/2019/08/selectionCost.jpg)

同时会用粒子效果显示选区，方便确认创建后哪些区域会受到保护。

![粒子显示的选区范围](https://www.zrips.net/wp-content/uploads/2019/08/selectedArea.jpg)

如果范围不合适，可以重新选点，也可以用 `/res select expand [amount]` 或 `/res select contract [amount]`，沿视线方向扩大或缩小选区。

确认选区包含所有需要保护的地方后，执行 `/res create [resName]`。例如，要创建名为 SweetHome 的领地，就执行 `/res create SweetHome`。创建后会收到详细提示，保护范围也会再次显示出来。

![领地创建成功](https://www.zrips.net/wp-content/uploads/2019/08/createdResidence.jpg)

这样就创建好了，家园会受到领地保护。

选区还有其他参数，可以在指令列表中查看。

如果不方便手动选点，可以执行 `/res select auto` 开启自动选区。开启后，沿领地各个边缘走一圈，插件会随着你的移动选择区域，并用粒子效果显示选区。

## 自动创建

自动创建也有几种方式。

站在房屋中央，执行 `/res auto (resName) (radius)`。领地名称可以省略，省略时使用玩家名称。半径也可以省略；如果不想花光余额，可以用它限制要创建的领地大小。命令会在你周围创建允许范围内尽可能大的领地，并考虑周围已有的领地，避免重叠。

另一种方式是在服务器里第一次把箱子放到地上时自动获得领地。此功能需要在配置文件中开启，可以免费创建一块小领地，也可以按设置收取费用。

## 管理领地

创建后，你就是这块领地的主人，可以通过领地标志，调整其他玩家或动物在区域内的行为。

如果想保持私密，可以执行 `/res set tp false` 关闭 `tp` 标志，禁止其他人传送到领地。领地主人仍然可以传送。

执行 `/res set move false` 可以阻止其他玩家进入领地，同时阻止传送进入。

站在领地内执行 `/res padd [playerName]`，可以将朋友加入领地，给予传送、使用箱子、开门、放置和破坏方块等基本权限。需要移除时，执行 `/res pdel [playerName]`。

同一块领地可以为不同玩家设置不同权限。例如，站在领地内执行 `/res pset [playerName] move false`，就能只禁止指定玩家进入，其他人仍可进入。

随时可以用 `/res info` 查看领地本身的权限限制，以及为个别玩家单独设置的权限。

如果想和别人住在同一块领地，又不想给予整个领地的权限，可以使用子领地。子领地就是领地内部单独划出的区域。按照上面的方式，在领地内选好范围，再执行 `/res subzone firstSub`，就会创建名为 firstSub 的子领地。它可以设置不同的标志，让玩家在这块区域有更多权限，同时限制其在其他地方的操作。

需要扩大领地时，站在主领地区域内，避开子领地，面向要扩大的方向，执行 `/res expand [amount]`。`amount` 是沿该方向扩大的方块数。保护范围会随之更新，并收取相应费用。缩小领地的操作相同，命令为 `/res contract [amount]`。
