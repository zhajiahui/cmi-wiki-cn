# 占位符

Residence 支持 PlaceholderAPI，可以在同样支持 PlaceholderAPI 的其他插件中使用以下占位符。

- `%residence_user_current_owner%`：当前领地主人的名称。
- `%residence_user_current_rentends%`：租期结束时间。
- `%residence_user_current_rentdays%`：区域可租用的天数。
- `%residence_user_current_rentedby%`：正在租用该区域的玩家名称。
- `%residence_user_current_rentprice%`：区域出租时的租金。
- `%residence_user_current_forrent%`：区域是否待出租，返回 `true` 或 `false`。
- `%residence_user_current_saleprice%`：出售价格。
- `%residence_user_current_forsale%`：区域是否待出售，返回 `true` 或 `false`。
- `%residence_user_current_ssize%`：领地面积，计算方式为 `x*z`。
- `%residence_user_current_qsize%`：领地体积，计算方式为 `x*z*y`。
- `%residence_user_current_bank%`：领地银行余额。
- `%residence_user_current_res%`：当前领地名称。
- `%residence_user_blocksell%`：玩家出售方块的金额。
- `%residence_user_blockcost%`：玩家购买方块的费用。
- `%residence_user_maxrentdays%`：玩家可租用的最长天数。
- `%residence_user_maxrents%`：玩家可拥有的可出租领地数量上限。
- `%residence_user_maxsubdepth%`：允许的子领地嵌套层数上限。
- `%residence_user_maxsub%`：玩家可拥有的子领地数量上限。
- `%residence_user_maxud%`：高度上限。
- `%residence_user_maxew%`：长度上限。
- `%residence_user_maxres%`：玩家可拥有的领地数量上限。
- `%residence_user_cancreate%`：玩家是否可以创建领地，返回 `true` 或 `false`。
- `%residence_user_amount%`：玩家当前拥有的领地数量。
- `%residence_user_admin%`：玩家是否为领地管理员，返回 `true` 或 `false`。
- `%residence_user_group%`：玩家所属的 Residence 权限组。
