# 你好，MV5！

<p><img alt="multiverse 5 logo" src="assets/3bbbbccd8c29-multiverse5-long.svg"/></p>
<div class="bg-blue-700 rounded-3xl text-white text-lg">
<p class="px-5 py-5">Multiverse是志愿者在空闲时间开发的。如果您喜欢我们的工作，请考虑在 <a class="text-white font-bold underline" href="https://github.com/sponsors/Multiverse" target="_blank">Github 赞助商</a> 或 <a class="text-white font-bold underline" href="https://opencollective.com/multiverse-plugins" target="_blank">开放集体</a> 上支持我们。</p>
</div>
<p>Multiverse 5 经过多年的制作，我们很高兴向公众发布它！ </p>
<p>自 2021 年以来，我们一直在不懈努力，使其成为 Multiverse 有史以来最好的版本。 2025 年初，我们在 Discord 上发布了 Multiverse 版本 5 的 alpha 版本。我们收到的反馈非常有建设性和积极性，并且我们一直在努力根据反馈改进每个 alpha 版本。随着我们正式发布Multiverse 5第一个稳定版本，我们将继续改进它并添加更多功能！</p>
<a id="Whats-New?"></a><h2 id="whats-new">有什么新鲜事？</h2>
<ol>
<li>
<p>修复了Multiverse-Inventories <strong>玩家改名bug</strong>！</p>
</li>
<li>
<p>使用 <strong>完整制表符补全</strong> 改进了命令结构！</p>
</li>
<li>
<p>使用 <strong>详细评论和更多选项</strong> 修改配置文件！</p>
</li>
<li>
<p>使用 paper 的异步 api 和更精细的每个世界权限改进了传送处理！</p>
</li>
<li>
<p><strong>最后位置</strong> 的重大改进！！！添加了禁用每组的功能。向那些拥有大厅世界的人致敬！</p>
</li>
<li>
<p>添加了<strong>单一生物群系</strong>的世界创建选项和可定制的超平坦世界<strong>生成器设置</strong></p>
</li>
<li>
<p>更多更多，请参阅 <a href="mv5-whats-new-multiverse-core.md">完整的变更日志在这里</a>！</p>
</li>
</ol>
