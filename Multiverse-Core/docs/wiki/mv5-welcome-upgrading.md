# MV5 升级指南

<a id="READ-THIS-FIRST!"></a><h2 id="read-this-first">请先阅读此内容！</h2>
<ul>
<li>您的服务器必须运行 <strong>我的世界 1.18 及以上</strong></li>
<li>请在更新服务器之前<strong>进行备份</strong></li>
<li>安装 MV5 版本后您 <strong>无法降级</strong></li>
<li>依赖于旧 MV4 的 API 的 3rd 方插件可能无法工作。见<a href="mv5-welcome-incompatible-plugins.md">不兼容的插件</a></li>
<li>PlaceholderAPI 现在已内置，并且语法已更改！不要再使用 ecloud 版本了！请参阅<a href="core-reference-placeholders.md">PlaceholderAPI</a></li>
<li>有一些命令语法更改。见<a href="mv5-welcome-command-changes.md">命令变更</a></li>
</ul>
<a id="Downloading"></a><h2 id="downloading">正在下载</h2>
<p>我们最新的 MV5 版本可在 Modrinth 上使用！转到版本页面并确保下载以 <code>5.x.x</code> 开头的版本名称。</p>
<ul>
<li>Multiverse-Core: https://modrinth.com/plugin/multiverse-core</li>
<li>Multiverse-NetherPortals: https://modrinth.com/plugin/multiverse-netherportals</li>
<li>Multiverse-Inventories: https://modrinth.com/plugin/multiverse-inventories</li>
<li>Multiverse-Portals: https://modrinth.com/plugin/multiverse-portals</li>
<li>Multiverse-SignPortals: https://modrinth.com/plugin/multiverse-signportals</li>
</ul>
<a id="Will-I-lose-my-data?"></a><h2 id="will-i-lose-my-data">我会丢失数据吗？</h2>
<p>不！所有配置都应自动迁移到新格式，并且所有现有的世界、传送门、库存数据仍然有效。无需删除任何 config.yml、重新导入世界或重新链接任何传送门。如果您遇到任何问题，请通过 <a href="https://discord.gg/NZtfKky">不和谐</a> 与我们联系。</p>
