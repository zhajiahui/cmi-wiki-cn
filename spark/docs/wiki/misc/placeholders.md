# 占位符

在 Bukkit 服务器上运行时，spark 提供一些简单的占位符，可供 PlaceholderAPI 和 MVdWPlaceholderAPI 使用。

| 占位符 | 说明 |
| --- | --- |
| `%spark_tps%` | 返回过去 5s、10s、1m、5m、15m 平均 TPS 的格式化摘要。 |
| `%spark_tps_5s%` | 返回过去 5 秒平均 TPS 的格式化结果。 |
| `%spark_tps_10s%` | 返回过去 10 秒平均 TPS 的格式化结果。 |
| `%spark_tps_1m%` | 返回过去 1 分钟平均 TPS 的格式化结果。 |
| `%spark_tps_5m%` | 返回过去 5 分钟平均 TPS 的格式化结果。 |
| `%spark_tps_15m%` | 返回过去 15 分钟平均 TPS 的格式化结果。 |
| `%spark_tickduration%` | 返回过去 10 秒和 1 分钟平均游戏刻耗时的格式化摘要。 |
| `%spark_tickduration_10s%` | 返回过去 10 秒平均游戏刻耗时的格式化结果。 |
| `%spark_tickduration_1m%` | 返回过去 1 分钟平均游戏刻耗时的格式化结果。 |
| `%spark_cpu_system%` | 返回过去 10 秒、1 分钟和 15 分钟系统平均 CPU 使用率的格式化摘要。 |
| `%spark_cpu_system_10s%` | 返回过去 10 秒系统平均 CPU 使用率的格式化结果。 |
| `%spark_cpu_system_1m%` | 返回过去 1 分钟系统平均 CPU 使用率的格式化结果。 |
| `%spark_cpu_system_15m%` | 返回过去 15 分钟系统平均 CPU 使用率的格式化结果。 |
| `%spark_cpu_process%` | 返回过去 10 秒、1 分钟和 15 分钟进程平均 CPU 使用率的格式化摘要。 |
| `%spark_cpu_process_10s%` | 返回过去 10 秒进程平均 CPU 使用率的格式化结果。 |
| `%spark_cpu_process_1m%` | 返回过去 1 分钟进程平均 CPU 使用率的格式化结果。 |
| `%spark_cpu_process_15m%` | 返回过去 15 分钟进程平均 CPU 使用率的格式化结果。 |
