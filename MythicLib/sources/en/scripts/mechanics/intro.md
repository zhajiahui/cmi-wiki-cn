# Introduction {#introduction}

A script is a list of mechanics and conditions. If all of the script conditions are met, then its mechanics are ran in order, from first to last. A mechanic is a specific action, it can be sending a projectile, sending a message to a player, playing a sound to multiple entities, etc.

| Mechanic Type | Description |
| --- | --- |
| [Buffs](https://docs.phoenixdevt.fr/mythiclib/scripts/mechanics/buffs) | Give temporary stats; restore health, food... |
| [Projectiles](https://docs.phoenixdevt.fr/mythiclib/scripts/mechanics/projectiles) | Throw physical projectiles |
| [Miscellaneous](https://docs.phoenixdevt.fr/mythiclib/scripts/mechanics/misc) | Commands, cooldowns, delay, entity effects... |
| [Movement](https://docs.phoenixdevt.fr/mythiclib/scripts/mechanics/movement) | Give velocity and teleport |
| [Offense](https://docs.phoenixdevt.fr/mythiclib/scripts/mechanics/offense) | Deal damage, apply potion effects... |
| [Shapes](https://docs.phoenixdevt.fr/mythiclib/scripts/mechanics/shapes) | Helixes, slashes, parabolas... |
| [Variables](https://docs.phoenixdevt.fr/mythiclib/scripts/mechanics/variables) | Edit/create numbers, vectors etc. |
| [Visual](https://docs.phoenixdevt.fr/mythiclib/scripts/mechanics/visual) | Messages, sounds and particles |
| [Inventory/UI](https://docs.phoenixdevt.fr/mythiclib/scripts/mechanics/inventory) | Inventory/GUI related mechanics |
| [External](https://docs.phoenixdevt.fr/mythiclib/scripts/mechanics/external) | Mechanics implemented by other plugins |
