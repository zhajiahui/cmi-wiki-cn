# MythicLib 是什么 {#🤔-what-is-mythiclib}

你可能想知道 - **我安装了MMOItems或MMOCore，我的服务器上已经有足够的插件，为什么我需要安装并担心额外的插件？**

MythicLib不仅仅是一个包含共享代码和实用程序的库。它是一个集中功能以减少配置重复和代码冗余的插件。

它集中了RPG的基本功能，例如：

- MMO玩家属性系统，
- MMO伤害和元素系统，
- 伤害和再生指标，
- MMO技能系统和脚本引擎，
- 与其他插件的集成，
- 许多smaller-size共享配置选项，
