# 内置技能 {#💫-built-in-skills}

MythicLib拥有大约90默认技能的庞大注册表，它结合了MMOItemspre-6.7功能和MMOCorepre-1.9技能。

技能标记为mmocore 仅当安装MMOCore时才可用。

> **提示**
>
> 使用 CTRL+F 查找具有特定关键字的能力。

## 编辑built-in技能的伤害类型 {#edit-damage-types-of-built-in-skills}

造成伤害的Built-in技能（e.g。*火球*、*冲击波*等）可以更改其伤害类型。

> **警告**
>
> 此选项仅适用于built-in技能。特别是，它不适用于通过MythicMobs添加的自定义技能。要更改自定义技能的损坏类型，请参阅[下一节](builtin.md#edit-damage-types-of-custom-skills)。

例如，以下语法将 *Firebolt*技能造成的伤害类型更改为 *Magic*、*技能* 和 *Projectile*。它取自`MythicLib/skill/default_skills.yml`配置文件。

```yml
FIREBOLT:
  name: Firebolt
  icon: BOOK
  source: default:FIREBOLT
  #....
  damage_types: [MAGIC,SKILL,PROJECTILE]
```

要更改built-in技能造成的伤害类型，请在技能配置中使用`damage_types`参数。如果配置文件中不存在，请添加它。你可以指定一种或多种损坏类型，以逗号分隔。

### 编辑自定义技能的损坏类型 {#edit-damage-types-of-custom-skills}

要更改built-in技能造成的伤害类型，请在技能配置中使用`damage_types`参数。如果配置文件中不存在，请添加它。你可以指定一种或多种损坏类型。

如果你通过MythicMobs添加了自定义技能，则可以在使用`mmodamage`技能机制时通过指定`types`参数来更改其伤害类型。你可以在[此维基页面](custom/mythic.md#dealing-damage)]上找到更多信息。

如果你通过MythicLib添加了自定义技能，则可以通过在`damage`技能机制中指定`damage_types`参数来更改其伤害类型。你可以在[此维基页面](../scripts/mechanics/offense.md#deal-damage-to-an-entity)]上找到更多信息。
