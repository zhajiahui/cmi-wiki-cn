# 介绍 {#☄️-introduction}

技能在MMOCore或MMOItems中随处可见。它们可以绑定到物品或玩家职业，甚至在佩戴全套护甲时临时授予玩家。技能可以做任何事情，从伤害敌人到增强队友；它们可以是主动的（右键单击时会施放火弩箭）或被动的（当玩家着火时会造成额外伤害）。

> **信息**
>
> 由于MythicLib、1.3、MMOItems和MMOCore中的技能都集中到MythicLib中。因此，你可以在MMOCore玩家职业中使用MMOItems能力，并将MMOCore技能绑定到MMOItems物品/物品套装。

技能具有数字**参数**（伤害、冷却时间、持续时间...），你可以自定义这些参数，以使你的技能功率适应你的物品或玩家等级。例如，你可以编辑进攻性技能造成的伤害、某些药水效果持续多长时间、技能消耗多少魔力...

## 定制技能 {#custom-skills}

你可以使用具有自定义脚本语言的流行插件在所有 MMO 插件中注册自定义技能：

- [MythicMobs](custom/mythic.md)
- [MythicLib](custom/mythiclib.md)
- [Fabled](custom/fabled.md)
- [CoreTools](custom/coretools.md)
