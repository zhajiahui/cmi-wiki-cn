# 介绍 {#introduction}

某些机制需要实体或位置等参数：例如，如果你想在给定位置生成粒子，则需要指定该确切位置，这是使用 **目标选择器** 完成的。如果你想对实体造成 X 伤害，你必须能够告诉 ML 要损坏哪个实体。

**实体**和**职位/位置**都有目标选择器。目标选择器可以同时返回多个实体或位置，在这种情况下，相同的脚本/机制将被执行多次，每个实体/位置一次。

|目标选择器型|描述 |
| --- | --- |
| [实体](entity.md) | 实体目标选择器 |
| [位置](location.md) | 地点/位置目标选择器 |
