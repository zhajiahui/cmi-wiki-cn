# 介绍 {#introduction}

脚本仅在满足所有条件时才执行其机制列表。它们被检查in-order，这意味着MythicLib将首先评估第一个条件，如果不满足则停止，然后评估第二个条件，如果不满足则停止，依此类推......如果满足所有条件，则机制将依次执行。

|条件类型|描述 |
| --- | --- |
| [通用](generic.md) | 数学公式、布尔表达式、字符串检查... |
| [位置](location.md) | Location-based条件 |
| [杂项](misc.md) | 其他 |
