# 介绍 {#introduction}

脚本是机制和条件的列表。如果满足所有脚本条件，则其机制将按从第一个到最后一个的顺序运行。机制是一个特定的动作，它可以发送投射物、向玩家发送消息、向多个实体播放声音等。

|机械类型|描述 |
| --- | --- |
| [增益效果](buffs.md) | 给予临时属性；恢复生命值，食物... |
| [投射物](projectiles.md) | 投掷物理投射物 |
| [杂项](misc.md) | 命令、冷却时间、延迟、实体效果... |
| [机芯](movement.md) | 给出速度和传送 |
| [进攻](offense.md) | 造成伤害，施加药水效果... |
| [形状](shapes.md) | 螺旋线、斜线、抛物线... |
| [变量](variables.md) | 编辑/创建数字、矢量等 |
| [视觉](visual.md) | 消息、声音和粒子 |
| [物品栏/UI](inventory.md) | 物品栏/GUI相关机械 |
| [外部](external.md) | 其他插件实现的机制 |
