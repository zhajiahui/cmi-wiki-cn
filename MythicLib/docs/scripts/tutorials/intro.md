# 介绍 {#introduction}

欢迎来到这个**关于使用MythicLib制作自定义脚本的小教程**。在本教程中，我们将介绍一些基本的机制用法，以便你可以为自己创建一些看起来不错的技能。

> **提示**
>
> 在浏览此页面之前，建议你简要阅读[自定义脚本](../intro.md)页面。

侧栏中的其他选项卡将更深入地解释所有内容，这只是为了让你能够大致了解这种脚本语言的工作原理。

你将找到最常用机制的示例，例如损坏、声音或粒子，但最重要的是harder-to-use机制的示例，例如形状：射弹、抛物线等。

乍一看，脚本可能看起来相当吓人，但我们建议使用现代文本编辑器，例如 [VS Code](https://code.visualstudio.com/)，具有YAML颜色突出显示功能，这是非常有价值的。

|教程 |描述 |
| --- | --- |
| [投射物](projectile.md) | 你将学习如何让玩家发射具有破坏性的射弹 |
| [抛物线](parabola.md) | 抛物线弥补了漂亮独特的脚本，如彩虹或药水飞溅 |
| [螺旋](helix.md) | 螺旋非常适合指示基于治疗或增益的技能 |
| [斜线](slash-skill.md) | 这些都是非常经典的技能以及战士或近战职业。你将学习如何创建剑砍效果 |
