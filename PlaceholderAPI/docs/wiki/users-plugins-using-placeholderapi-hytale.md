# Hytale

这里列出了所有支持 Hytale 版 PlaceholderAPI 的插件。这些插件会提供自身的占位符，或允许使用其他占位符。  
如果你的插件尚未列出，且希望将其加入列表，请[阅读 Wiki 的 README](https://github.com/PlaceholderAPI/PlaceholderAPI/blob/wiki/README.md)，了解如何提交修改。
