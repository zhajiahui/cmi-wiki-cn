## 独立扩展

其中大多数扩展由 PlaceholderAPI 团队维护，可以视为*官方扩展*。

<a id="changeoutput"></a>
### **ChangeOutput**

papi ecloud download changeoutput

根据其他占位符的返回值更改输出内容。

更多信息请参阅 [GitHub 仓库](https://github.com/PlaceholderAPI/Expansion-ChangeOutput/tree/hytale)

```
%changeoutput_<options>_input:<input>_matcher:<matcher>_ifmatch:<output-if-matched>_else:<output-if-not-matched>%
```

- `<options>`
- equals - 精确匹配输入内容
- ignorecase - 忽略大小写后匹配输入内容
- ignorecolor - 忽略颜色代码后匹配输入内容
- contains - 检查匹配文本中是否包含输入内容
- >= - 检查输入值是否大于或等于匹配值
- > - 检查输入值是否大于匹配值
- <= - 检查输入值是否小于或等于匹配值
- < - 检查输入值是否小于匹配值
- `<input>` - 要替换的文本
- `<match>` - 为满足条件而查找的目标文本
- `<output-if-matched>` - 输入满足条件时，显示此文本
- `<output-if-not-matched>` - 输入不满足条件时，改为显示此文本

*所有参数都可以替换为用大括号包裹的其他占位符：* `{}`
