# Minecraft

这里列出了 Minecraft 版 PlaceholderAPI 的所有可用占位符。  
Hytale 版请参阅[此页面](users-placeholder-list-hytale.md)。

占位符扩展标题下方的信息框中可能会提供下载命令。  
如果显示 `Built into Plugin`，表示该占位符扩展已内置于其依赖的插件中。如果显示的是 URL，则需要手动下载，并自行放入 `expansions` 文件夹。

注意

此占位符列表按“原样”提供，不保证内容准确和/或为最新。

此页面仅在有人提出请求时更新。欢迎[提交拉取请求](https://github.com/PlaceholderAPI/PlaceholderAPI/pulls)，参与完善此列表。  
有关如何为此列表或整个 Wiki 作出贡献的更多信息，请参阅 [Wiki 的 README 文件](https://github.com/PlaceholderAPI/PlaceholderAPI/blob/wiki/README.md)。

<a id="changeoutput"></a>
### **ChangeOutput**

papi ecloud download changeoutput

根据其他占位符的返回值更改输出。

更多信息请参阅 [GitHub 仓库](https://github.com/Kqliber/Expansion-ChangeOutput)。

```
%changeoutput_<options>_input:<input>_matcher:<matcher>_ifmatch:<output-if-matched>_else:<output-if-not-matched>%
```

- `<options>`
- equals - 与输入完全匹配
- ignorecase - 匹配输入，忽略大小写
- ignorecolor - 匹配输入，忽略颜色代码
- contains - 检查匹配内容是否包含输入
- >= - 检查输入是否大于或等于匹配值
- > - 检查输入是否大于匹配值
- <= - 检查输入是否小于或等于匹配值
- < - 检查输入是否小于匹配值
- `<input>` - 想要替换的文本
- `<match>` - 用于判断是否满足条件的匹配文本
- `<output-if-matched>` - 输入满足条件时，显示此文本
- `<output-if-not-matched>` - 输入不满足条件时，改为显示此文本

*所有参数都可以替换为其他占位符，并用* `{}` *包裹*

<a id="checkitem"></a>
### **CheckItem**

papi ecloud download CheckItem

检查玩家背包中是否有某种物品。

```
%checkitem_<modifier1>,<modifier2>,<...>%- Returns if user has the item
%checkitem_amount_<modifier1>,<modifier2>,<...>% - Returns amount of items the user has
%checkitem_remove_<modifier1>,<modifier2>,<...>% - Removes the items from the players inventory - Can be used with amount, it just has to be after. (Ex. %checkitem_amount_remove_<...>%) Please becareful   as it does REMOVE ITEMS FOR GOOD
%checkitem_give_<modifier1>,<modifier2>,<...>%   - Gives the player items. Returns true if successful, returns the number of items NOT given if unsuccessful. (When unsuccessful items can still begiven,   it just might not be all of them)
%checkitem_getinfo:<slot>_<modifier1>,<modifier2>,<...>% - Returns information about an item in a slot. Returns information in the same order listed on this wiki. List is seperated via " &r" (Ex.  %checkitem_getinfo:0_mat:)
```

*说明：*  
*- `mainhand` 和 `offhand` 可用于 `getinfo:<slot>`*  
*- 出于安全考虑，`give` 和 `remove` 占位符默认* *禁用*。*如需启用，请查看 PlaceholderAPI 的 `config.yml` 文件。*

**修饰符**  
可以组合不同的修饰符，检查不同的值。  
可用的修饰符如下：

- `namecontains:<text>`  
  检查物品的显示名称是否包含 `<text>`\* \*\* ~
- `namestartswith:<text>`  
  检查物品的显示名称是否以 `<text>` 开头\* \*\* ~
- `nameequals:<text>`  
  检查物品的显示名称是否等于 `<text>`\* \*\* ^ ~
- `mat:<material>`  
  检查物品是否为 `<material>`（例如：`STONE`）^ ~
- `amt:<number>`  
  检查玩家是否拥有 `<number>` 个物品 ^ ~
- `data:<number>`  
  检查物品的数据值是否为 `<number>`（例如：红色羊毛的数据值为 `14`（`WOOL:14`））。  
  仅适用于 1.12 及更早版本！^ ~
- `custommodeldata:<number>`  
  检查物品的 CustomModelData 是否为 `<number>`  
  仅适用于 1.14 及更新版本！^ ~
- `lorecontains:<text>`  
  检查物品的描述是否包含 `<text>` *~* **与 `getinfo` 配合使用时，可以将 `<text>` 设为数字，以返回指定行的物品描述**\*
- `loreequals:<text>`  
  检查物品的描述是否等于 `<text>`，各行以 `|` 分隔 ^ ~  
  ***与 `getinfo` 配合使用时，可以将 `<text>` 设为数字，以返回指定行的物品描述***
- `matcontains:<text>`  
  检查物品的材质名称是否包含 `<text>`\*
- `enchantments:<enchantment=lvl>;<enchantment>`  
  检查物品是否具有 `<enchantment>` 附魔，可选填 `=level` 指定等级  
  使用原版 Minecraft 的附魔名称 ^ ~
- `enchanted`  
  检查物品是否已附魔（任意附魔均可）~
- `potiontype:<potiontype>`  
  检查物品是否具有该药水类型（[点击此处查看药水类型](https://hub.spigotmc.org/javadocs/spigot/org/bukkit/potion/PotionType.html)）^ ~
- `potionextended:<boolean>`  
  检查药水是否已延长持续时间 ^ ~
- `potionupgraded:<boolean>`  
  检查药水是否已提升等级 ^ ~
- `strict`  
  需要使用 `mat:` 修饰符。严格检查物品的名称和描述。（如果背包中有一块名为 `Test` 的石头，使用 `%checkitem_mat:stone,strict%` 会返回 false）
- `inhand`  
  检查物品是否在玩家手中。`inhand` 会检查*双手*。可以添加 `:main` 或 `:off` 来指定主手或副手。（例如：`inhand:main`）
- `inslot:<number>`  
  检查物品是否位于指定槽位（[点击此处查看有效槽位](https://i.imgur.com/3YCrfC8.png)）
- `nbtstrings:<key>=<value>;<key>=<value>`  
  检查物品的 nbtStrings 是否包含值为 `<value>` 的 `<key>`。\* ^ ~
- `nbtints:<key>=<value>;<key>=<value>`  
  检查物品的 nbtInts 是否包含值为 `<value>` 的 `<key>`。\* ^ ~

*对于 NBT 数据，可以在字符串中加入 `..` 来访问复合标签，例如（`%checkitem_nbtstrings:PublicBukkitValues..executableitems:ei-id=Free_Money%`）* ^

**说明：**

- \* 表示区分大小写
- \*\* 表示只能使用一个
- ^ 表示该修饰符支持 `give` 占位符
- ~ 表示该修饰符可与 `getinfo` 占位符配合使用
- 字符串中的逗号必须使用 `\` 转义（例如：`loreequals:Milk\, Eggs\, Bread`）
- **支持占位符，但必须使用大括号形式！（例如：`%player_name%` 应写成 `{player_name}`**

<a id="aevorinreports"></a>
### **AevorinReports**

内置于插件

所有占位符都使用 `reports` 标识符。

当前查看者占位符以当前解析所针对的玩家为对象。适用于全息文字、记分板、Tab 列表等针对各玩家分别显示的内容。

| 占位符 | 说明 |
| --- | --- |
| `%reports_submitted%` | 查看者提交的举报总数。 |
| `%reports_pending_submitted%` | 查看者提交的待处理举报数。 |
| `%reports_resolved_submitted%` | 查看者提交的已处理举报数。 |
| `%reports_valid_submitted%` | 查看者提交的有效举报数。目前统计的是已处理举报。 |
| `%reports_rejected_submitted%` | 查看者提交的已驳回举报数。 |
| `%reports_against%` | 针对查看者的举报总数。 |
| `%reports_pending_against%` | 针对查看者的待处理举报数。 |
| `%reports_resolved_against%` | 针对查看者的已处理举报数。 |
| `%reports_rejected_against%` | 针对查看者的已驳回举报数。 |

指定玩家占位符查询的是某个指定名称的玩家，而非当前查看者。将 `<player>` 替换为玩家名称。离线玩家必须已被服务器缓存。

| 占位符 | 说明 |
| --- | --- |
| `%reports_submitted_by_<player>%` | 指定玩家提交的举报总数。 |
| `%reports_pending_submitted_by_<player>%` | 指定玩家提交的待处理举报数。 |
| `%reports_resolved_submitted_by_<player>%` | 指定玩家提交的已处理举报数。 |
| `%reports_valid_submitted_by_<player>%` | 指定玩家提交的有效举报数。目前统计的是已处理举报。 |
| `%reports_rejected_submitted_by_<player>%` | 指定玩家提交的已驳回举报数。 |
| `%reports_against_<player>%` | 针对指定玩家的举报总数。 |
| `%reports_pending_against_<player>%` | 针对指定玩家的待处理举报数。 |
| `%reports_resolved_against_<player>%` | 针对指定玩家的已处理举报数。 |
| `%reports_rejected_against_<player>%` | 针对指定玩家的已驳回举报数。 |

群组服全局占位符统计举报数据库中的全部举报。

| 占位符 | 说明 |
| --- | --- |
| `%reports_total%` | 系统中的举报总数。 |
| `%reports_total_pending%` | 待处理举报总数。 |
| `%reports_total_resolved%` | 已处理举报总数。 |
| `%reports_total_rejected%` | 已驳回举报总数。 |

指定服务器占位符按一个已配置的服务器名称统计举报。将 `<server>` 替换为 AevorinReports 的 `server-name` 配置项中存储的服务器名称。

只有在 AevorinReports 使用 MySQL，且多台服务器连接到同一数据库时，这些占位符才会返回各服务器的独立统计。

| 占位符 | 说明 |
| --- | --- |
| `%reports_total_on_<server>%` | 在指定服务器上创建的举报总数。 |
| `%reports_total_pending_on_<server>%` | 指定服务器上的待处理举报总数。 |
| `%reports_total_resolved_on_<server>%` | 指定服务器上的已处理举报总数。 |
| `%reports_total_rejected_on_<server>%` | 指定服务器上的已驳回举报总数。 |
