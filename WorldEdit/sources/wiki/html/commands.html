General Commands#

/worldedit (or /we)

Description

WorldEdit commands

Usage

/worldedit <help|version|trace|reload|cui|tz|report>

/worldedit help

Description

Displays help for WorldEdit commands

Permissions

worldedit.help

Usage

/worldedit help [-s] [-p <page>] [command...]

  [-s]

List sub-commands of the given command, if applicable

  [-p <page>]

The page to retrieve

  [command...]

The command to retrieve help for

//rotate

Description

Rotate the contents of the clipboard

Non-destructively rotate the contents of the clipboard. Angles are provided in degrees and a positive angle will result in a clockwise rotation. Multiple rotations can be stacked. Interpolation is not performed so angles should be a multiple of 90 degrees.

Permissions

worldedit.clipboard.rotate

Usage

//rotate <rotateY> [rotateX] [rotateZ]

  <rotateY>

Amount to rotate on the y-axis

  [rotateX]

Amount to rotate on the x-axis
