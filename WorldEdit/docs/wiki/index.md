# WorldEdit 文档 { #worldedit-documentation }

WorldEdit 是易于使用的游戏内 Minecraft 地图编辑器。结合命令和“笔刷”，可以雕刻世界，或完成各种地形改造工作。

- 在数秒内快速创建、替换或删除数以千计的方块

- 不再浪费时间修复异常水流等琐碎问题！

- 快速创建球体、圆柱等基本形状

- 复制、粘贴、加载区域，并将其保存为 .schematics 文件

- 使用数学表达式生成地形等

- 用“笔刷工具”雕刻山脉、峡谷等地形

- 用指南针左键点击，或执行 /jumpto，快速传送到目标区域

- 选定区域后，立即从备份恢复

- [开源](https://www.github.com/EngineHub/WorldEdit)，也是历史最久的 Minecraft 项目之一，从 Minecraft Alpha 时期便已存在！
